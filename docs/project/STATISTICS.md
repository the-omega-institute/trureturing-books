# 全书统计只作编译产物

全书计数、排名、声明总索引与统计地图已从书稿中移除。附录 C 保留证据核对方法；定理、书面证明与开放问题的实际陈述及证据仍在所属章节中维护。正文修改或钉版不再刷新全书统计文件、声明序号与统计图片。

需要查阅统计时执行：

```bash
./tbook stats --book quantum-geometry
./tbook stats --book quantum-geometry --write
```

第一条命令只显示摘要；第二条同时导出 `build/statistics/quantum-geometry.json`。该目录被 Git 忽略，内容由正式出版解析器和所钉锁文件计算，环境出现次数与唯一声明数分别记录。需要详细标准输出时使用 `--json`。

确有外部消费者时读取这份编译产物，按需把它作为构建附件或站点资源发布并用相对链接引用；不复制总数到 README、正文、图注或幻灯片，也不把数据嵌入交互程序。站点和导出格式的验证账本是既有构建产物，继续按实际引用生成。

本次工具与规则定向回移自上游模板的统计产物改动（[上游 PR #109](https://github.com/the-omega-institute/trureturing-books-template/pull/109)）；保留当前模板版本与同步基线，待正常模板升级时采用上游版本，不在消费者重置清单。
