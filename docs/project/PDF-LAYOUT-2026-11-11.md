# PDF 排版复核 · 2026-11-11

本次复核中英文屏幕版、印刷版 PDF，修复公式越界、审计表跨列重叠、长章名页眉出纸以及定尺寸数学括号显示为标识符文字的问题。

## 修复

模板修复回馈至 [trureturing-books-template PR #14](https://github.com/the-omega-institute/trureturing-books-template/pull/14)，随 v0.2.5 发布，由 `./tbook template update` 同步：

- 表格里的 Lean 标识符可以在字符之间换行，避免很长的单个名称片段跨进相邻列。
- 超宽独立公式按所在列表、定理框或表格单元格的实际宽度等比缩小，布局同步计算缩放后的高度。
- 屏幕版页眉按 1:2 分配书名与章名栏宽，避免长章名把书名挤出纸张上边缘。
- 修正 Pandoc 固定尺寸角括号和取整括号的 Typst 输出；实际印出括号符号，保留 `\text{…}` 中的同名文字。

正文只调整排版：第 8、12、14、15、27 章的长推导显式分行，第 27、28 章的审计表增加契约列宽。各语言的定理、环境顺序、Lean 引用与数学内容保持一致。

## 验证方法

- 执行 `./tbook check`、完整单元测试和 `./tbook build all`，EPUB 同时经 epubcheck 验证。
- 对四份 PDF 的所有页面扫描文字是否越出纸张；检查同基线的等宽代码是否跨列交叠，排除封面有意采用的彩色叠印。
- 渲染并查看封面、目录、长章名页眉、分行推导、定理框、跨页审计表与验证账本；几何扫描辅助定位，实际渲染确认结果。
- 用浏览器复核改动章节的中英文版本，在深浅主题及桌面、手机宽度下检查公式和表格。
- Pages 部署后下载四份线上 PDF，再次核对页数、边界和修复位置。

新增上游回归以 Typst 实际布局坐标断言公式两端位于容器内、长标识符确实换行、后续段落没有压在公式上；旧模板四种组合均失败，新模板通过。定尺寸括号另以实际渲染宽度回归，示例从错误的 268.6 pt 恢复为 105.8 pt。
