## 确认问题与修正

`CH15-DUAL-SUM-NORMALIZATION`：`prop-finite-character-cancellation` 求和的指标为零化子 `H⊥`，原说明却使用位置子群 `H` 的初态归一化因子。对于 `H⊥` 上的归一化均匀输入，正确振幅是将原始和除以 `√|H⊥| √m`。由 `|H| |H⊥| = m`，在 `H` 上各得振幅 `1/√|H|`，在其外为零；取平方模后，每个位置的 Born 概率为 `1/|H|`，总和为 1。反向的均匀 `H` 输入则在 `H⊥` 上各得概率 `1/|H⊥|`；相邻实验卡采用这个方向，两语导言与命题后说明现已区分：导言先讲位置子群 `H` 的均匀输入及其频率支撑 `H⊥`，随后明确正式对偶命题从反方向在 `H⊥` 上求和，支撑为 `H`。

例如 `m = 8`、`H = {0,4}`、`H⊥ = {0,2,4,6}`：原因子使 0、4 两处各得概率 1、总和 2；正确结果为各 `1/2`、总和 1。邻近的自对偶四点例子无法暴露这个错误。

`CH15-ROOT-SUM-PAIRWISE`：非平凡特征标之和为零，并不要求每支箭头都有相反或垂直的配对。例如 `m = 3`、`H = {0}`、`x = 1` 时，三个三次单位根整体相消，各对既不相反也不垂直。中文导言及命题后说明现用“首尾相接、闭合归零／闭合链”保留相位齿轮与箭头意象；英文原有整体相消措辞无需改写。

产品改动仅为中文三行、英文两行。题记中的“三元两两正交”、全部标题、35 个环境／媒体块的序列、稳定 ID/GID、正式陈述、证明与固定结语保持原样；媒体图注、生产代码、控件、图片、锁和派生文件未改。

## 数学与来源证据

对任意 `m > 0`，写循环子群为 `H = d Z_m`、`n = m/d`，则 `|H| = n`、`H⊥ = n Z_m`、`|H⊥| = d`。原始和为 `Σ_{j<d} exp(2πijx/d)`；几何级数给出 `x ∈ H` 时为 `d`，否则为零。除以 `√(dm)` 即得上述归一化结论，包含平凡子群、全群与 `m = 1`。这项一般推导与既有 `m = 1…48` 的 198 个子群独立复算相符；有限扫描只作佐证。
