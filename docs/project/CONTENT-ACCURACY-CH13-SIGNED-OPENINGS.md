## 确认问题与改动

`CH13-NUM-SIGNED-OPENINGS`：两侧开角 α、β 的滑块均支持 −180° 至 180°。原中文把固定贝尔态在 Bob 整圈转动中的峰值一律说成外侧刻度 √(4+N)，其中 N=4|sinα sinβ|；英文原文只给上界，强度与中文不一致。

固定开角后，令 δ=φ−a₀，四项关联的和为 C cosδ+D sinδ，其中 C=1+cosβ+cosα−cos(α+β)，D=sinβ+sinα−sin(α+β)。直接展开得 C²+D²=4+4sinα sinβ，故整圈最大值为 √(4+4sinα sinβ)。乘积非负时到外侧 √(4+N)；乘积为负时只到内侧 √(4−N)。例如 α=90°、β=−90°，整圈期望值为 0，外侧谱界仍为 2√2。

两语现在都说出这个整圈最大值及其两种情形，保留“数值演示，不是证明”的身份。改动限两处语言 span，其他字节不变：计算、动态读数、抽屉、控件、预设、绿色依据块、GID、章节、锁与图片均未改。修订页面 SHA-256 为 `24017f807ba0d24b7bbeb418fe85791536d542ef6c2635277d13abe9aaa24059`。
