## 确认问题与最小修正

`CH16-INTRO-POLYTOPE-DIMENSION`：有限可达点集的凸包未必满三维；北极初态在门长预算 `L=0,1,2` 时分别是单点、线段和平面三角形。导言现允许低维凸包，只在满三维时使用平直弦面拼接的三维割圆图像，并明确 `ε_L` 是球面最坏方向到最近可达顶点的测地角覆盖残差。有限点集的覆盖半径严格为正，不表示每个目标都有正误差，也不是欧氏支撑高度的差。

`CH16-S08-LOW-L-INITIAL-STATE`：16.8 的定义允许任意固定初态 `r₀∈S²`，北极只是例子；原来紧接其后的低门长维数说明缺少初态限定。现只为原有点／线段／平面多边形例子补上“以北极为初态”，保持通用定义。

独立计算从 Pauli 共轭得到 `H(x,y,z)=(z,−y,x)` 与 `T(x,y,z)=((x−y)/√2,(x+y)/√2,z)`。北极的三个预算给出仿射维数 `0,1,2`；允许的初态 `r₀=eₓ` 则给出 `0,2,3`：预算 2 的四点 `eₓ,eᵧ,e_z,(1,1,0)/√2` 的差向量行列式为 `√2−1≠0`。因此不能把北极示例的维数推广到所有初态。一般残差结论来自有限集以外的球面点与连续距离函数在紧致球面上取得最大值；可达顶点自身的目标误差仍为零。
