# 重复环境记录：放宽正交条件的首批研究

本批接续第四章 4.1 的正交记录模型与 4.2 的单比特相位阻尼，研究完全正交能否放宽为有误差控制的近似。具体问题留在这份项目笔记；通用研究 skill 不保存假设清单或固定登记项。

在 D5、对应 Blueprint 和所钉 mathlib 的矩阵范数部分检索记录重叠、信道迭代、捏合误差和收缩界后，找到两个已有冻结声明：

- `D5/S3/Quantum/Decoherence/EnvironmentMarginalChannel.environment_marginal_channel`：受控记录耦合的环境边缘态等于 Gram 逐项乘法。
- `D5/S3/Quantum/Decoherence/RepeatedRecordExponentialDecay.repeated_record_exponential_decay`：重复信道的逐项公式、记录类捏合公式及 Frobenius 相对误差上界。

两项声明已在书库当前钉版 `bb452a18f3e77a2c4e50864d2d7bce34fb73a040` 冻结，故用 `./tbook pin --refresh` 增加引用，不升级提交或复制 Lean 定理。上游 [PR #30028](https://github.com/the-omega-institute/trureturing/pull/30028) 扩充原定理所属 Scribe 的应用说明及其工具生成的投影，没有新增数学声明或冻结目标。

单位记录向量记为 E_i，Gram 系数采用 E_i(a) 乘以 E_j(a) 的共轭再求和的约定。若不同记录向量之间的重叠模长统一不超过 q，且 0 ≤ q < 1，则第 N 步到记录类捏合的 Frobenius 误差至多为初始残差的 q 的 N 次方。这是定量充分条件；同类内部相干被保留，不能无条件改称逐个基地址的完全退相干。

临时 Lean 应用检查成功地从原声明取出该误差界，并编译了一个归一化的相位相反记录对：两向量不相等而重叠模长为 1。原定理的公理闭包仅含 `propext`、`Classical.choice`、`Quot.sound`。检查文件作为临时证据，不保留成包装定理或登记模块。另以固定种子 712403 探索了 200 组有限记录、800 个步数情形，包含重复向量；误差界在数值容差 1e-12 内成立。该探索不替代 Lean 证明或实验观测。

书中给出两条重叠为 1/2 的非正交单位记录及赤道初态，直接手算十步后的相对残差为 1/1024。精确误差界、Frobenius 范数、记录向量相等的分组、相位边界，以及新鲜无相关环境的重复信道解释，均同步写入中英文。更新附录 C、声明地图、由锁文件驱动的静态图与缩略图，保持既有索引标签稳定。
