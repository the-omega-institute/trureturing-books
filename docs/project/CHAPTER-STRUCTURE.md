# 章节层级与文件命名

主章保留章首标题、作者题记、导言和总览图，独立论题成为子章节页面。目录层级与编号以各语言的 `SUMMARY.md` 为准，文件名只提供稳定的编辑标识。

主章命名为 `chNN-topic.md`，子章节命名为 `chNN-sNN-topic.md`，更深一级继续追加 `-sNN`。数字至少两位，主题使用英文 kebab-case；中英文文件名完全一致，文件平放在各自语言目录。入口、终章和附录沿用 `README.md`、`coda.md`、`appendix-a.md` 等现有名称。

```bash
./tbook new-chapter quantum-geometry ch30-s07-worked-examples \
  --parent ch30-fields-lines-eth-and-navier-stokes \
  --title zh="手算例子" --title en="Worked examples"
```

命令同时校验各语言并创建文件，将新子章节插在父项的全部后代之后。每个版本目录中的条目使用每级两个空格缩进；需要更深一级时，指定现有子章节为父项。拆分正文的完整步骤见 [写作手册](../AUTHORING.md) 的“章节命名与长章拆分”。

## 标题格式

目录与各页面的一级标题使用相同文字，一级标题后的 `{#id}` 不属于显示名称。中文主章为“第三十章 标题”，英文为“Chapter 30 Title”；编号与标题之间是一个空格。子页面为“30.1 标题”，页内二级标题从“30.1.1 标题”开始，三级标题继续到“30.1.1.1 标题”。未拆分的主章在二级标题从“9.1 标题”开始，所有层级都沿父标题追加数字。

序曲和终章的一级标题分别为“序曲 标题 / Prelude Title”“终章 标题 / Coda Title”，页内编号为 `0.1` 与 `40.1`（终章是目录中的第 40 个编号单元，主章仍为 39 章）。附录为“附录 A 标题 / Appendix A Title”，页内编号为 `A.1`、`A.1.1`。叙事名称如“第一幕”是标题内容；额外的“一、”“I.”“1.”序号不再与层级编号叠加。

标题改名时保留原有显式 id；原先依文字生成的片段也写成显式 id，已有小节链接继续有效。本次只调整标题格式、同步目录中两处旧名称；正文段落、环境 id、Lean 引用与媒体顺序保持一致。模板的标题检查还会提示目录与一级标题不同、一级标题缺失或重复、层级跳跃以及中英文层级序列不同。
