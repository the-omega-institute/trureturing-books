# 研究方法与证据

## 原文到命题

在当前项目的已有研究材料中保留接续所需信息；仅在需要时新增简洁笔记。记录的篇幅与格式服从研究内容，不要求先登记假设、分配编号或建立全量清单：

- 来源：原文引句与可定位的位置、当前书库提交和钉版；上游基线及已有相关工作。
- 目标：待证明或检验的精确命题、基础前提、要消去的假设、预期适用域。
- 对应：原文各子句与数学对象的对应；构造或抽象是否覆盖原来的对象族；物理读出、单位及观测量。
- 路线与证据：实际检索词及命中、关键推导、原始文献出处、数值方法和种子、失败路线的具体原因。
- 结果：确切证明范围、反例、误差界或仍缺的桥梁；形式化 GID、实际构建/公理检查/审查结果。
- 发布：上游与书库 PR、候选提交、实际合并提交、冻结状态、钉版、CI 与 Pages；失败和未执行的检查分别写明。
- 接续：最小未解子问题、下一条有根据的路线，以及本批是否产生值得回灌 skill 的经验。

一个问题可以拆出结果不同的子问题；准确说明每个结果覆盖了什么，原始主张在修正后仍应可追溯。研究笔记及进度描述都不能替代证明或实验依据。

## 优先选择真正减少假设的路线

以下路线用于选题，不预设其结论已经成立：

- **构造**：直接构造记录、投影或更新算子，证明原来要求的性质；随后检查构造所覆盖的对象范围。
- **重构与表示**：给定操作公理，刻画所有满足它们的模型。列明哪些公理来自经验、哪些只是对象定义。
- **近似与稳健性**：把完全正交、零耦合、固定相位等理想条件替换成量化偏差，研究结论如何变化。给出误差所在的范数与参数依赖。
- **极限与有效理论**：从更具体的动力学推导有效模型，明确取极限、交换积分和忽略高阶项所需条件。
- **反例与可区分预测**：寻找同样满足现有前提却违反目标的实例，或与基准模型产生不同可测结果的参数区间。

完成有效模型的误差界，不表示已经证明现实对象精确满足理想假设。抽象机制的可实现性，也不能独自建立某个具体物理系统确实采用了该机制；后一步需要系统识别、操作对应与观测证据。

## 对 skill 的行为核对

新建或改动指引后，用与改动有关的真实或隔离情景检查决策。例如：

1. 找到更强的既有冻结定理时，能否复用而不重复造上游声明。
2. 只证明有效模型的误差界时，能否保留原始物理假说的残余范围。
3. 上游 PR 已合并但尚无冻结状态片时，能否继续其他研究而不提前钉版。
4. 某条哲学类比尚无操作定义时，能否诚实保留诠释，转向其中有数学内容的子问题。

核对记录写出实际输入、决策和观察到的结果，不把计划执行的核对写成已通过。
