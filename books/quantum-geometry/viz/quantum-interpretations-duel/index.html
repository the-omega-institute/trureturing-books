理论接口 · 六个基础谜题与五种诠释Theory interface · six foundational puzzles, five interpretations

舞台上只有一台仪器：远方的 Bob 拿着 B，密封实验室里有量子比特 S、朋友的记录 F 与 N 份环境寄存器 E，起始态 |Φ⁺⟩SB = (|00⟩ + |11⟩)/√2，张量次序 S、F、B、E。过程 II 把旋转后的 S 基相干地拷进 F 与环境：|Ψ⟩ = (|uθ, 0, uθ⟩|e₀⟩⊗N + |vθ, 1, vθ⟩|e₁⟩⊗N)/√2，其中 |uθ⟩ = cos θ|0⟩ + sin θ|1⟩，|vθ⟩ = −sin θ|0⟩ + cos θ|1⟩（θ 是希尔伯特空间里的角，布洛赫轴的角是 2θ）。五副透镜读的是同一个 |Ψ⟩、同一组旋钮。本页是交互数值演示，不是证明；每个绿框只为它所引的那一条冻结陈述负责。见 附录 D · 六个基础谜题与诠释。

  1. 条件与无条件。以 Bob 的 Z = +1（B = 0，概率 1/2）为条件，|Ψ₊⟩ = c|uθ, 0⟩|e₀⟩⊗N − s|vθ, 1⟩|e₁⟩⊗N；在逻辑基 (|uθ, 0⟩, |vθ, 1⟩) 下对环境求迹得 ρL = [[p, −csγ], [−csγ, 1 − p]]，p = cos²θ。θ = 30° 时恰为 3/4 与 1/4：这是条件权重。不加条件时，朋友与 Bob 的边缘都是 50/50；没有任何旋钮或透镜能把这个边缘变成 75/25，没有经典消息也传不出那个 herald（手算，ARGUED）。
  2. 二次读数（NUM）。γ(N) = exp(−N/10⁴)（MODEL）。Tr ρL² = p² + (1 − p)² + 2p(1 − p)γ²；捏合删去的质量 C = 2p(1 − p)γ²（LEAN ✓ pinching_discarded_coherence_mass 给的就是 |ρ₀₁|² + |ρ₁₀|²）；条纹可见度 V = 2√(p(1 − p))γ；r² = (2p − 1)² + 4p(1 − p)γ²，τL:E = 2(1 − Tr ρL²) = 4p(1 − p)(1 − γ²)，于是 r² + τ = 1。θ = 30° 时 γ → 1 给 (r², τ, C, V) = (1, 0, 3/8, √3/2)，γ → 0 给 (1/4, 3/4, 0, 0)。r² + τ = 1 是这个两施密特系数模型的手算，LEAN ✓ complementary_context_probability_pythagoras 不直接给它，它也不是任意混合多体系统的单配等式。熵以比特计：h₂(x) = −x log₂x − (1 − x) log₂(1 − x)，S(ρL) = h₂((1 + r)/2)，ΔS捏合 = h₂(p) − S(ρL) ≥ 0；θ = 30° 时 h₂(p) = 0.811278124459 比特。
  3. 谜题一 · 维格纳的切割。LEAN ✓ energy_eigenstate_stationary：有限维厄米 H、归一的能量本征向量 v，则 U = exp(−itH) 幺正且 UρvU* = ρv（只对本征态，不推出测量结果）。LEAN ✓ finite_record_pinching_idempotent：记录测量的未读态映射 𝒫∘𝒫 = 𝒫（系综恒等式，不选出一行，不是物理坍缩律）。LEAN ✓ objective_claim_requires_invariant_common_factor：客观诠释主张的前提里已带着跨语境不变的公因子，定理只把它取出来，不裁决维格纳朋友的一致性。页面算出：只碰 SF 时维格纳能看到的可见度是 V = 2√(p(1 − p))γ，碰到 SF + E 时理想的逆幺正撤回整条拷贝，可见度回到 2√(p(1 − p))（访问范围是约定，MODEL）。
  4. 谜题二 · 从“与”到“或”。LEAN ✓ reduced_irreversibility_is_access_defect：对角相同、非对角不同的两个量子比特，经同一个幺正拷贝后联合记录不同、约化态相同，不存在同时恢复两者的映射，而拷贝的伴随把两条联合记录都撤回：这里的“不可逆”是访问缺陷，不是客观坍缩，也不是热力学代价。LEAN ✓ pinching_discarded_coherence_mass 与 complementary_context_probability_pythagoras（在它显式的纯度—范数与坐标前提下）。“或”是从混合里选出一行：页面用种子 ξ，ξ < p 时记录 0，这是 MODEL / 玻恩规则的假设，不是 Lean 推出的结果。
  5. 谜题三 · 不等的权重。LEAN ✓ inner_product_norm_parallelogram_law（只这一方向，不含逆命题，也不推出玻恩规则）；rank_one_pure_state_modulus_square_reduction（代数约化，归一与概率解释要另加前提）；complete_common_phase_polynomial_theorem（有限变量多项式定理，不排除更高次的不变观测量）；square_eq_neg_one_of_skewAdjoint_unitary（R² = −I，不证明实希尔伯特空间的表述不可能；舞台上 |vθ⟩ = R|uθ⟩，R = [[0, −1], [1, 0]]）；robertson_schrodinger（对称的全线性映射与归一态；对实态 |uθ⟩、A = Z、B = X，对易子之半为 0，乘积全落在协方差上）；diagonal_prime_observables_cannot_recover_relative_phase（名字里有 prime，定理里没有素数前提）。多世界“两支分支、各数一次”与权重 3 : 1 的张力，以及 Gleason 的定理、Renou 等（2021）的三节点网络协议与 Chen 等、Li 等（2022）的实验，都是 ARGUED。
  6. 谜题四 · 贝尔与 EPR。另做一轮独立的、记录之前的贝尔测试（或记录已被完全撤回），而不是让朋友的记录与维格纳的干涉同时测量。A(a) = cos a Z + sin a X，B(b) = cos b Z + sin b X，E(a, b) = cos(a − b)，P(x, y | a, b) = [1 + xy E(a, b)]/4。取 a = 2θ、b = 0 恰得条件 P(x = +1 | y = +1) = cos²θ 与均匀的边缘；CHSH 取 a₀ = 0、a₁ = π/2、b₀ = π/4、b₁ = −π/4，S = 2√2 ≈ 2.828427124746 > 2（LEAN ✓ bell_chsh_state_expectation_is_greatest：这个固定算子的最大期望恰为 2√2）。这个最大值不是朋友与环境不可逆地记录之后 S–B 还剩的关联。LEAN ✓ local_marginal_correlation_blind_spot：6 维的局部部分看不见 9 维的关联部分；它不是无信号定理本身。单位 c = 1、L = 1，事件 A = (0, −1)、B = (0, +1)，Γ = 1/√(1 − β²)：Δt′ = −2Γβ，Δx′ = 2Γ，Δt′² − Δx′² = −4；β = ±0.8 给 Δt′ = ∓8/3、Δx′ = 10/3。推动只改事件坐标，不改玻恩权重、γ、CHSH 与边缘（手算，NUM；LEAN ✓ eq_smul_minkowski_of_null 只说零锥决定二次型到一个比例，比例可为 0）。
