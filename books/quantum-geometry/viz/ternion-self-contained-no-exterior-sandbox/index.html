这是数值沙盘，不是证明。每个数都由页面当场算出（NUM）；每条 Lean 定理只在依据栏写明的那一个实例上演示，没有实例的写明“页面不证明它”；双球的画法、毛发与标架的取样、“粒子”“场·波·粒”“无外”的读法都是本书的模型（MODEL）。

  1. 两只球。站在 A 看三元数 𝕋₃ ≅ S³(1)：到 A 的测地距离为 r 的点是 (cos r, sin r · n)，n 是单位方向。丢掉第一个坐标，r ≤ π/2 的半球落进左球 Bin（以 A 为心），r ≥ π/2 的半球落进右球 Bout（以 Ā 为心，按 x 镜像）。两只球的球面是同一个接缝 S²eq。
  2. 自锁成粒。𝕋₃ 的体积 2π² 有限，边界却是空集。时间轴把 r 从 0 推到 π：紫色体积先填满 Bin、再填满 Bout，扫过的 (1/2π²)∫η 从 0 走到 1；它的边界就是琥珀波前，面积 4π sin² r，只在 r = 0 与 r = π 两端为 0。填到一半时边界最大，没有“半颗”闭合的三元数。
  3. 场·波·粒。青色三脚架是左不变标架 eⱼ(q) = q·iⱼ 的投影，四维长度处处为 1，χ(S³) = 0；S² 上的品红毛发在两极留下两个旋涡零点，χ(S²) = 2。青色曲线是 k = 1 驻波 ψ₀ = cos r，Δψ₀ = −3ψ₀。整体积分 Q = 1 是“粒子”的读数。
  4. 去掉 C 点。取 A = (1, 1, 0, 0)/√2、B = (1, 0, 1, 0)/√2，夹角 60°、κ = 0.75。仿射和 A + B − C 要先钉一个 C：C₁ = (1, 0, 0, 0) 给模方 4 − 2√2 = 1.1716，C₂ = (0, 0, 0, 1) 给 4.0000，都不在壳上，还随 C 漂移。堆步 [B, A, B] = B A⁻¹ B = (0, −1/√2, 1/√2, 0) 模方为 1，换任何基点都不变，[A, C, C] = A。钉住 C = 1 把 dim SO(4) = 6 降到 dim SO(3) = 3。
  5. 向外即向内。波前面积 A(r) = 4π sin² r 在 r = π/2 达到 4π、包住一半体积 π²；越过接缝后射线没有撞墙也没有折返，波前却收拢，r = π 时在 Ā 收成一点，包满 2π²。

  1. The two balls. Seen from A, the ternion 𝕋₃ ≅ S³(1) has the points (cos r, sin r · n) at geodesic distance r, with n a unit direction. Dropping the first coordinate, the hemisphere r ≤ π/2 falls into the left ball Bin (centred on A) and the hemisphere r ≥ π/2 into the right ball Bout (centred on Ā, mirrored in x). The spheres of the two balls are one and the same seam S²eq.
  2. A particle that locks itself. 𝕋₃ has the finite volume 2π² and an empty boundary. The rail pushes r from 0 to π: the violet volume fills Bin and then Bout, and the swept (1/2π²)∫η runs from 0 to 1; its boundary is the amber wavefront, of area 4π sin² r, which is 0 only at r = 0 and r = π. Half filled, the boundary is largest: there is no closed “half” ternion.
  3. Field, wave, particle. The cyan tripods are projections of the left-invariant frame eⱼ(q) = q·iⱼ, of four-dimensional length 1 everywhere, χ(S³) = 0; the magenta hair on S² keeps two vortex zeros at the poles, χ(S²) = 2. The cyan curve is the k = 1 standing wave ψ₀ = cos r, Δψ₀ = −3ψ₀. The whole integral Q = 1 is the reading “particle”.
  4. Drop the point C. Take A = (1, 1, 0, 0)/√2 and B = (1, 0, 1, 0)/√2, 60° apart, κ = 0.75. The affine sum A + B − C needs a pinned C: C₁ = (1, 0, 0, 0) gives the squared norm 4 − 2√2 = 1.1716 and C₂ = (0, 0, 0, 1) gives 4.0000, both off the shell and drifting with C. The heap step [B, A, B] = B A⁻¹ B = (0, −1/√2, 1/√2, 0) has squared norm 1 and is the same for every base point, and [A, C, C] = A. Pinning C = 1 lowers dim SO(4) = 6 to dim SO(3) = 3.
  5. Outward is inward. The wavefront area A(r) = 4π sin² r reaches 4π at r = π/2, enclosing half the volume, π²; past the seam the rays hit no wall and do not turn back, yet the wavefront closes up and shrinks to the point Ā at r = π, enclosing all of 2π².
  6. Two balls glued. S³ = Bin³ ∪ Bout³ glued along the seam, both balls of volume π². Crossing the seam from Bin you enter the other finite ball, centred on Ā, not a void outside; the magenta dashed lines join copies of one and the same seam point.
  7. Two lenses. The ontology lens uses the intrinsic names A, Ā, Bin, Bout and S²eq; the coordinate lens reads the same picture as a projection in ℝ⁴: (1, 0, 0, 0), x₀ ≥ 0, x₀ = 0. Both use the same r and C.
