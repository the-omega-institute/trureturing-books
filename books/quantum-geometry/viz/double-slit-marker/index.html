理论接口 · 这个页面在演示什么Theory interface · what this page shows

粒子穿过双缝，缝后的标记把“走了哪条缝”写下来：左缝写成 r_L，右缝写成 r_R。左边是屏，右边是两支标记箭头。拖动它们的夹角 α，条纹对比度与路径可辨度此消彼长；标记是纯态时，点始终在圆上。本页是数值演示，不是证明。

  1. 圆。纯态标记的两支箭头是两个单位长的记录态。r_R 落在 r_L 上的影子是 c = cos α，就是条纹对比度 V；r_R 的高是 sin α，就是路径可辨度 D = √(1 − V²)。对这样的纯态记录，Lean 证明了 D² + V² = 1，以及两端：c = 0 时条纹全无、路径全知，V = 1 时路径全无（第 6 章定理 thm-record-coherence-complementarity）。
  2. 屏。忽略标记后，路径的约化态是 ½(1, c; c, 1)。屏上的分布是 env(x)·(1 + c·cos kx)：c 越小，亮纹越矮、暗纹越亮。副对角元 c/2 的平方和 c²/2 就是捏合会去掉的相干质量（Lean 已验证的恒等式）。
  3. 先落点，后读标记。读标记要选一组方向。按路径读（使 r_L、r_R 最好区分的那组方向），纯态标记在 α = 90° 时把每个落点都正确地记作左或右（混合标记则不然：λ = 0.5 时 D = 0.5，只有 75% 读对），两行都没有条纹；按擦除方向读（r_L 与 r_R 的角平分线及其垂线），两行分别是条纹与错开半格的反条纹。无论怎样读，两行合起来就是上面那片落点：屏上的分布不因后来的选择而改变。
  4. 混合的标记。标记本身带噪声（纯态权重 λ < 1，纯度 (1 + λ²)/2 < 1）时，条纹对比度仍是 cos α，能读出的可辨度却只有 λ·sin α，于是 D² + V² = 1 − (1 − λ²)·sin²α：α > 0 时点落进圆内，α = 0 时标记什么也没记下，点仍在圆上；内弧 (cos α, λ·sin α) 从 (1, 0) 出发。例如 α = 60°、λ = 0.5 时是 0.4375 < 1。所引的冻结定理假设两支记录是归一化的纯态向量；混合标记在 α = 0 时取等，是本页数值模型里的等式，不是那条纯态记录定理的应用。以迹距离定义可辨度时 D² + V² ≤ 1 是 Englert 1996 的文献结果，未在本书形式化。

A particle passes the double slit, and a marker behind the slits writes down which way it went: the left slit writes r_L, the right slit r_R. The screen is on the left, the two marker arrows on the right. Drag the angle α between them: the fringe contrast and the path distinguishability trade places, and for a pure marker the point stays on the circle. The page is a numerical illustration, not a proof.

  1. The circle. For a pure marker the two arrows are two record states of unit length. The shadow of r_R on r_L is c = cos α, the fringe contrast V; the height of r_R is sin α, the path distinguishability D = √(1 − V²). For such pure records Lean proves D² + V² = 1 and both ends: with c = 0 the fringes are gone and the path is known, with V = 1 the path is unknown (theorem thm-record-coherence-complementarity of chapter 6).
  2. The screen. Once the marker is ignored, the reduced path state is ½(1, c; c, 1). The screen shows env(x)·(1 + c·cos kx): the smaller c, the lower the bright fringes and the brighter the dark ones. The squares of the off-diagonal entries c/2 add up to c²/2, the coherence mass that pinching removes (a Lean-verified identity).
  3. Hits first, reading later. Reading the marker means choosing a pair of directions. Read for the path (the pair that tells r_L from r_R best) and, for a pure marker at α = 90°, every hit is recorded correctly as left or right (not so for a mixed marker: at λ = 0.5, D = 0.5 and only 75% are read correctly), and neither row shows fringes; read to erase (the bisector of r_L and r_R and its perpendicular) and the rows show fringes and anti-fringes shifted by half a period. However the marker is read, the two rows together are the hits above: the screen does not change with the later choice.
  4. A mixed marker. When the marker itself is noisy (pure-state weight λ < 1, purity (1 + λ²)/2 < 1), the fringe contrast is still cos α but the readable distinguishability is only λ·sin α, so D² + V² = 1 − (1 − λ²)·sin²α: for α > 0 the point falls inside the circle, while at α = 0 the marker records nothing and the point stays on it; the inner arc (cos α, λ·sin α) starts at (1, 0). At α = 60° and λ = 0.5, for example, it is 0.4375 < 1. The cited frozen theorem assumes normalized pure record vectors; the equality of a mixed marker at α = 0 is an equality of this page's numerical model, not an application of that pure-record theorem. With the distinguishability defined by the trace distance, D² + V² ≤ 1 is a literature result of Englert (1996), not formalized in this book.
