理论接口 · 公平、平方、相位、不确定与扩维Theory interface · fairness, squaring, phase, uncertainty and expansion

六张实验卡沿同一条线索走：读数只看影子时，高度与相位都被折进去；两两公平的比较只剩平方，平方和守住 1；平方抹掉的相位与不可交换的面积一起撑起不确定度；有限盒子会被填满，要再看见什么，就要在盒外立起新的正交轴。本页是交互数值演示，不是证明；每个舞台只为它自己算出的数负责。

  1. 开口螺旋与闭合影子。h(t) = (cos t, sin t, c·t) 的平面投影每 2π 重复（手工推导）。黄金螺旋 (n, s, o) ↦ (n + 1, s + T, ¬o) 是它的离散版本：整数傅里叶读数 exp(2πi·m·s/T) 走一步不变（LEAN ✓ golden_helix_fourier_readout_step），加上层 n 就分辨得出每一步（LEAN ✓ level_fourier_joint_readout_detects_step）。层不等于物理时间，这一读法是诠释模型。
  2. 截断视界。递增子空间上的投影对每个固定向量收敛（LEAN ✓ increasing_projection_strong_limit），而每个真子空间都有 ‖I − P‖ = 1（LEAN ✓ uniform_completion_obstruction）：强收敛与按算子范数一致收敛是两回事。θ = 90° 时单位向量在 VD 上的影子 cos θ 为 0，这是一个读数的消失，不是物理世界的边界。
  3. 公平与平方。一次方 |cos θ| + |sin θ| 随所选的轴在 1 与 √2 之间变化；平方和 cos²θ + sin²θ = 1 与 (AB)(BA) = (A·B)² + ‖A∧B‖² = 1 不随轴与次序变（克利福德包装为手工推导，坐标恒等式见 LEAN ✓ lagrange_gram_identity）。平行四边形律（LEAN ✓ inner_product_norm_parallelogram_law）、秩一模平方归约（LEAN ✓ rank_one_pure_state_modulus_square_reduction）与公共相位多项式定理（LEAN ✓ complete_common_phase_polynomial_theorem）各自只说它们自己的事：互惠本身并不强迫 p = 2。
  4. 平方折叠相位。|+⟩ 与 |−⟩ 在每个对角观测量上读数相同，X 分得开（LEAN ✓ diagonal_prime_observables_cannot_recover_relative_phase）；单位圆上 z ↦ z² 的提升绕一圈停在 −1（LEAN ✓ circle_double_cover_history_lift）。把它读成自旋转 360° 变号是手工特化。
  5. 不确定度。(ΔA)²(ΔB)² = C² + |K|² + G（LEAN ✓ robertson_schrodinger）。在量子比特纯态上，ψ 的正交补只有一维，G = 0，恒等式就是切平面上的拉格朗日恒等式：青色的线 C 与品红的面积 K。这是给定纯态与给定观测量上的等式，不是“只因不知道相位”。
  6. 正交扩维（MODEL）。固定的有限盒子里，可观测克雷洛夫塔严格增长至多 dim V − rank C 次，一旦停住就永远停住（LEAN ✓ observable_krylov_strict_growth_bound、observable_krylov_once_stable_permanently）。补空间非零时，补里有到 V 距离为 1 的单位向量（LEAN ✓ finite_layer_projection_escape）；有限素数表之外总有素因子（LEAN ✓ prime_axis_escape，30031 = 59 × 509 说明它不必是下一个素数）。把 D → D + 1 读成时间，是本书的诠释模型。

The six experiment cards follow one thread: a readout that sees only the shadow folds height and phase into it; a fair pairwise comparison keeps only squares, and the square sum holds at 1; the phase that squaring erases, together with the area of non-commuting observables, holds up the uncertainty; a finite box fills up, and seeing more takes a new orthogonal axis outside it. The page is an interactive numerical illustration, not a proof; each stage answers only for the numbers it computes.

  1. Open helix, closed shadow. The planar projection of h(t) = (cos t, sin t, c·t) repeats every 2π (a hand derivation). The golden helix (n, s, o) ↦ (n + 1, s + T, ¬o) is its discrete version: the integer Fourier readout exp(2πi·m·s/T) is unchanged by a step (LEAN ✓ golden_helix_fourier_readout_step), and with the level n added every step is detected (LEAN ✓ level_fourier_joint_readout_detects_step). The level is not physical time; that reading is an interpretive model.
  2. The truncation horizon. Projections onto increasing subspaces converge on every fixed vector (LEAN ✓ increasing_projection_strong_limit), while every proper subspace has ‖I − P‖ = 1 (LEAN ✓ uniform_completion_obstruction): strong convergence and uniform operator-norm convergence are different things. At θ = 90° the shadow cos θ of a unit vector on VD is 0; that is one readout vanishing, not a boundary of the physical world.
  3. Fairness and squaring. The first-order sum |cos θ| + |sin θ| changes with the chosen axis between 1 and √2; the square sum cos²θ + sin²θ = 1 and (AB)(BA) = (A·B)² + ‖A∧B‖² = 1 change with neither axis nor order (the Clifford packaging is a hand derivation; the coordinate identity is LEAN ✓ lagrange_gram_identity). The parallelogram law (LEAN ✓ inner_product_norm_parallelogram_law), the rank-one modulus-square reduction (LEAN ✓ rank_one_pure_state_modulus_square_reduction) and the common-phase polynomial theorem (LEAN ✓ complete_common_phase_polynomial_theorem) each say only what they say: reciprocity alone does not force p = 2.
  4. Squaring folds phase. |+⟩ and |−⟩ read the same on every diagonal observable, and X tells them apart (LEAN ✓ diagonal_prime_observables_cannot_recover_relative_phase); the lift of one turn through z ↦ z² on the unit circle ends at −1 (LEAN ✓ circle_double_cover_history_lift). Reading it as a spin changing sign under a 360° turn is a hand specialization.
  5. Uncertainty. (ΔA)²(ΔB)² = C² + |K|² + G (LEAN ✓ robertson_schrodinger). On a pure qubit state the orthogonal complement of ψ is one-dimensional, G = 0, and the identity is the Lagrange identity on the tangent plane: the cyan line C and the magenta area K. It is an equality for a given pure state and given observables, not "only ignorance of phase".
  6. Orthogonal expansion (MODEL). In a fixed finite box the observable Krylov tower grows strictly at most dim V − rank C times and, once it stops, stops for good (LEAN ✓ observable_krylov_strict_growth_bound, observable_krylov_once_stable_permanently). When the complement is nonzero it holds a unit vector at distance 1 from V (LEAN ✓ finite_layer_projection_escape); outside any finite list of primes there is a prime factor (LEAN ✓ prime_axis_escape; 30031 = 59 × 509 shows it need not be the next prime). Reading D → D + 1 as time is the book's interpretive model.
