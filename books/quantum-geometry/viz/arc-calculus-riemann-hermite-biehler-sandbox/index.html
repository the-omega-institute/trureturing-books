这是数值沙盘，不是证明，更不是黎曼猜想的证明。页面算的是一个只含前十二个零点的模型 ξmodel；它的零点是放在临界线上的，所以 Δ > 0、核半正定与 N = 0 在模型里成立是这个选择的结果。对真正的 ξ，核正定就是黎曼猜想本身（OPEN）。每个数都由页面当场算出（NUM），Lean 定理只在依据栏写明的那一个实例上演示，文献结果标 ARGUED，诠释与画法标 MODEL。

  2. 矢高相变。每个素数是一枚模长 p−σ 的旋子，它的矢高 1 − cos p−σ = ½p−2σ + O(p−4σ)。σ > ½ 时 Σp−2σ 收敛，栅栏贴到虚线极限；σ = ½ 时由梅滕斯第二定理 Σsag = ½ ln ln Pε + Csag + O(1/ln Pε)，Csag = 0.1121458，Pε = e1/ε 时就是 −½ ln ε + Csag → ∞。这只说明 σ = ½ 是矢高总和开始发散的位置，并不推出零点在那里。
  3. 双壳与核。Eε = ξ + (ε/2)ξ′，对合 Eε#(s) = Eε(1 − s) = ξ − (ε/2)ξ′（全纯，不是 Eε(1 − s̄)）。ΔεHB = |Eε(½ + u + it)|² − |Eε(½ − u + it)|² = 2ε Re(ξ̄ξ′) = ε ∂u|ξ|²。核 K(w, s) = (ξ′(s)ξ̄(w) + ξ(s)ξ̄′(w))/(2[(s − ½) + (w̄ − ½)]) 与 ε 无关，对角线上 ΔεHB = 4uεK(s, s)。模型的零点都在临界线上时 Re(ξ′/ξ) = Σ u/|z − iγ|² > 0，Δ > 0，核半正定；离轴四元组在 t = γ₀ 处给出 (u² − δ²)² 形的双阱，0 < u < δ 上 Δ < 0。
  4. 有限网格斯托克斯。检验框 [½ + u₀, ½ + 0.42] × [12, 34.5] 切成 nu × nt 胞。每条棱的相位 φ(e) 只算一次，反方向取 −φ(e)，内棱两两相消恰为 0，胞和等于外边界和，N(∂R) = (1/2π) Σ∂R φ 是框内零点数，网格多粗都一样。u₀ < 0 时 N = 5；u₀ > 0 且 δ = 0 时 N = 0；δ > u₀ > 0 时 N = 1。
  5. 乘性层与桥。FL = ½∏k≤L，每乘一层 M，KMξ = (M ⊗ M̄)∘Kξ + (ξ ⊗ ξ̄)∘KM：两项都是舒尔乘积，KM 半正定的层保持正性。临界线因子层都满足；离轴四元组那层的 KM 不定。分块舒尔补：K ⪰ 0 当且仅当枢轴块 C ≻ 0 且舒尔补 S ⪰ 0（C 可逆时）。真正的 ξ 不是有限乘积；对它证明正性就是桥接引理（OPEN）。Conrey–Li（2000）说明 de Branges 的一条正性充分条件对 ξ 不成立。

书中：§31.3 极小圆弧体微积分切入黎曼猜想 · 开放问题 prob-ch34-schur-hb-kernel-positivity-bridge

This is a numerical sandbox, not a proof, and certainly not a proof of the Riemann hypothesis. The page computes a model ξmodel with the first twelve zeros only; its zeros are placed on the critical line, so Δ > 0, the positive kernel and N = 0 hold in the model as a result of that choice. For the true ξ, kernel positivity is the Riemann hypothesis itself (OPEN). Every number is computed on the page (NUM); each Lean theorem is shown only on the one instance named in the evidence panel; literature results are marked ARGUED, readings and drawing choices MODEL.

  1. The terrain. Across u = σ − ½ ∈ [−0.45, 0.45], into the page t ∈ [11.5, 34.8], height the log radial potential L = ln(|ξ|²/W₀(t) + 10−4): dividing each row by |ξ|² at u = 0.45 levels the wings, and every zero reaches the level ln 10−4, so the five canyons γ₁ = 14.1347, γ₂ = 21.0220, γ₃ = 25.0109, γ₄ = 30.4249, γ₅ = 32.9351 are equally deep. Since W₀ depends on t only, ∂uL has the sign of ∂u|ξ|².
  2. The sagitta transition. Each prime is a rotor of modulus p−σ with sagitta 1 − cos p−σ = ½p−2σ + O(p−4σ). For σ > ½, Σp−2σ converges and the fence settles on its dashed limit; at σ = ½ the second theorem of Mertens gives Σsag = ½ ln ln Pε + Csag + O(1/ln Pε), Csag = 0.1121458, which for Pε = e1/ε reads −½ ln ε + Csag → ∞. This only places the onset of divergence at σ = ½; it does not put zeros there.
  3. Shells and kernel. Eε = ξ + (ε/2)ξ′ and the involution Eε#(s) = Eε(1 − s) = ξ − (ε/2)ξ′ (holomorphic, not Eε(1 − s̄)). ΔεHB = |Eε(½ + u + it)|² − |Eε(½ − u + it)|² = 2ε Re(ξ̄ξ′) = ε ∂u|ξ|². The kernel K(w, s) = (ξ′(s)ξ̄(w) + ξ(s)ξ̄′(w))/(2[(s − ½) + (w̄ − ½)]) does not depend on ε, and on the diagonal ΔεHB = 4uεK(s, s). With every zero of the model on the line, Re(ξ′/ξ) = Σ u/|z − iγ|² > 0, so Δ > 0 and the kernel is positive semidefinite; an off-line quartet gives a double well of the shape (u² − δ²)² at t = γ₀, with Δ < 0 on 0 < u < δ.
  4. Finite-mesh Stokes. The box [½ + u₀, ½ + 0.42] × [12, 34.5] is cut into nu × nt cells. Each edge phase φ(e) is computed once and its reverse is −φ(e), so interior arcs cancel in pairs to exactly 0, the cells add up to the rim, and N(∂R) = (1/2π) Σ∂R φ counts the zeros in the box however coarse the mesh. N = 5 for u₀ < 0; N = 0 for u₀ > 0 when δ = 0; N = 1 when δ > u₀ > 0.
  5. Multiplicative layers and the bridge. FL = ½∏k≤L; multiplying in a layer M gives KMξ = (M ⊗ M̄)∘Kξ + (ξ ⊗ ξ̄)∘KM, both Schur products, so a layer with KM positive semidefinite keeps positivity. Every on-line pair layer does; the off-line quartet layer has an indefinite KM. Block Schur complement: K ⪰ 0 exactly when the pivot block C ≻ 0 and the complement S ⪰ 0 (C invertible). The true ξ is not a finite product; proving positivity for it is the bridge lemma (OPEN). Conrey–Li (2000) show that a positivity condition de Branges proposed as sufficient fails for ξ.
