理论接口 · 这个页面在演示什么Theory interface · what this page shows

二维闵可夫斯基时空，事件写成 (t, x)，自然单位 c = 1；舞台上横轴是 x，竖轴是 t，白色的两条线是光锥 t = ±x。页面上的每个数都实时算出；本页是数值演示，不是证明。

  1. 对照。同一个事件 v = (5, 3) 用两种方式变：转动 (t, x) ↦ (t cos s + x sin s, −t sin s + x cos s) 保持 t² + x² = 34，点沿品红的圆走；推动 B(s) 保持 t² − x² = 16，点沿青色的双曲线走。圆会穿过光锥，双曲线 t² − x² = 16 与光锥 t² − x² = 0 没有交点，推不过去。
  2. 推动。B(η) = [[cosh η, −sinh η], [−sinh η, cosh η]]。由 cosh²η − sinh²η = 1，q(Bv) = q(v)，q(t, x) = t² − x²。η = ln 2 时 cosh η = 5/4、sinh η = 3/4，B(5, 3) = (4, 0)（第十七章的例子）。用光锥坐标 u = t + x、u′ = t − x 写，推动只是 u ↦ e−ηu、u′ ↦ eηu′：光锥 u = 0 与 u′ = 0 上的点只在各自的线上伸缩，这就是白色珠子的运动。琥珀色的两根轴是以快度 η 运动的旅行者的 t′、x′ 轴：t′ 沿 (cosh η, sinh η)，x′ 沿 (sinh η, cosh η)（B(−η) 把原来的 t、x 轴送到这里）。η = ln 2 时 t′ 轴穿过 v = (5, 3)，琥珀色的点 Bv = (4, 0) 就是 v 在这位旅行者坐标里的读数。
  3. 比例。kB(η) 也把光锥送回光锥，但 q(kBv) = k² q(v)：琥珀色的点落到 τ = 4k 的双曲线上，t′ 轴上的单位刻度乘上 k 后落在 τ = k 上（q(kBe₀) = k²）。零锥只定下二次型的形状，定不下比例；要回到 q(Bv) = q(v)，还得单独要求 q(Be₀) = 1。
  4. 卡尺。任取空间位移 (0, w)，两条零向量 v± = (±|w|, w) 满足 q(v±) = 0；v+ + v− = 2(0, w)，v+ − v− = 2|w|(1, 0)。冻结引理的证明正是用这两条零向量把 S(0, w) 与时空交叉项夹住。页面只画 q = minkowski 这一个二次型。
  5. 世界线。从 O = (0, 0) 到 P = (10, 0)：静止世界线 τ = √q(10, 0) = 10；经折返点 A 的折线 τ = √q(A) + √q(P − A)，A = (5, 3) 时为 4 + 4 = 8。刻度每隔一个单位固有时一个。时间轴把所有事件一起推动 η：每段的 q 不变，所以两个总数在任何参考系里都是 8 与 10；变的是各段的坐标时间。A 只能在 O 的未来光锥与 P 的过去光锥围成的菱形里；落到菱形边上，那一段沿光锥走，√q = 0。

Two-dimensional Minkowski spacetime with events written (t, x) in natural units c = 1; on the stage x runs across and t up, and the two white lines are the light cone t = ±x. Every number on the page is computed live; the page is a numerical illustration, not a proof.

  1. Compare. One event v = (5, 3) is moved in two ways: the turn (t, x) ↦ (t cos s + x sin s, −t sin s + x cos s) keeps t² + x² = 34 and runs along the magenta circle; the boost B(s) keeps t² − x² = 16 and runs along the cyan hyperbola. The circle crosses the light cone; the hyperbola t² − x² = 16 never meets the cone t² − x² = 0, so it cannot be pushed through it.
  2. Boost. B(η) = [[cosh η, −sinh η], [−sinh η, cosh η]]. Since cosh²η − sinh²η = 1, q(Bv) = q(v) with q(t, x) = t² − x². At η = ln 2, cosh η = 5/4 and sinh η = 3/4, and B(5, 3) = (4, 0) (the example of Chapter 17). In light-cone coordinates u = t + x, u′ = t − x the boost is just u ↦ e−ηu, u′ ↦ eηu′: points of the cone lines u = 0 and u′ = 0 only stretch along their own line, which is how the white beads move. The two amber axes are the t′ and x′ axes of a traveller moving with rapidity η: t′ along (cosh η, sinh η), x′ along (sinh η, cosh η) (B(−η) carries the old t and x axes there). At η = ln 2 the t′ axis runs through v = (5, 3), and the amber point Bv = (4, 0) is v read in this traveller’s coordinates.
  3. Scale. kB(η) also sends the cone to itself, but q(kBv) = k² q(v): the amber point lands on the hyperbola τ = 4k and the unit tick on t′, multiplied by k, on τ = k (q(kBe₀) = k²). The null cone fixes the shape of the quadratic form, not its scale; to get back q(Bv) = q(v) one must ask separately for q(Be₀) = 1.
  4. Caliper. For any spatial displacement (0, w) the null vectors v± = (±|w|, w) have q(v±) = 0, with v+ + v− = 2(0, w) and v+ − v− = 2|w|(1, 0). The proof of the frozen lemma uses exactly these two null vectors to clamp S(0, w) and the time–space cross term. The page draws only the one quadratic form q = minkowski.
  5. Worldlines. From O = (0, 0) to P = (10, 0): the rest worldline has τ = √q(10, 0) = 10; the bent path through the turning point A has τ = √q(A) + √q(P − A), which is 4 + 4 = 8 at A = (5, 3). There is one tick per unit of proper time. The rail boosts every event together by η: each leg keeps its q, so the two totals are 8 and 10 in every frame; what changes is each leg's coordinate time. A must stay in the diamond between the future cone of O and the past cone of P; on its edge that leg runs along the cone and √q = 0.
