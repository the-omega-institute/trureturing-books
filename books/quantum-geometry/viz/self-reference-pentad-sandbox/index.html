这是数值沙盘，不是证明。每个数都由页面当场算出（NUM）；每条 Lean 定理只在依据栏写明的那一个实例上演示。五张卡是同一个方程 x* = F(x*) 的五个实例，按乘子 λ = F′(x*) 从“一步到位”排到“根本没有不动点”。

  1. F₁ 查表。12 个槽排成一圈，每槽存一个指针 p(x)。初始森林里 9 → 6 → 3 → 1 → 0 是一条 4 跳的链，槽 0 的指针指向自己：Lookup(0) = 0，p ≡ *p。时间轴 0–4 让琥珀读头沿链走 4 跳；4–5 对每个槽查一次并做路径压缩，所有指针改指根；5–6 再查一次只要 1 跳。压缩后的表 P 满足 P² = P：再查一次什么也不改，乘子 |λ| = 0。
  2. F₂ 余弦。单位圆躺在水平的盲平面 i 上，竖直的实平面 I 与它交于实轴。圆上一点转过 θ：它在实轴上的影子长 cos θ（青色），它走过的圆弧长 θ（品红；旁边把这段弧拉直成同样长的品红尺）。两者相等的唯一一处是 θ* = 0.7390851332 = 42.35°。实平面 I 上画 y = cos θ 与 y = θ 和从 θ₀ = 0.10 出发的蛛网：乘子 λ = −sin θ* = −0.6736 为负，所以每一步换边、按 0.6736 收缩。cos²θ* = 54.62%，sin²θ* = 45.38%。
  3. F₃ 本征态与信道。H|0⟩ = E₀|0⟩：U(t)|0⟩ = e−iE₀t|0⟩，布洛赫矢量不动，只有紫色相位纤维上的珠子转圈，|λ| = 1。信道 ℰ(ρ) = |λ| UρU† + (1 − |λ|) ρ* 把任意态按 |λ| = 0.65 拉向 ρ*，并绕青色轴转 ω = 45°：品红的横向相干 |ρ₀₁| 按 0.65ⁿ 衰减，ℰ(ρ*) = ρ*。|λ| = 1 时它只转不缩，|λ| = 0 时一步到 ρ*。捏合 𝒫 把相干一步删光，再捏一次不变。
  4. F₄ 15 → 1 蒸馏。[[15, 1, 3]] 码的 15 个比特放在四面体的 4 个顶点、6 条棱中点、4 个面心与体心；4 个检验胞各含 8 个比特，它们的关联矩阵正是 [15, 11, 3] 汉明码的校验矩阵。每个输入 T 门以概率 ε 带一个 Z 错误；校验子为 0 时接受（青色分支），否则丢弃（15 条品红分支，各指向那个单比特错误所在的点）。εout(ε) = (1 + 15(1 − 2ε)⁸ − 15(1 − 2ε)⁷ − (1 − 2ε)¹⁵) / (2(1 + 15(1 − 2ε)⁸))，ε = 0.0500 时 εout = 0.00514（领头项 35ε³ = 0.00438），压低 9.73 倍；斜率 dεout/dε 在 0 处为 0，阈值 εth = 0.1415 以下逐轮立方收缩，以上被推向 0.5。“门序列 = 门本身”在这里是：15 个门组成的电路输出的，仍是一个 T 门。
  5. F₅ 对角线。4 × 4 表 g(a, b) 的每一行是一条目录。读头沿对角线 (a, a) 走，把 g(a, a) 翻转后升到上一层 ℓ + 1：diagonal(¬, g) = 0011 在第 a 个位置与第 a 行不同，所以不是任何一行。¬ 没有不动点（¬b ≠ b），这正是逃逸的原因；换成有不动点的 f = id，对角线 1100 恰好就是第 2 行，被目录收住。
  6. 透镜。“不动点”读法不改任何参数，只把标签换成 x* = F(x*)：F₁ 是 find ∘ find = find（|λ| = 0），F₂ 是 cos（λ = −0.6736），F₃ 是 U 的相位（|λ| = 1）与信道（|λ| = 0.65），F₄ 是 ε ↦ εout（λ = 0，立方），F₅ 是 ¬，没有不动点。

书中：§36.9 五阶自指不动点谱系

This is a numerical sandbox, not a proof. Every number is computed on the page (NUM); each Lean theorem is shown only on the one instance named in the evidence panel. The five cards are five instances of one equation x* = F(x*), ordered by the multiplier λ = F′(x*) from “there in one step” to “no fixed point at all”.

  1. F₁ Lookup. Twelve slots stand in a ring, each holding a pointer p(x). In the initial forest 9 → 6 → 3 → 1 → 0 is a chain of 4 hops, and slot 0 points at itself: Lookup(0) = 0, p ≡ *p. On the rail, 0–4 walks the amber read head 4 hops along the chain; 4–5 looks up every slot once with path compression, so every pointer turns to the root; 5–6 looks up again in 1 hop. The compressed table P satisfies P² = P: another lookup changes nothing, multiplier |λ| = 0.
  2. F₂ Cosine. The unit circle lies in the horizontal blind plane i, and the vertical real plane I meets it along the real axis. Turn a point of the circle by θ: its shadow on the real axis has length cos θ (cyan), and the arc it travelled has length θ (magenta; beside it the same arc straightened into a magenta ruler). The only place where they agree is θ* = 0.7390851332 = 42.35°. The real plane I carries y = cos θ, y = θ and the cobweb from θ₀ = 0.10: the multiplier λ = −sin θ* = −0.6736 is negative, so each step changes side and shrinks by 0.6736. cos²θ* = 54.62%, sin²θ* = 45.38%.
  3. F₃ Eigenstate and channel. H|0⟩ = E₀|0⟩: U(t)|0⟩ = e−iE₀t|0⟩, so the Bloch vector stays put and only the bead on the violet phase fibre turns, |λ| = 1. The channel ℰ(ρ) = |λ| UρU† + (1 − |λ|) ρ* pulls any state towards ρ* by |λ| = 0.65 while turning it by ω = 45° about the cyan axis: the magenta transverse coherence |ρ₀₁| decays as 0.65ⁿ, and ℰ(ρ*) = ρ*. At |λ| = 1 it turns without shrinking; at |λ| = 0 it reaches ρ* in one step. Pinching 𝒫 deletes the coherence in one step, and pinching again changes nothing.
  4. F₄ 15 → 1 distillation. The 15 qubits of the [[15, 1, 3]] code sit at the 4 corners, 6 edge midpoints, 4 face centres and the centre of a tetrahedron; each of the 4 check cells holds 8 qubits, and their incidence matrix is exactly the parity-check matrix of the [15, 11, 3] Hamming code. Each input T gate carries a Z error with probability ε; a zero syndrome is accepted (the cyan branch), anything else is discarded (15 magenta branches, each pointing at the qubit whose single error it reports). εout(ε) = (1 + 15(1 − 2ε)⁸ − 15(1 − 2ε)⁷ − (1 − 2ε)¹⁵) / (2(1 + 15(1 − 2ε)⁸)); at ε = 0.0500, εout = 0.00514 (leading term 35ε³ = 0.00438), a suppression by 9.73; the slope dεout/dε is 0 at 0, and below the threshold εth = 0.1415 each round shrinks the error cubically while above it the error is pushed to 0.5. “A gate sequence equals the gate itself” here means: the circuit of 15 gates outputs again one T gate.
  5. F₅ Diagonal. Each row of the 4 × 4 table g(a, b) is one entry of a listing. The read head walks the diagonal (a, a), negates g(a, a) and lifts it to the level ℓ + 1 above: diagonal(¬, g) = 0011 differs from row a in place a, so it is no row at all. ¬ has no fixed point (¬b ≠ b), and that is why it escapes; with f = id, which has fixed points, the diagonal 1100 is exactly row 2 and the listing catches it.
  6. Lens. The fixed-point reading changes no parameter, only the labels, to x* = F(x*): F₁ is find ∘ find = find (|λ| = 0), F₂ is cos (λ = −0.6736), F₃ is the phase of U (|λ| = 1) and the channel (|λ| = 0.65), F₄ is ε ↦ εout (λ = 0, cubic), and F₅ is ¬, with no fixed point.
