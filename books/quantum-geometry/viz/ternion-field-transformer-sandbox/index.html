这是数值沙盘，不是证明。每个数都由页面当场算出（NUM）；每条 Lean 定理只在依据栏写明的那一个实例上演示，没有实例的写明“页面不演示”；TFT 架构、停机启发式与舞台的造型是本书的读法（MODEL）。球里的点 σ = tan(θ/4)û 是绕 û 转 θ 的转动，球面 ‖σ‖ = 1 是半周折缝，对径点代表同一转动。

  1. 双分母乘法。N = (1 − ‖σA‖²)σB + (1 − ‖σB‖²)σA + 2σA × σB，D₊ = 1 + ‖σA‖²‖σB‖² − 2σA·σB，D₋ = ‖σA + σB‖²；D₊ ≥ D₋ 时取 +N/D₊，否则取 −N/D₋。D₊ + D₋ = (1 + ‖σA‖²)(1 + ‖σB‖²) ≥ 1 与 ‖N‖² = D₊D₋ 给出 max(D₊, D₋) ≥ ½ 与 ‖σA ★ σB‖² = min/max ≤ 1。
  2. 折缝不变的正弦矢。ξ(σ) = 4(1 − ‖σ‖²)σ/(1 + ‖σ‖²)² = sin θ û，在阴影翻转 σ ↦ −σ/‖σ‖² 下不变，在折缝上为零；共形标度 λ = 2/(1 + ‖σ‖²) 在 [1, 2] 内。
  3. 3D-NAPE。γA = (√2 − 1)e₁、γB = (√2 − 1)e₂ 各是 90° 转动，γA ★ γB = (1, 1, 1)/3，γB ★ γA = (1, 1, −1)/3，相对旋子转 120°；同轴的平面转动互相交换，换序差为 0。
  4. 双侧旋子与蝴蝶桥。每座场一对 ℓ、r（6 个实参数），σ ↦ ℓ ★ σ ★ r；K = 2ᵐ 座场经 m 级蝶形配对，每对 3 个参数。K = 1024 时四路投影 24K + 60K、曲率门 6K、定常 3D-NAPE 3K，共 93K = 95,232，对照 12d² = 113,246,208。
  5. 玻恩—流群注意力。b = cos²(Δθ/2)，α = Φ/(ε₀ + ΣΦ)，Φ = bp（页面取 p = 2）；σt←s = σ̃Q ★ ((−σ̃K) ★ σV)，m = (−σt) ★ σt←s，ω = Σα·¼ξ(m)，σmid = σt ★ R(ω)。全失配时 Σα → 0；Softmax 的权重和仍为 1。
  6. 法诺李三元曲率门。{a, b, c} = (a·c)b − (b·c)a，Δ = w₁ × ξ + {ξ, w₂, f}，f = ξ(σ(k+1) ★ σ(k+3))，σout = σmid ★ R(Δ)；步长 r = ‖(−σmid) ★ σout‖ ≤ εself 时停机。ξ = 0 时曲率门关闭。
  7. 双透镜。“旋子几何”读法把舞台读成球里的转动；“Transformer 工程”读法把同一组量读成隐状态、位置编码、Q/K/V、残差与前馈门。两种读法用的是同一组参数。

Every number is computed on the page (NUM); each Lean theorem is shown only on the one instance named in the evidence panel, and where there is none the panel says the page does not show it; the TFT architecture, the halting heuristic and the shapes on the stage are the reading of this book (MODEL). A point σ = tan(θ/4)û of the ball is the rotation by θ about û, the sphere ‖σ‖ = 1 is the half-turn seam, and antipodal points are the same rotation.

  1. The dual-denominator product. N = (1 − ‖σA‖²)σB + (1 − ‖σB‖²)σA + 2σA × σB, D₊ = 1 + ‖σA‖²‖σB‖² − 2σA·σB, D₋ = ‖σA + σB‖²; take +N/D₊ when D₊ ≥ D₋ and −N/D₋ otherwise. D₊ + D₋ = (1 + ‖σA‖²)(1 + ‖σB‖²) ≥ 1 and ‖N‖² = D₊D₋ give max(D₊, D₋) ≥ ½ and ‖σA ★ σB‖² = min/max ≤ 1.
  2. The seam-invariant sine vector. ξ(σ) = 4(1 − ‖σ‖²)σ/(1 + ‖σ‖²)² = sin θ û is unchanged by the shadow flip σ ↦ −σ/‖σ‖² and vanishes on the seam; the conformal scale λ = 2/(1 + ‖σ‖²) stays in [1, 2].
  3. 3D-NAPE. γA = (√2 − 1)e₁ and γB = (√2 − 1)e₂ are 90° turns, γA ★ γB = (1, 1, 1)/3 and γB ★ γA = (1, 1, −1)/3, and the relative rotor turns by 120°; planar turns about one axis commute, and their swap angle is 0.
  4. Bilateral rotors and butterfly bridges. Each field has a pair ℓ, r (6 real parameters), σ ↦ ℓ ★ σ ★ r; K = 2ᵐ fields are paired in m butterfly stages with 3 parameters per pair. At K = 1024 the four projections take 24K + 60K, the curvature gate 6K and the stationary 3D-NAPE 3K, 93K = 95,232 in all, against 12d² = 113,246,208.
  5. Born–Heap attention. b = cos²(Δθ/2), α = Φ/(ε₀ + ΣΦ) with Φ = bp (the page takes p = 2); σt←s = σ̃Q ★ ((−σ̃K) ★ σV), m = (−σt) ★ σt←s, ω = Σα·¼ξ(m) and σmid = σt ★ R(ω). A total mismatch sends Σα to 0; the Softmax weights still add up to 1.
  6. The Fano Lie-triple curvature gate. {a, b, c} = (a·c)b − (b·c)a, Δ = w₁ × ξ + {ξ, w₂, f} with f = ξ(σ(k+1) ★ σ(k+3)), and σout = σmid ★ R(Δ); the layer halts when the step r = ‖(−σmid) ★ σout‖ is at most εself. At ξ = 0 the gate is shut.
  7. Two lenses. The rotor-geometry reading reads the stage as rotations in a ball; the Transformer-engineering reading reads the same quantities as hidden states, position codes, Q/K/V, residuals and a feed-forward gate. Both readings use the same parameters.
