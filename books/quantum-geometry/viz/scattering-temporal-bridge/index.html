理论接口 · 势垒双支与时间双缝Theory interface · barrier branches and the temporal double slit

这是数值演示，不是证明。页面上的每个数都由页面当场算出（NUM）；文献只作为来源列出，页面不复现其中的数据，也不替其中的诠释背书。

  1. 定态势垒。单位 ℏ = 2m = V₀ = 1，势垒占 [0, L]，E ∈ [0.1, 0.9]，k = √E，κ = √(1 − E)。左侧 ψ = eikx + r e−ikx，右侧 ψ = t eikx，势垒里 ψ = t eikL(cosh κ(L − x) − i(k/κ) sinh κ(L − x))。D = cosh κL + i(κ² − k²)/(2kκ) sinh κL，t = e−ikL/D，r = −i(k/κ + κ/k) sinh κL/(2D)。在 x = 0 与 x = L 两处 ψ 与 ψ′ 都连续；页面列出两侧的值。
  2. 两条倏逝支。势垒里 ψ = a₊eκx + a₋e−κx。单独一支的 Im(ψ̄ψ′) 为 0；流 j = 2 Im(ψ̄ψ′) = 4κ Im(ā₋a₊) 只来自两支的交叉项，沿 x 不变，等于右侧的 2kT。T = |t|²，R = |r|²，T + R = 1。e−2κL 只是领头指数，不含前因子：κL 大时 T/e−2κL 趋于 16E(1 − E)，页面把两者并排列出。
  3. 虚的 k。势垒里 eikx 的 k 换成 iκ，这是解析延拓。把它读成“藏起来的 90° 空间转身”是本书的诠释模型，不是任何测量的结果。
  4. 时间双缝。两条时间路径的振幅 z₁ = 1、z₂ = a ei(q+φ)，q = EΔt/ℏ，a ∈ [0, 1.5]；标记重叠 μ = |⟨m₁|m₂⟩| ∈ [0, 1]，其相位并入 φ。对标记求迹后得到的是混合态，探测计数是强度而不是某一个振幅的平方：1 + a² + 2aμ cos(q + φ) = |√μ(z₁ + z₂)|² + (1 − μ)(1 + a²)。前一项是相干合成振幅 √μ(z₁ + z₂)（舞台上紫色的螺旋与箭头）的强度；后一项是按 1 − μ 加权的非相干本底强度，舞台上画成半径平方等于它的紫色环，它不是振幅。页面画的 P(q) = (1 + a² + 2aμ cos(q + φ))/(1 + a²) 是计数除以非相干基线 1 + a² 的相对谱强度：不是概率，也不是对全部能量归一的密度，取值在 0 与 2 之间，只有 a = 1、μ = 1 且 cos(q + φ) = 1 时达到 2。μ = 0 时相干合成振幅为 0，本底强度 (1 − μ)(1 + a²) = 1 + a² 仍为正，P ≡ 1。下限是 (1 + a² − 2aμ)/(1 + a²)；P = 0 当且仅当 a = 1、μ = 1 且 cos(q + φ) = −1。
  5. 相消要求什么。干涉同时取决于相位、两路振幅之比与标记重叠；它不是“探测器把粒子消灭”。没有任何测量表明粒子以负时间穿越；带后选择的原子激发时间的读数依赖测量协议。
  6. 来源。ITO 薄膜中的时间双缝衍射：doi:10.1038/s41567-023-01993-w；阿秒双缝（Lindner 等，2005）：doi:10.1103/PhysRevLett.95.040401；磁振子平台：doi:10.1103/jc1c-k3ll；带后选择的原子激发：doi:10.1103/gjfq-k9dv。

This is a numerical illustration, not a proof. Every number is computed on the page (NUM); the literature is listed as sources only, and the page neither reproduces their data nor endorses their interpretations.

  1. The stationary barrier. Units ℏ = 2m = V₀ = 1, the barrier fills [0, L], E ∈ [0.1, 0.9], k = √E, κ = √(1 − E). On the left ψ = eikx + r e−ikx, on the right ψ = t eikx, inside ψ = t eikL(cosh κ(L − x) − i(k/κ) sinh κ(L − x)). D = cosh κL + i(κ² − k²)/(2kκ) sinh κL, t = e−ikL/D, r = −i(k/κ + κ/k) sinh κL/(2D). Both ψ and ψ′ are continuous at x = 0 and at x = L; the page lists the values on both sides.
  2. Two evanescent branches. Inside, ψ = a₊eκx + a₋e−κx. Each branch alone has Im(ψ̄ψ′) = 0; the flux j = 2 Im(ψ̄ψ′) = 4κ Im(ā₋a₊) comes only from the cross term of the two, does not change along x, and equals 2kT on the right. T = |t|², R = |r|², T + R = 1. e−2κL is the leading exponential only, without its prefactor: for large κL the ratio T/e−2κL tends to 16E(1 − E), and the page lists both side by side.
  3. Imaginary k. Inside the barrier the k of eikx becomes iκ: an analytic continuation. Reading it as a hidden 90° spatial turn is this book's interpretive model, not the result of any measurement.
  4. The temporal double slit. Two temporal path amplitudes z₁ = 1 and z₂ = a ei(q+φ), q = EΔt/ℏ, a ∈ [0, 1.5]; the marker overlap μ = |⟨m₁|m₂⟩| ∈ [0, 1], its phase absorbed into φ. Tracing out the markers leaves a mixed state, and the count is an intensity, not the square of one amplitude: 1 + a² + 2aμ cos(q + φ) = |√μ(z₁ + z₂)|² + (1 − μ)(1 + a²). The first term is the intensity of the coherent resultant amplitude √μ(z₁ + z₂) (the violet helix and arrow on the stage); the second is the incoherent background intensity weighted by 1 − μ, drawn as a violet ring whose squared radius equals it, and it is not an amplitude. The P(q) = (1 + a² + 2aμ cos(q + φ))/(1 + a²) on the page is the count divided by the incoherent baseline 1 + a², a relative spectral intensity: not a probability and not a density normalised over all energies; it lies between 0 and 2 and reaches 2 only at a = 1, μ = 1 and cos(q + φ) = 1. At μ = 0 the coherent amplitude is 0, the background intensity (1 − μ)(1 + a²) = 1 + a² stays positive and P ≡ 1. The floor is (1 + a² − 2aμ)/(1 + a²); P = 0 exactly when a = 1, μ = 1 and cos(q + φ) = −1.
  5. What cancellation needs. Interference depends on the phase, on the ratio of the two amplitudes and on the marker overlap together; it is not a detector annihilating the particle. No measurement shows a particle traversing in negative time; the reading of an atomic excitation time under postselection depends on the measurement protocol.
  6. Sources. Double-slit time diffraction in an ITO film: doi:10.1038/s41567-023-01993-w; the attosecond double slit (Lindner et al., 2005): doi:10.1103/PhysRevLett.95.040401; a magnon platform: doi:10.1103/jc1c-k3ll; atomic excitation with postselection: doi:10.1103/gjfq-k9dv.
