这是数值演示，不是证明。页面上的每个数都当场算出（NUM）；七条 Lean 定理各自只在下面写明的那个实例上演示，作者关于自由意志与时间之河的读法是诠释，不是定理。

  1. 自定精度停机。x0 = 0，xk = cos xk−1。观察者在第一次出现 |xk − xk−1| = |cos xk−1 − xk−1| ≤ ε 的那一步停下，等价于 xk−1 进入残差帽 {x : |cos x − x| ≤ ε}。ε = 0.150 时帽是 [0.6475, 0.8271]，x4 = 0.6543 是第一个落进帽里的点，第 5 步 |x5 − x4| = 0.1392 停机，留下 x5 = 0.7935，余差 |x5 − θ*| = 0.0544 折进不再走的螺旋。ε → 0 时帽缩成 θ*，停机步数无界增长；ε = 1 时 x0 已在帽里，第一次检查就停，没有任何细化，输出只是噪声。
  2. 正交折叠。六个模的振幅取 σ = (1.00, 0.76, 0.54, 0.35, 0.20, 0.10) 归一化，玻恩权重 w = (0.4898, 0.2829, 0.1428, 0.0600, 0.0196, 0.0049)。ε = 0.100 时前三个立在 I 墙上，后三个绕铰链 î 转 90° 躺进河里：0.9155 + 0.0845 = 1。下游每走一步浮出一份折入的模（从重到轻），θ* = 0.7390851332… 的尾数 0.0000851332… 也每步浮出一位；任何时刻两份之和都是 1。铰链 î = [[0, −1], [1, 0]] 满足 î² = −1。
  3. 幂迭代排序。G = diag(σ)，迭代 Gⁿ 后第 m 模相对第一模是 (σm/σ1)ⁿ。n = 4、ε = 0.120 时只有前两模过线（1 与 0.3336），G⁴ 的前两模平方份额 (1⁸ + 0.76⁸)/Σσm⁸ = 99.33%，而 G 本身的秩 2 能量 (1² + 0.76²)/Σσm² = 77.27%；按 Eckart–Young，相对截断误差平方分别是 0.67% 与 22.73%。读 b = (1, …, 1)/√6 的克雷洛夫塔维数 1, 2, 3, 4, 5, 6 之后不再增长。
  4. 换基即换序。ψ = (1, 2, 5)/√30。B(α) 是从位置基（α = 0°）到 DCT-II 频率基（α = 90°）的最短转动，wB(k) = ⟨bk|ρ|bk⟩ = cos²θk，三者之和恒为 1。位置基里排序是 0.8333、0.1333、0.0333，频率基里倒过来是 0.7111、0.2667、0.0222；α = 65° 时是 0.6273、0.2525、0.1202，ε = 0.150 时前两个过线。
  5. 频闪雕基。不看时态在 ΩT = π/2 内从 |0⟩ 转到赤道，留在 |0⟩ 的概率 cos²(π/4) = 0.5000。均匀检查 N 次，每次只转 π/(4N)，留下的概率每次乘 cos²(π/(4N))；N = 16 时 [cos²(π/64)]¹⁶ = 0.9622，每次的横向漏失 sin²(π/64) = 0.0024，是步长的平方阶。

This is a numerical illustration, not a proof. Every number on the page is computed on the spot (NUM); each of the seven Lean theorems is shown only on the instance written below, and the reading of free will and of the river of time by the author is an interpretation, not a theorem.

  1. Halting at a self-chosen precision. x0 = 0, xk = cos xk−1. The observer stops at the first step with |xk − xk−1| = |cos xk−1 − xk−1| ≤ ε, that is, once xk−1 enters the residual cap {x : |cos x − x| ≤ ε}. For ε = 0.150 the cap is [0.6475, 0.8271]; x4 = 0.6543 is the first point inside it, step 5 halts with |x5 − x4| = 0.1392 and keeps x5 = 0.7935, and the residual |x5 − θ*| = 0.0544 is folded into the spiral that is no longer walked. As ε → 0 the cap shrinks to θ* and the halting step grows without bound; at ε = 1 the start x0 is already inside the cap, the first check stops the iteration, nothing is refined and the output is noise.
  2. The orthogonal fold. The six mode amplitudes are σ = (1.00, 0.76, 0.54, 0.35, 0.20, 0.10) normalized, with Born weights w = (0.4898, 0.2829, 0.1428, 0.0600, 0.0196, 0.0049). At ε = 0.100 the first three stand on the wall I and the last three turn 90° about the hinge î and lie in the river: 0.9155 + 0.0845 = 1. Each step downstream one folded mode surfaces (heaviest first), and so does one digit of the tail 0.0000851332… of θ* = 0.7390851332…; at every moment the two parts add up to 1. The hinge î = [[0, −1], [1, 0]] satisfies î² = −1.
  3. Power iteration sorts. G = diag(σ); after Gⁿ the m-th mode stands to the first as (σm/σ1)ⁿ. At n = 4 and ε = 0.120 only the first two modes clear the line (1 and 0.3336); the squared share of the first two modes of G⁴, (1⁸ + 0.76⁸)/Σσm⁸, is 99.33%, against the rank-2 energy of G itself, (1² + 0.76²)/Σσm² = 77.27%; by Eckart–Young the relative squared truncation errors are 0.67% and 22.73%. The Krylov tower read through b = (1, …, 1)/√6 has dimensions 1, 2, 3, 4, 5, 6 and then grows no more.
  4. A new basis, a new order. ψ = (1, 2, 5)/√30. B(α) is the shortest turn from the position basis (α = 0°) to the DCT-II frequency basis (α = 90°); wB(k) = ⟨bk|ρ|bk⟩ = cos²θk, and the three always add up to 1. In the position basis the order is 0.8333, 0.1333, 0.0333; in the frequency basis it is reversed, 0.7111, 0.2667, 0.0222; at α = 65° it is 0.6273, 0.2525, 0.1202, and at ε = 0.150 the first two clear the line.
  5. Strobe sculpting. Unwatched, the state turns from |0⟩ to the equator within ΩT = π/2 and stays in |0⟩ with probability cos²(π/4) = 0.5000. With N evenly spaced checks it turns only π/(4N) between them, and each check multiplies the staying probability by cos²(π/(4N)); for N = 16, [cos²(π/64)]¹⁶ = 0.9622, and the sideways leak at each check, sin²(π/64) = 0.0024, is of the order of the square of the step.
