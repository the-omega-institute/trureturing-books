克利福德几何积将参考测量轴 A = ẑ 与单比特布洛赫态向量 B(θ, φ) 的关系缝合为同一个代数方程 AB = A·B + A∧B：标量内积 A·B = cos θ 给出粒子投影的确定性，二向量外积 A∧B = sin θ I 给出横向相干与量子门旋转的平行四边形面积。本页是数值演示，不是证明。

线路顺序：态制备 |ψ⟩（滑块 θ, φ 与预设）→ 单比特旋转器门 U(α) = exp(−iα n̂·σ/2)（门带，至多差一个全局相位）→ 门后纯态 ρ₀ = |ψ(θ,φ)⟩⟨ψ(θ,φ)| = B(θ, φ)（每施加一个门，滑块 θ, φ 即同步为 ρ₀ 的坐标）→ 固定 z 轴退相干信道 E_η → ρ(η) = E_η(ρ₀)。简写为 |ψ⟩ → U(α) → ρ₀(θ,φ) → E_η → ρ(η)。

  1. 几何积与勾股守恒（第六章 §6.1–§6.2）。极角滑块 θ ∈ [0°, 180°] 与方位角滑块 φ ∈ [0°, 360°] 控制单位向量 B(θ, φ)。内积线长度 cos θ 与外积面积 ‖A∧B‖ = sin θ 恒满足 cos²θ + sin²θ = 1，对应冻结定理 lagrange_gram_identity（LEAN ✓）。
  2. 线路第 2 步 · 单比特旋转器门 U(α)（第五章 §5.2–§5.4）。按钮 I, X, Y, Z, H, S, T 各自施加一个旋转器门 U(α) = exp(−iα n̂·σ/2)（至多差一个全局相位）：X、Y、Z 分别绕 x̂、ŷ、ẑ 转 α = π，H 绕 (x̂ + ẑ)/√2 转 α = π，S、T 绕 ẑ 分别转 α = π/2、π/4，I 即 α = 0。这里的 α 是门的转角，与第 3 项的环境记录重叠角滑块 α 无关。门作用在当前布洛赫向量上，输出门后纯态 ρ₀ = B(θ, φ)，并按时间先后记入“线路顺序”带；例如从 |0⟩（θ = 0°）点击 H 立即得到赤道叠加态 ρ₀ = |+⟩⟨+|（θ = 90°, φ = 0°）。
  3. 环境记录互补圆 D² + V² = 1（第六章 §6.3）。滑块 α ∈ [0°, 90°] 设定双路径干涉仪中左右环境记录态的夹角，决定记录重叠 c = cos α、干涉条纹可见度 V = |cos α| 与路径可区分度 D = √(1 − V²) = sin α，对应冻结定理 pure_record_distinguishability_coherence_complementarity（LEAN ✓）。
  4. 线路第 3 步 · 保单位捏合退相干 ≠ 非保单位兰道尔重置（第六章 §6.3、第八章 §8.2）。滑块 η ∈ [0, 1] 控制固定 z 轴退相干信道 E_η(ρ) = (1−η)ρ + ηΠ(ρ)，其中 Π(ρ) = diag(ρ₀₀, ρ₁₁) 是计算基捏合。它把门后纯态 ρ₀ 的布洛赫向量阻尼为 r(η) = ((1−η)sin θ cos φ, (1−η)sin θ sin φ, cos θ)，得到当前态 ρ(η) = E_η(ρ₀)；z 分量不动，所以 Π(ρ(η)) = Π(ρ₀) = diag(p₀, p₁)，p₀ = cos²(θ/2)。下面两种过程必须分开：
    • (a) 保单位退相干 / 捏合。例如 |+⟩⟨+| → I/2（θ = 90°，η = 1，此时 E_1 = Π）。Π 与 E_η 都是保单位信道：Π(I/2) = E_η(I/2) = I/2。相位相干泄入环境记录，系统冯·诺依曼熵从 S(ρ₀) = 0 升到 S(Π(ρ₀)) = H₂(cos²(θ/2)) ≤ ln 2，增量为 ΔS_pinch = D(ρ ‖ Π(ρ)) = S(Π(ρ)) − S(ρ) ≥ 0（取 ρ = ρ₀）。取输入 ρ = |ψ⟩⟨ψ|、U 为门带，则 UρU* = ρ₀，该恒等式即 entropy_production_coherence_deletion_identity（LEAN ✓）。当前态的希尔伯特—施密特正交分解 ⟨ρ(η),ρ(η)⟩ = ⟨Π(ρ₀),Π(ρ₀)⟩ + (|ρ₀₁(η)|²+|ρ₁₀(η)|²) 对应 pinching_hilbert_schmidt_pythagorean（LEAN ✓）。读数“当前态剩余相对熵相干”D(ρ(η) ‖ Π(ρ₀)) = S(Π(ρ₀)) − S(ρ(η)) 是同一恒等式取 U = I、ρ = ρ(η)，再用 Π(ρ(η)) = Π(ρ₀) 得到的：η = 0 时等于预算 S(Π(ρ₀))，η = 1 时降为 0。
    • (b) 逻辑重置 / 擦除。I/2 → |0⟩⟨0|。这是非保单位信道：它把整个布洛赫球压到北极，压缩系统态空间，ΔS_sys = −ln 2 < 0。按兰道尔原理，它必须向温度为 T 的热库耗散至少 k_B T ln 2 的热量（文献结果，未在本书形式化）。
    本页的 η 滑块只实现 (a)：“正交捏合退相干 (ln 2)”预设显示的是系统熵增 ln 2，不是擦除所需的放热。
  5. 模型边界。页面在双精度浮点下计算三维正交投影、二元熵与柱状账单，旋转器按钮将角度取整到度以便与滑块同步；页面只含保单位信道 E_η，不含任何非保单位重置信道。形式化定理本身在 Lean 4 中对任意精度实数与复矩阵严格成立。

Clifford's geometric product unifies the reference measurement axis A = ẑ and the qubit Bloch vector B(θ, φ) into a single algebraic identity AB = A·B + A∧B: the scalar inner product A·B = cos θ measures collinear particle certainty, while the exterior bivector A∧B = sin θ I measures the transverse wave parallelogram area that generates quantum gate rotations. The page is a numerical illustration, not a proof.

Circuit order: state preparation |ψ⟩ (sliders θ, φ and presets) → single-qubit rotor gate U(α) = exp(−iα n̂·σ/2) (the gate tape, up to a global phase) → post-gate pure state ρ₀ = |ψ(θ,φ)⟩⟨ψ(θ,φ)| = B(θ, φ) (after each gate the θ, φ sliders jump to the coordinates of ρ₀) → fixed-z dephasing channel E_η → ρ(η) = E_η(ρ₀). In short: |ψ⟩ → U(α) → ρ₀(θ,φ) → E_η → ρ(η).

  1. Geometric product & Pythagorean conservation (Chapter 6 §6.1–§6.2). The polar slider θ ∈ [0°, 180°] and azimuthal slider φ ∈ [0°, 360°] steer the unit Bloch vector B(θ, φ). The collinear projection cos θ and bivector wedge norm ‖A∧B‖ = sin θ satisfy cos²θ + sin²θ = 1, corresponding to lagrange_gram_identity (LEAN ✓).
  2. Circuit step 2 · single-qubit rotor gate U(α) (Chapter 5 §5.2–§5.4). Each button I, X, Y, Z, H, S, T applies one rotor gate U(α) = exp(−iα n̂·σ/2) (up to a global phase): X, Y, Z rotate by α = π about x̂, ŷ, ẑ; H rotates by α = π about (x̂ + ẑ)/√2; S and T rotate about ẑ by α = π/2 and π/4; I is α = 0. Here α is the gate's rotation angle, unrelated to the record overlap slider α of item 3. The gate acts on the current Bloch vector, outputs the post-gate pure state ρ₀ = B(θ, φ), and is logged in time order on the “Circuit order” tape; for instance, applying H to |0⟩ (θ = 0°) gives the equatorial superposition ρ₀ = |+⟩⟨+| (θ = 90°, φ = 0°).
  3. Environmental record complementarity circle D² + V² = 1 (Chapter 6 §6.3). The slider α ∈ [0°, 90°] sets the angle between left and right environmental record states in a two-path interferometer, determining the overlap c = cos α, fringe visibility V = |cos α|, and path distinguishability D = √(1 − V²) = sin α, verified in pure_record_distinguishability_coherence_complementarity (LEAN ✓).
  4. Circuit step 3 · unital pinching dephasing ≠ non-unital Landauer reset (Chapter 6 §6.3, Chapter 8 §8.2). The slider η ∈ [0, 1] sets the fixed-z dephasing channel E_η(ρ) = (1−η)ρ + ηΠ(ρ), where Π(ρ) = diag(ρ₀₀, ρ₁₁) is the computational-basis pinching. It damps the Bloch vector of the post-gate pure state ρ₀ to r(η) = ((1−η)sin θ cos φ, (1−η)sin θ sin φ, cos θ), giving the current state ρ(η) = E_η(ρ₀); the z component is untouched, so Π(ρ(η)) = Π(ρ₀) = diag(p₀, p₁) with p₀ = cos²(θ/2). Two different processes must be kept apart:
    • (a) Unital dephasing / pinching. For example |+⟩⟨+| → I/2 (θ = 90°, η = 1, where E_1 = Π). Both Π and E_η are unital channels: Π(I/2) = E_η(I/2) = I/2. Phase coherence leaks into environmental records and the system's von Neumann entropy rises from S(ρ₀) = 0 to S(Π(ρ₀)) = H₂(cos²(θ/2)) ≤ ln 2; the increase is ΔS_pinch = D(ρ ‖ Π(ρ)) = S(Π(ρ)) − S(ρ) ≥ 0 (with ρ = ρ₀). Taking the input ρ = |ψ⟩⟨ψ| and U the gate tape gives UρU* = ρ₀, and the identity is entropy_production_coherence_deletion_identity (LEAN ✓). The current-state Hilbert–Schmidt split ⟨ρ(η),ρ(η)⟩ = ⟨Π(ρ₀),Π(ρ₀)⟩ + (|ρ₀₁(η)|²+|ρ₁₀(η)|²) is pinching_hilbert_schmidt_pythagorean (LEAN ✓). The readout “current-state remaining coherence” D(ρ(η) ‖ Π(ρ₀)) = S(Π(ρ₀)) − S(ρ(η)) is the same identity with U = I and ρ = ρ(η), combined with Π(ρ(η)) = Π(ρ₀): it equals the budget S(Π(ρ₀)) at η = 0 and falls to 0 at η = 1.
    • (b) Logical reset / erasure. I/2 → |0⟩⟨0|. This channel is non-unital: it squeezes the whole Bloch ball onto the north pole and compresses the system's state space, ΔS_sys = −ln 2 < 0. By Landauer's principle it must dissipate at least k_B T ln 2 of heat into a thermal reservoir at temperature T (literature result, not formalized in this book).
    The η slider implements only (a): the “Full Pinching Dephasing (ln 2)” preset shows a system entropy increase of ln 2, not the heat that erasure costs.
  5. Model limits. The page evaluates orthographic 3D projections, binary entropies, and bar ledgers in double-precision floating point and rounds rotor gate outputs to integer degrees to stay synchronized with the sliders; the page contains only the unital channel E_η and no non-unital reset channel. The Lean 4 theorems hold exactly over ℝ and ℂ.
