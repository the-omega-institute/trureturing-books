ARGUED文献结果，未在本书形式化：操作系统的递归页表自映射（如 x86-64 四级分页，Intel SDM 卷 3A 第 4 章）——顶层页目录的某个槽写入页目录自己的物理基址，经过这个槽一次就回环一层。页面照第三十八章的二级算例取 N = 4、b₀ = 0x1000、T₁ = 0x2000、D₁,₂ = 0x9000；其余地址是为补全表格而选的。Literature result, not formalized in this book: recursive self-mapping of operating-system page tables (e.g. x86-64 four-level paging, Intel SDM Vol. 3A, Ch. 4): one slot of the top-level directory holds the directory’s own physical base, and each pass through that slot loops back one level. The page follows Chapter 38’s two-level example with N = 4, b₀ = 0x1000, T₁ = 0x2000, D₁,₂ = 0x9000; the other addresses are chosen to fill in the tables.
MODEL把观察者读成宇宙本体内存的一枚记忆指针、把零号槽的 p = *p 读成“拆去总线隔墙的本体寻址”，是本书的诠释模型；“一拍走一层”的时间轴也是为画面选的。零号槽一步回到自己，只因为那一格里写的正是它自己的地址；页面不声称这是一种可实现的算法加速：读任何别的地址，仍要走完各级。Reading the observer as a memory pointer into the universe’s ontological memory, and slot 0’s p = *p as “ontological addressing with the bus wall torn down”, is this book’s interpretive model; the rail’s “one level per tick” is chosen for the picture. Slot 0 returns to itself in one step only because that cell holds its own address; the page does not claim this is a realizable algorithmic speed-up: reading any other address still takes every level.

理论接口 · 这个页面在演示什么Theory interface · what this page shows

同一条时间轴上并排走三种寻址：在 N = 64 格内存里逐格扫描，最坏要 N = 64 步；桶链式路由树深 log₂N = 6 层，共 N − 1 = 63 个开关，一个地址只拨动根到叶路上的 6 个；页目录的零号槽写着页目录自己的地址，读一次就回到自己。本页是计数与查表的演示，不是证明。

  1. 依据的章节。第三十八章 · 宇宙本体 QRAM、观察者记忆指针与递归自映射页表，特别是注记 rem-ch38-qram-page-wootters-literature（桶链式 QRAM）、例 ex-ch38-recursive-page-table-dereference（二级页表步进算例）与定理 thm-ch38-self-mapped-diagonal-fixed-point 第 1 款。
  2. 三条路怎么数。扫描：读头一拍读一格，地址 a 是第 a + 1 格，恰在第 a + 1 拍读到。路由树：开关按“层 ℓ、前缀”编号，地址 a 的第 ℓ 层开关是 a 的前 ℓ 位所指的那一个，按第 ℓ + 1 位拨向左（0）或右（1）；一拍拨一层，6 拍到叶子。叠加地址的几条分支在相同前缀上共用开关，一旦有一位不同就分开，以后不再共用。页表：Walk(b, [i₁, …, i_L]) 一跳读 Mem[b][i₁]，以读出的地址为下一跳的基址。
  3. 已验证的定理。页表场景里只有一条：对角线落点不动点 diagonal_landing_fixed（LEAN ✓）。页面画出的“f = 读零号槽，f(0x1000) = 0x1000”是它的一个具体形状，把这一格读成 p = *p 的本体寻址是本章的诠释（MODEL）。
  4. 不在 Lean 里的。桶链式 QRAM 的 O(log N) 路由深度（Giovannetti–Lloyd–Maccone 2008）与 x86-64 递归页表自映射是文献结果与工程事实（ARGUED）。“观察者是宇宙记忆指针”“拆去总线隔墙的 p ≡ *p”是本书的诠释模型（MODEL）。页面不声称 O(1) 的“本体寻址”是可实现的算法加速：只有写着自己地址的那一格一步就回到自己。

Three ways of addressing run side by side on one rail: scanning N = 64 memory cells one by one takes up to N = 64 steps; the bucket-brigade routing tree is log₂N = 6 levels deep with N − 1 = 63 switches, and one address sets only the 6 on its root-to-leaf path; slot 0 of the page directory holds the directory’s own address, so one read lands back on itself. The page is a demonstration of counting and lookup, not a proof.

  1. The chapter behind it. Chapter 38 · Ontological QRAM, the observer memory pointer, and recursive self-mapped page tables, in particular the note rem-ch38-qram-page-wootters-literature (bucket-brigade QRAM), the example ex-ch38-recursive-page-table-dereference (the two-level walk) and item 1 of the theorem thm-ch38-self-mapped-diagonal-fixed-point.
  2. How the three are counted. Scan: the head reads one cell per tick; address a is cell a + 1 and is read at exactly tick a + 1. Tree: switches are numbered by level ℓ and prefix; the level-ℓ switch of address a is the one named by the first ℓ bits of a, and it turns left (0) or right (1) by bit ℓ + 1; one level per tick, the leaf at tick 6. The branches of a superposed address share switches while their prefixes agree, part at the first differing bit, and never share again. Page table: Walk(b, [i₁, …, i_L]) reads Mem[b][i₁] in one hop and uses the address read as the base of the next hop.
  3. Verified theorems. One, in the page-table scene: the diagonal landing fixed point diagonal_landing_fixed (LEAN ✓). The page’s “f = read slot 0, f(0x1000) = 0x1000” is one concrete shape of it; reading that cell as the ontological addressing p = *p is the chapter’s interpretation (MODEL).
  4. Not in Lean. The O(log N) routing depth of bucket-brigade QRAM (Giovannetti–Lloyd–Maccone 2008) and x86-64 recursive page-table self-mapping are literature results and engineering facts (ARGUED). “The observer is a memory pointer of the universe” and “p ≡ *p with the bus wall torn down” are this book’s interpretive model (MODEL). The page does not claim that O(1) “ontological addressing” is a realizable algorithmic speed-up: only the cell that holds its own address returns to itself in one step.
