理论接口 · 这个页面在演示什么Theory interface · what this page shows

单比特的态是布洛赫球里的一点 r：球皮上是纯态，球肚子里是混合态。一种噪声每作用一步，就把整颗球做一次仿射变形 r ↦ (λx, λy, az + h)。舞台上的细线是作用之前的单位球，青色是它的像；琥珀色的 ρ 与白色的 σ 是从球皮出发的两个态，白线是它们之间的迹距离 T = ½‖r − s‖。本页是数值演示，不是证明。

  1. 三种噪声的形状。相位阻尼 (cx, cy, z)：只收腰、不掉高，不动点是整根竖轴；振幅阻尼 (√a x, √a y, az + 1 − a)：缩小并往北极上漂，只有北极不动；去极化 (fx, fy, fz)：同心缩小，只有球心不动。页面里每一步取 c = 1 − p、a = 1 − p、f = 1 − p，走 N 步就是 c^N、a^N、f^N。上面说的不动点都是 p > 0 时的；p = 0 时三种噪声每一步都是恒等映射，整颗球处处不动。这些布洛赫形式是标准教材算例：文献结果，未在本书形式化。
  2. 相位阻尼与捏合。相位阻尼迭代 N 次只把副对角元乘以 c^N：phaseDampingIterate_apply（LEAN ✓）；c < 1 时等权叠加态的相干元趋于零：equal_superposition_coherence_tendsto_zero（LEAN ✓）。c = 0 一步就是捏合：捏合丢掉的相干质量是 |ρ₀₁|² + |ρ₁₀|²，在布洛赫坐标里等于 (x² + y²)/2（手算）：pinching_discarded_coherence_mass（LEAN ✓）；捏合的不动点恰是副对角元为零的矩阵，即竖轴：pinching_eq_self_iff_offDiag_eq_zero（LEAN ✓）。
  3. 横向最多留多少。固定北极的映射 (λx, λy, az + 1 − a) 保持整个闭单位球，当且仅当 λ² ≤ a：north_pole_ball_preserving_iff（LEAN ✓）。纯振幅阻尼取 λ = √a，恰好饱和。滑块 T₂ / T₁ 按第四章的指数包络 a = e^{−t/T₁}、λ = e^{−t/T₂} 取 λ = a^{T₁/T₂}；于是当 0 < p < 1（即 0 < a < 1）时，λ² ≤ a 当且仅当 T₂ ≤ 2T₁，T₂ > 2T₁ 时像的一部分落到球外（品红），这样的映射不把态送到态；这时舞台把单位球画成玻璃球壳、把像画成受光的实体，刺出的一块着品红，它与球壳的交线是一圈白色细线。p = 0 与 p = 1 两端对任何比值都有 λ² = a：p = 0 时每一步是恒等映射，p = 1 时每一步是 γ = 1 的振幅阻尼，把整颗球复位到北极，两者都是信道。这里判定的只是球的保持性，不是完全正性。
  4. 距离只减不增。对任意量子信道，迹距离不增：traceDistance_contract（LEAN ✓）。单比特上 T = ½‖r − s‖ 是手算换算。步与步之间页面取相邻两个整数步输出的凸组合；每一步是信道时它也是信道，所以白线在整条时间轴上都只缩不长；整数步上的数与 N 次迭代完全一致。
  5. 球心。强度为 1 的去极化把整颗球送到球心 r = 0，即 ρ = I/2：从哪个态出发都落在同一点，距离为零。

A qubit state is a point r of the Bloch ball: pure states on the skin, mixed states inside. Each step of a noise deforms the whole ball by one affine map r ↦ (λx, λy, az + h). The thin wire on the stage is the unit ball before the noise and the cyan body is its image; the amber ρ and the white σ are two states that start on the skin, and the white line between them is their trace distance T = ½‖r − s‖. The page is a numerical illustration, not a proof.

  1. The shapes of the three noises. Phase damping (cx, cy, z) narrows the waist and keeps the height; its fixed points are the whole vertical axis. Amplitude damping (√a x, √a y, az + 1 − a) shrinks the ball and lifts it towards the north pole, the only fixed point. Depolarizing (fx, fy, fz) shrinks it evenly towards the centre, the only fixed point. Each step on the page takes c = 1 − p, a = 1 − p, f = 1 − p, so N steps give c^N, a^N, f^N. The fixed points named here are those for p > 0; at p = 0 each of the three noises is the identity at every step, and the whole ball stays put. These Bloch forms are standard textbook computations: literature result, not formalized in this book.
  2. Phase damping and pinching. Phase damping iterated N times only multiplies the off-diagonal entries by c^N: phaseDampingIterate_apply (LEAN ✓); for c < 1 the coherence of the equal superposition tends to zero: equal_superposition_coherence_tendsto_zero (LEAN ✓). One step with c = 0 is pinching: the coherence mass it discards is |ρ₀₁|² + |ρ₁₀|², which is (x² + y²)/2 in Bloch coordinates (by hand): pinching_discarded_coherence_mass (LEAN ✓); the fixed points of pinching are exactly the matrices with zero off-diagonal entries, the vertical axis: pinching_eq_self_iff_offDiag_eq_zero (LEAN ✓).
  3. How much may stay sideways. The north-pole map (λx, λy, az + 1 − a) keeps the whole closed unit ball if and only if λ² ≤ a: north_pole_ball_preserving_iff (LEAN ✓). Pure amplitude damping takes λ = √a and saturates it. The T₂ / T₁ slider follows the exponential envelopes of Chapter 4, a = e^{−t/T₁} and λ = e^{−t/T₂}, so λ = a^{T₁/T₂}. For 0 < p < 1 (that is, 0 < a < 1), λ² ≤ a exactly when T₂ ≤ 2T₁; for T₂ > 2T₁ part of the image lies outside the ball (magenta), and such a map does not send states to states; the stage then draws the unit ball as a glass shell and the image as a lit solid, the piece that sticks out in magenta, with a thin white line where it crosses the shell. At the two ends λ² = a whatever the ratio: at p = 0 each step is the identity, and at p = 1 each step is amplitude damping with γ = 1, which resets the whole ball to the north pole; both are channels. This decides only whether the ball is kept, not complete positivity.
  4. Distances never grow. The trace distance does not grow under any quantum channel: traceDistance_contract (LEAN ✓). On a qubit, T = ½‖r − s‖ is a hand computation. Between steps the page takes the convex combination of the outputs of the two neighbouring whole steps; when each step is a channel, so is that combination, and the white line only shrinks along the whole rail; at whole steps the numbers are exactly those of N iterations.
  5. The centre. Depolarizing at strength 1 sends the whole ball to the centre r = 0, that is ρ = I/2: every starting state lands on the same point, at distance zero.
