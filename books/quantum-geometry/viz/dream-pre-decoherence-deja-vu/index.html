两份相位记录Two phase recordsγ

每份记录给地址 0 写 (1, 0)，给地址 1 写 (i, 0)，重叠 γ = −i；写入一份让 ρ₀₁ 乘 γ，逆转一份乘 γ* = i。时间轴四站：输入、两份都写入、只逆转副本 0、两份都逆转。舞台上的开关可以换成“重叠为 0”的对照：地址 1 写 (0, 1)，两条路被完全分开。Each record writes (1, 0) for address 0 and (i, 0) for address 1, so its overlap is γ = −i; writing a copy multiplies ρ₀₁ by γ, reversing one by γ* = i. Four stops on the rail: input, both written, copy 0 reversed, both reversed. The switch on the stage swaps in the comparison “overlap 0”: address 1 writes (0, 1), and the two paths are told apart completely.

一张投影沙盘，三个场景。尺子：实二维量子比特 |ψ⟩ = (cos θ, sin θ) 的布洛赫圆盘，测量轴 n = (sin β, 0, cos β) 是一把尺子。漏斗：三个单位向量的格拉姆行列式 det G 随第三个余弦 z 变化的拱形与先验窗口。记录：非对角元 ρ₀₁ 在复平面上的箭头。本页是数值演示，不是证明；绿色框只给 Lean 已验证的陈述本身。

  1. 选尺子。Q±(β) = ½(I ± n·σ)，结果权重 p± = (1 ± r·n)/2。同一个输入 θ = 30°：β = 0° 时 p₊ = 3/4，β = 90° 时 p₊ = (2 + √3)/4 ≈ 0.933。转动的是测量的问法，没有改写任何已经记下的事件，也没有往过去传任何信号；“延迟选择”只是演示里何时转尺子。小图：V = ℝ³、S = span(e₁, e₂)、e = e₃ 是一条剩余方向；T 循环 e₁ → e₂ → e₃ → e₁、C(v) = v₁ 时 O₀、O₁、O₂ 的维数为 1、2、3，严格增长两步 = 3 − rank C。扩大环境空间本身是模型动作，不是克雷洛夫定理的结论。
  2. 梦中预编译。完整未读捏合 Π_β(ρ) = Q₊ρQ₊ + Q₋ρQ₋ = ½(I + (r·n) n·σ)，保留全部结果权重，不选出某一个结果。θ = 30°、β = 0°：ρ_in 的非对角 √3/4 归零，σ = diag(3/4, 1/4)，态熵 h₂(3/4) ≈ 0.811 bit，丢弃的希尔伯特—施密特质量 3/8（没有 bit 单位）。把它读成梦的“预编译”是本书的诠释（MODEL）。
  3. 兼容漏斗。B = (1, 0, 0)，A = (4/5, 3/5, 0)，C(φ) = (4/5, (3/5)cos φ, (3/5)sin φ)：硬锚 x = A·B = 4/5，y = B·C = 4/5，z = A·C = 16/25 + (9/25)cos φ，det G = 81/625 − (z − 16/25)²（手工推导），可行 z ∈ [0.28, 1]。先验依次把 q = cos φ 限制在 [−1, 1]、[0, 2/3]、[1/3, 1/2]，z 的窗口 [0.28, 1] ⊇ [0.64, 0.88] ⊇ [0.76, 0.82]；目标 z = 0.80（q = 4/9，det G = 13/125）。示意路径 z(t) = 19/25 + t/25 是模型选的，窗口的嵌套并不强迫它，也不唯一决定终点。黄金小图：(a, b) ∈ {−12, …, 12}²，内部坐标 a + b(1 − φ)，窗口中心 φ − 3/2、宽 s：s = 1、1/2、1/4 时选中 26、11、7 个点（闭区间，容差 10⁻¹²）。
  4. 梦后逻辑升级。四个世界 {00, 01, 10, 11}：旧特征 f₀(a, b) = a 留下 4 个分不开的有序对，逃逸率 4/12 = 1/3；区分性的 f₁(a, b) = b 独有地分开这 4 对（U = 4），逃逸率降到 0；冗余的 f_dup = f₀ 的 U = 0。梦里的猜测是 00；学到 f₁ = 1 选出 01，与旧先验 {00, 01} 相容，却推翻了猜测——所以作废的是编译出来的投影，不是整个先验。开关打开时，模型规则把可撤销的先验 q ∈ [1/3, 1/2] 换成 q ∈ [−1, −1/3]（硬锚不动），窗口变成 [0.28, 0.52]，旧目标 0.80 被排除，新目标 z = 0.40（q = −2/3，det G = 9/125）；尺子转到 β = 90°，保存的 σ 再投影成 I/2，新增熵 ≈ 0.189 bit，残差 1/8。“学到新事实 → 换尺子、换先验、冲刷缓存”是选定的模型规则，不是第 14–16 条定理的推论；修正不可交换的三世界例子是另一个独立的显式例子。关掉开关是从不变的快照重置演示，不是忘掉事实，也不是找回被删掉的相干。
  5. 相位记录与逆转。θ = 45° 时 ρ₀₁ = 1/2。两份记录各给地址 0 写 (1, 0)、给地址 1 写 (i, 0)，重叠 γ = −i：两份都写入后 ρ₀₁ = −1/2，只逆转副本 0 得 −i/2，两份都逆转回到 1/2（Lean 证书的四个值；站点之间的转动只是动画）。复原定理的前提是每份记录 γ*·γ = 1；重叠为 0 的对照里两条路被完全分开，前提不成立，逆转救不回来。这些相位信道也不能拿来复原已经捏合过的 σ：被删掉的非对角在局部已经没有了。
  6. 似曾相识。对同一把尺子，Π(Π(ρ)) = Π(ρ)：第二次残差是零矩阵，新增熵 0（手工特化，ARGUED）。这个零是“同一映射再做一次的新增态熵”，不是态本身的熵（仍是 0.811 bit），也不是结果的惊讶度（−log₂ 3/4 ≈ 0.415 与 −log₂ 1/4 = 2 bit），更不是热力学的零功、CPU 的能耗或大脑的代谢。缓存卡是虚构的情节记录：命中 = Valid ∧ 地址相符 ∧ 上下文版本相符 ∧ 再投影不改变保存的态；“无时间标签的熟悉感” = 命中 ∧ Time_Tag = NULL。Time_Tag 是情节时间戳，不是地址标签；单凭有效位确立不了命中。这不是字面意义的无标签 TLB，也不是测得的人脑似曾相识机制（MODEL）。
  7. 不是什么。“梦见过，所以必然发生”不从幂等、格拉姆半正定、切投包含或对角落地中推出；页面没有任何定理断言预知梦、时间旅行或神经缓存。

One projection sandtable in three scenes. Ruler: the Bloch disc of a real qubit |ψ⟩ = (cos θ, sin θ), with the measurement axis n = (sin β, 0, cos β) as a ruler. Funnel: the arch traced by the Gram determinant det G of three unit vectors as their third cosine z varies, with the prior windows. Records: the arrow of the off-diagonal entry ρ₀₁ in the complex plane. The page is a numerical illustration, not a proof; the green boxes carry only the statements verified in Lean.

  1. Choosing the ruler. Q±(β) = ½(I ± n·σ), with outcome weights p± = (1 ± r·n)/2. For the same input θ = 30°: p₊ = 3/4 at β = 0° and p₊ = (2 + √3)/4 ≈ 0.933 at β = 90°. What turns is the question the measurement asks; no recorded event is rewritten and no signal goes to the past; “delayed choice” is only when the ruler is set in the demonstration. Inset: in V = ℝ³ with S = span(e₁, e₂), e = e₃ is a residual direction; with T cycling e₁ → e₂ → e₃ → e₁ and C(v) = v₁, O₀, O₁, O₂ have dimensions 1, 2, 3: two strict growth steps = 3 − rank C. Enlarging the ambient space is itself a model action, not a conclusion of the Krylov theorem.
  2. Dream precompile. The complete unread pinching Π_β(ρ) = Q₊ρQ₊ + Q₋ρQ₋ = ½(I + (r·n) n·σ) keeps every outcome weight and selects no outcome. At θ = 30°, β = 0°: the off-diagonal √3/4 of ρ_in goes to zero, σ = diag(3/4, 1/4), the state entropy is h₂(3/4) ≈ 0.811 bit and the discarded Hilbert–Schmidt mass is 3/8 (no unit of bits). Reading this as the dream's “precompile” is this book's interpretation (MODEL).
  3. Compatible funnel. B = (1, 0, 0), A = (4/5, 3/5, 0), C(φ) = (4/5, (3/5)cos φ, (3/5)sin φ): hard anchors x = A·B = 4/5, y = B·C = 4/5, and z = A·C = 16/25 + (9/25)cos φ, det G = 81/625 − (z − 16/25)² (manual derivation), feasible for z ∈ [0.28, 1]. The priors restrict q = cos φ to [−1, 1], [0, 2/3], [1/3, 1/2] in turn, so the z windows are [0.28, 1] ⊇ [0.64, 0.88] ⊇ [0.76, 0.82]; the target is z = 0.80 (q = 4/9, det G = 13/125). The illustrative path z(t) = 19/25 + t/25 is chosen by the model; the nesting of the windows neither forces it nor fixes its end uniquely. Golden inset: (a, b) ∈ {−12, …, 12}², internal coordinate a + b(1 − φ), window centred at φ − 3/2 with width s: s = 1, 1/2, 1/4 select 26, 11, 7 points (closed intervals, tolerance 10⁻¹²).
  4. Post-dream logic upgrade. Four worlds {00, 01, 10, 11}: the old feature f₀(a, b) = a leaves 4 ordered pairs it cannot tell apart, an escape rate of 4/12 = 1/3; the distinguishing f₁(a, b) = b alone separates those 4 pairs (U = 4) and the escape rate drops to 0; the redundant f_dup = f₀ has U = 0. The dream's guess is 00; learning f₁ = 1 selects 01, consistent with the old prior {00, 01} but contradicting the guess, so what is invalidated is the compiled projection, not the whole prior. With the switch on, the model rule replaces the defeasible prior q ∈ [1/3, 1/2] by q ∈ [−1, −1/3] (the hard anchors stay), the window becomes [0.28, 0.52], the old target 0.80 is excluded and the new target is z = 0.40 (q = −2/3, det G = 9/125); the ruler turns to β = 90°, the saved σ projects to I/2, the added entropy is ≈ 0.189 bit and the residual 1/8. “A learned fact → a new ruler, a new prior, a flushed cache” is a chosen model rule, not a consequence of theorems 14–16; the three-world example of non-commuting revision is a separate explicit example. Switching off resets the demonstration from the unchanged snapshot; it neither unlearns the fact nor recovers deleted coherence.
  5. Phase records and reversal. At θ = 45°, ρ₀₁ = 1/2. Each of two records writes (1, 0) for address 0 and (i, 0) for address 1, with overlap γ = −i: with both written ρ₀₁ = −1/2, reversing copy 0 only gives −i/2, and reversing both returns it to 1/2 (the four values of the Lean certificate; the turning between stops is animation only). The restoration theorem assumes γ*·γ = 1 for every record; in the comparison with overlap 0 the two paths are told apart completely, the premise fails and reversal cannot restore anything. Nor can these phase channels restore the already pinched σ: its deleted off-diagonal entry is no longer there locally.
  6. Déjà vu. For the same ruler, Π(Π(ρ)) = Π(ρ): the second residual is the zero matrix and the added entropy is 0 (a manual specialization, ARGUED). This zero is “the state entropy added by applying the same map again”; it is not the entropy of the state (still 0.811 bit), nor the surprisal of an outcome (−log₂ 3/4 ≈ 0.415 and −log₂ 1/4 = 2 bit), nor zero thermodynamic work, CPU energy or brain metabolism. The cache card is a fictional episode record: hit = Valid ∧ address matches ∧ context version matches ∧ re-projection leaves the saved state unchanged; “untagged familiarity” = hit ∧ Time_Tag = NULL. Time_Tag is an episodic timestamp, not an address tag; a valid bit alone establishes no hit. This is not literal tagless TLB addressing, nor a measured mechanism of human déjà vu (MODEL).
  7. What it is not. “Dreamed once, therefore bound to happen” follows from none of idempotence, Gram positivity, the cut-and-project inclusion or diagonal landing; no theorem on this page asserts precognitive dreams, time travel or a neural cache.
