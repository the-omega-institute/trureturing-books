# 35.6.7 跨切口纠缠、帕里视界熵与八概念沙盘收束 {#sec-ch39-p2e-sandtable-closing}

承接上一节单点收缩尺度的比对，现在把八概念综合沙盘的最后两环合拢：当一条禁 $1^K$ 合法字被空间切口一分为二时，左右两半在切口处的尾部连 `1` 长度 $\tau(x)$ 与首部连 `1` 长度 $\iota(y)$ 必须满足 $\tau(x) + \iota(y) < K$。这一跨越边界的离散相容规则并不自动等同于量子纠缠——同一组合法字支撑与计算基概率可以对应不同的纠缠态——但它精确框定了在直接编码契约下双页逻辑态的可达施密特秩矩形 $[1, R_0] \times [1, R_1]$ 与页熵上界 $\ln R_b$。关于直接编码器的可达秩定理、局域父哈密顿量热浴链与固定禁戒长度下的一致谱隙证明，完整展开收录于[附录 O §O.1](ch39-s05-s07-cut-entanglement.md)。

::: {.viz src="pisot-clifford-rauzy-sandtable" preset="entanglement" height="500"}
**跨切口禁戒与可达秩矩形卡（`entanglement`）**：左侧展示跨切口拼接检验 $\tau(x) + \iota(y) < K$（青色标出相容拼接字对，品红标出触发 $1^K$ 阻塞的非法拼接），右侧绘制可达页秩矩形 $[1, R_0] \times [1, R_1]$ 与页熵上界 $\ln R_b$，琥珀色标出当前选定的参数与秩点。可达秩矩形与熵界属 `LEAN ✓`，具体参数枚举属 `NUM`，里德堡与任意子物理背景属 `文献结果`。
:::

从空间切口再进一步，考察长程禁 $1^K$ 字流的遍历统计与有限视界下的不可区分地址碰撞：在重置马尔可夫链上，帕里（Parry）平稳权重 $\pi_K$ 锁定了字流的拓扑熵 $\log_2 \beta_K$ 与诱导回归熵，而有限观测场中的逃逸对计数 $E(S)$ 刻画了受限观察者仍未能分辨的边界模糊度。需要严守认识论边界的是：拓扑熵识别与阿布拉莫夫公式属文献结果，一般分形视界律 $S_{\mathrm{ent}} \propto R^{D_F}$ 属概念模型（`MODEL`），而平移不变局域有隙实现与一般 $K \ge 4$ 非各向同性皮索窗上的视界熵刻画仍是开放问题（[@prob-ch39-p2e-fractal-horizon]）。双向帕里源、最大熵回返时长、Tribonacci Slater 前缀、非连续切口方向复形与三元拟阵扩展、替代词交替偏差及开链谱距离的完整技术证明，集中收录于[附录 O §O.2](ch39-s05-s08-parry-law-and-entropy.md)。

::: {.viz src="pisot-clifford-rauzy-sandtable" preset="entropy" height="500"}
**帕里平稳权重、有限逃逸对与诱导回归熵。** 青色表示重置链的帕里平稳权重 $\pi_K$，品红色表示有限观测场中未区分的逃逸对 $E(S)$，琥珀色标出当前阶数 $K$。卡片还给出拓扑熵 $\log_2\beta_K$ 与诱导回归熵读数，将拓扑熵识别与阿布拉莫夫公式标为文献结果，将一般分形视界律 $S_{\mathrm{ent}}\propto R^{D_F}$ 标为 `MODEL`。正文以手工推导证明有限平面子瓦片切口的贝尔对标度。平移不变或全格统一的局域有隙实现与一般 $K\ge4$ 非各向同性皮索窗仍是开放问题，参见 [@prob-ch39-p2e-fractal-horizon]。
:::
