# O.2.4.1 新增同行三元组的最小数 {#356841-新增同行三元组的最小数}

固定 $d,r\ge 1$，令 $q=3^d$。点集为 $\mathbb F_3^d\times\mathbb Z/(3r)\mathbb Z$，每个 $x\in\mathbb F_3^d$ 对应一行。保留所有跨行提升三元组，即第一坐标互异且在乘积群中和为零的三元组。我们可以在同一行内补上若干三元组，但每个三元组的三点须互异，任意两个不同的点至多同属一个三元组。[@thm-joint-circuit-internal-dimension]

::: {.theorem #thm-joint-circuit-minimum-internal-lower-bound title="增加一个点势维度的下界" lean="D5/S3/Combinatorics/Matroids/RankThreeMinimumInternalAdditions.internal_additions_lower_bound"}
在上述条件下，若归一化点势空间的维数增至 $d+1$，则至少需新增 $qr^2$ 个同行三元组。
:::

::: proof
维数判据要求每个未覆盖的同行点对在模三约化后具有相同的余数。因此，同一行内余数不同的两个点必在一个新增三元组中。每行有六种有序的异余数类对，每类有 $r$ 个点，故这类有序点对共有 $6qr^2$ 个。

对每个有序点对，选定一个含有它的新增三元组，并记下这两个点所在的有序位置。由三元组及位置能恢复原点对，所以这是一个单射。每个新增三元组只有六对不同的有序位置，因而至少需要 $qr^2$ 个新增三元组。完整证明由 Lean 内核检查。[@thm-joint-circuit-internal-dimension]
:::

::: {.theorem #thm-joint-circuit-minimum-internal-attained title="模三剩余类上的横截设计达到下界" lean="D5/S3/Combinatorics/Matroids/RankThreeMinimumInternalAdditions.exists_internal_additions_attaining"}
对上述跨行三元组，可以恰好加入 $qr^2$ 个同行三元组，使合并后的每个三元组仍有三个不同的点，每个不同点对至多出现一次，且归一化点势空间恰为 $d+1$ 维。
:::

::: proof
在每一行内，把循环坐标按模三余数分成三类。每类恰有 $r$ 个点，把每类的点编号为 $\mathbb Z/r\mathbb Z$。对每对编号 $a,b$，取余数 $0$ 类中编号 $a$ 的点、余数 $1$ 类中编号 $b$ 的点、余数 $2$ 类中编号 $-a-b$ 的点。给定其中任意两个不同余数的点，就能解出第三个编号。因此每个同行且余数不同的点对恰好出现一次，并且同余数点对未被这些三元组覆盖。新增三元组的余数和为 $0+1+2=0$，而未覆盖同行点对的余数差为零。两项模三条件都成立，点势维数因此为 $d+1$。

各行各有 $r^2$ 个新增三元组，与任何跨行三元组都没有共同点对。这里的编号只要求是各剩余类与 $\mathbb Z/r\mathbb Z$ 的集合双射，因而也适用于 $9\mid 3r$。例如 $d=1,r=2$ 时，每行的三个余数类分别是 $\{0,3\}$、$\{1,4\}$、$\{2,5\}$。为每类按写出的顺序编号 $0,1$，每行得到四个三元组 $\{0,1,2\}$、$\{0,4,5\}$、$\{3,1,5\}$ 和 $\{3,4,2\}$，三行一共新增十二个。完整证明由 Lean 内核检查。[@thm-joint-circuit-internal-dimension]
:::

## O.2.4.1.1 达到最小数的所有扩充 {#3568411-达到最小数的所有扩充}

上一节的构造用循环群运算选出第三个标签。精确下界还告诉我们这个选择有多少自由度。固定任意一行的任意一个余数类，将其中的点用 $\{0,\ldots,r-1\}$ 编号。各行各类的编号可以独立选择。

::: {.theorem #thm-joint-circuit-minimum-internal-latin title="最小三元组族由逐行拉丁方生成" lean="D5/S3/Combinatorics/Matroids/RankThreeOptimalInternalLatin.exists_latin_of_optimal_family"}
固定跨行三元组族。若新增三元组恰有 $3^d r^2$ 个，且归一化点势空间的维数为 $d+1$，则每个点行 $x$ 对应一个 $r$ 阶拉丁方 $L_x$。这一行的无序三元组恰好由余数 $0$ 类中编号为 $a$ 的点、余数 $1$ 类中编号为 $b$ 的点、余数 $2$ 类中编号为 $L_x(a,b)$ 的点构成，其中 $a,b$ 遍历全部编号。
:::

::: proof
达到下界时，计数证明中的单射成为双射。新增三元组的每一对不同有序位置，都对应同一行中余数不同的点对。因此每个新增三元组的三个点分别来自余数 $0,1,2$ 类。任意两个不同余数类中的点唯一确定第三点。用余数 $0,1$ 两类的点定义 $L_x(a,b)$，另外两对余数类的唯一补全性保证了 $L_x$ 的每行和每列都是编号的一个排列。完整证明由 Lean 内核检查。
:::

::: {.theorem #thm-joint-circuit-minimum-internal-latin-unique title="无序三元组族确定拉丁方" lean="D5/S3/Combinatorics/Matroids/RankThreeOptimalInternalLatin.latin_assignment_injective"}
固定余数类内的编号。如果两组逐行表格给出相同的无序三元组族，它们在每行的每个表格位置取值都相同。
:::

::: proof
即使忘掉三元组的顺序，点的余数也能识别它在三元组中的位置。固定点行后，余数 $0,1$ 类中的点给出表格位置 $(a,b)$，余数 $2$ 类中的点给出表格取值。完整证明由 Lean 内核检查。
:::

::: {.theorem #thm-joint-circuit-minimum-internal-latin-converse title="任意逐行拉丁方都给出最小扩充" lean="D5/S3/Combinatorics/Matroids/RankThreeOptimalInternalLatin.optimal_family_of_latin"}
在每个点行独立选择一个 $r$ 阶拉丁方。把各表格位置对应的三元组加到固定的跨行族中，恰好新增 $3^d r^2$ 个互不相同的同行三元组。合并后的任意不同点对仍至多出现一次，归一化点势空间的维数为 $d+1$。
:::

::: proof
每行每列的排列性质保证了同一行中不同余数类的点对可以唯一补全。同一三元组中三点互异，同余数的点对不会被这些新三元组覆盖。跨行三元组只覆盖不同行的点对，所以新增三元组保留了点对唯一性。每个新增三元组的余数和为零，未覆盖的同行点对的余数差也为零。由维数判据得到 $d+1$。每个点行有 $r^2$ 个表格位置。完整证明由 Lean 内核检查。[@thm-joint-circuit-internal-dimension]
:::

## O.2.4.1.2 所有保留额外维度的扩充 {#3568412-所有保留额外维度的扩充}

最小扩充已经覆盖了所有同行异余数点对。若继续添加三元组又要保留额外维度，维数判据允许在同一余数类内补充。仍固定跨行三元组与各余数类的独立编号。部分斯坦纳三元系是一族三元素集合，任意两个不同标签至多同属其中一个集合。

::: {.theorem #thm-joint-circuit-steiner-decomposition title="扩充族中的拉丁方与部分斯坦纳三元系" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSteinerDecomposition.forward_decomposition"}
设新增三元组均由同一行内三个不同的点组成，且合并后的族保持点对唯一性。若归一化点势空间维数为 $d+1$，则新增的无序族由各行拉丁方的三元组和各行各实际余数类内的部分斯坦纳三元系组成。
:::

::: proof
每个同行三元组的余数和为零，所以三个余数全同或全异。同一行中余数不同的点对都必须被覆盖。余数 $0,1$ 两类中的点对恰好把余数全异的三元组各数一次，因此这一类三元组共有 $3^d r^2$ 个。删去同余数的三元组后，异余数点对的覆盖和额外维度仍然保留，于是剩下的三元组可用最小族的拉丁方分类。每个余数类内其余三元组继承点对唯一性。完整证明由 Lean 内核检查。
:::

::: {.theorem #thm-joint-circuit-steiner-realization title="拉丁方与部分斯坦纳三元系可以独立选择" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSteinerDecomposition.realize_decomposition"}
在每行任取一个 $r$ 阶拉丁方，并在各行各余数类的 $r$ 个标签上任取部分斯坦纳三元系。对应的三元组给出固定跨行族的一个点对唯一扩充，归一化点势空间维数为 $d+1$。
:::

::: proof
跨行三元组使用不同行的点对。拉丁方三元组使用同行异余数的点对。部分斯坦纳三元系使用同行同余数的点对。三类点对互不相交。新增的同余数三元组仍有零余数和，且未覆盖的点对只会减少，所以保留额外维度的条件仍成立。完整证明由 Lean 内核检查。
:::

::: {.theorem #thm-joint-circuit-steiner-unique title="无序扩充族确定全部选择" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSteinerDecomposition.decomposition_unique"}
固定编号后，无序扩充族唯一确定各行的拉丁方和各行各余数类的部分斯坦纳三元系。
:::

::: proof
观察余数即可识别拉丁方三元组。其余每个三元组的一点已足以确定该三元组的行与余数类，再用该类的编号恢复三元素集合。完整证明由 Lean 内核检查。
:::

例如，取 $d=1$、$r=3$。每个余数类恰有三个点，可在该类中加入唯一的三元组，也可留空。三个点行共有九个余数类，各类的选择互相独立。因此在拉丁方给出的 $27$ 个三元组之外，可以再加入零到九个三元组，归一化点势空间始终保持二维。

## O.2.4.1.3 可取得的新增三元组数 {#3568413-可取得的新增三元组数}

上例中可以删去任意几个同余数三元组而保留维度。一般的余数类也有这个性质。记 $D(r,3,2)$ 为 $r$ 个标签上的部分斯坦纳三元系所能含有的最多三元组数。

::: {.theorem #thm-joint-circuit-internal-size-spectrum title="新增三元组数的完整区间" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.exact_size_spectrum"}
沿用本节的跨行三元组、点对唯一性及归一化条件。新增同行三元组的数目恰好可以取遍
$$
3^d r^2 \le N \le 3^d r^2+3^{d+1}D(r,3,2)
$$
中的所有整数，且点势空间维数保持 $d+1$。
:::

::: proof
每个拉丁方固定给出 $r^2$ 个三元组。各行的拉丁方部分互不重叠，且其中任何三元组都含有三个不同余数。其余三元组属于各行各余数类的部分斯坦纳三元系。这样的类有 $3^{d+1}$ 个，各类至多贡献 $D(r,3,2)$ 个三元组，故得到两个端点。

为取得中间任意一个数，先在每个余数类放入一个达到装填上界的三元组族。从这些同余数三元组的并集中任取 $N-3^d r^2$ 个。删去三元组会保留每个类内的点对唯一性。这些选择连同各行的拉丁方，由 [@thm-joint-circuit-steiner-realization] 给出所求扩充。完整证明由 Lean 内核检查。
:::

## O.2.4.1.4 饱和扩充的大小 {#3568414-饱和扩充的大小}

仍固定跨行三元组，并要求点对唯一性及归一化点势空间维数 $d+1$。如果在这两个条件下无法再加入一个同行三元组，就称扩充为**饱和**。任何包含关系下的真扩充都允许先加入其中的任意一个新三元组，因此饱和也等价于按包含关系极大。 [@thm-joint-circuit-steiner-insert]

::: {.theorem #thm-joint-circuit-steiner-insert title="可从较大的扩充中单独加入一个三元组" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.internal_extension_insert"}
若两个符合条件的同行三元组族满足 $G\subseteq H$，则从 $H$ 任选一个三元组加入 $G$，所得的族仍符合条件。
:::

::: proof
$G$ 的每个拉丁方三元组在 $H$ 中仍是拉丁方三元组。它在余数 $0,1$ 两类中的点确定方格，在余数 $2$ 类中的点确定方格值。因此两族的拉丁方完全相同。若所选三元组尚未出现，它属于某个余数类。只把该块加到相应类里，所得装填仍是 $H$ 在该类中装填的子集。于是点对唯一性与额外维度同时保留。
:::

::: {.theorem #thm-joint-circuit-steiner-saturated title="饱和等价于每个余数类中的装填极大" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.saturated_internal_extension_iff"}
沿用实际余数类的编号。一个扩充饱和，当且仅当其分解中的每个部分斯坦纳三元系都按包含关系极大。
:::

::: proof
若某一类的装填还能扩大，只扩大这一类便给出全局真扩充。反过来，全局真扩充固定全部拉丁方，因而至少扩大了一个余数类内的装填。
:::

::: {.theorem #thm-joint-circuit-steiner-six-saturated-sizes title="六标签时饱和大小隔一个整数取值" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.saturated_six_size_spectrum"}
当 $r=6$ 时，饱和扩充的新增三元组数恰为
$$
36\cdot 3^d+2\cdot 3^{d+1}+2k,\qquad 0\le k\le 3^{d+1},\quad k\in\mathbb Z.
$$
:::

::: proof
六标签装填的两个极大大小也可由经典的局部谱结论得出。 [Colbourn §§2.3.1–2.3.3](https://ajc.maths.uq.edu.au/pdf/4/ocr-ajc-v4-p143.pdf)

在六个标签上，每个标签至多属于两个三元组，因为每块要为该标签使用两个不同搭档，总共只有五个搭档。因此至多有四块。零块与一块都能补充。若有三块，它们不能有一对互不相交，否则任何第三块都会重复其中一块的点对。因此三块两两相交于三个不同的点。每块还各有一个只属于自己的点，这三个点之间的点对都未使用，可以把它们组成第四块。

两种极大大小都能取到。用简写 $abc=\{a,b,c\}$，两块的例子是 $012,345$，未使用的点对形成完全二部图，没有可补的三角形。四块的例子是 $012,034,135,245$，已达到上界。于是 $3^{d+1}$ 个实际余数类可独立选两块或四块。若恰有 $k$ 类选四块，加上每行 $36$ 块拉丁方三元组，即得所述数目。例如 $d=1$ 时，饱和大小恰为 $126,128,\ldots,144$。
:::

### 完整装填下的最大值缺口

当 $r\ge7$ 且 $r$ 个标签上存在完整的斯坦纳三元系时，相邻的两个最大饱和大小也相差二。完整装填使用了每个无序点对，因此每类有 $r(r-1)/6$ 块。要少用两块，可以从一个完整装填出发，选择三个不在同一块中的点，并更换覆盖它们内部点对的块。

::: {.theorem #thm-joint-circuit-steiner-saturated-top-gap title="完整斯坦纳系给出的两个最大饱和大小" lean="D5/S3/Combinatorics/Matroids/RankThreeSaturatedTopGap.saturated_top_gap"}
沿用本节的跨行三元组、点对唯一性和归一化条件。设 $d>0$、$r\ge7$，且 $r$ 个标签上存在一个覆盖每个无序点对的斯坦纳三元系。记
$$
N_{\max}=3^d r^2+3^{d+1}\frac{r(r-1)}{6}.
$$

饱和扩充的新增同行三元组数至多为 $N_{\max}$。$N_{\max}$ 与 $N_{\max}-2$ 均可取得，$N_{\max}-1$ 无法取得。
:::

::: proof
在每个余数类放入完整装填，便取得上界。要少两块，只改一个类。取不成块的三个点 $a,b,c$，设覆盖 $ab,bc,ca$ 的块分别是 $abx,bcy,caz$。因为 $abc$ 不是一块，$x,y,z$ 都在 $\{a,b,c\}$ 之外。点对唯一性保证 $x,y,z$ 互异。删去这三块并加入 $abc$，留下的未覆盖点对恰好沿 $a,x,b,y,c,z,a$ 排成六环。六环没有三角形，因此无法再加入一块。

每个包含给定点的块恰好为这个点使用两个搭档。完整装填能覆盖该点的 $r-1$ 个搭档，所以 $r$ 为奇数，任意部分装填中每个点的未覆盖搭档数都是偶数。若一个类比上界恰少一块，便有三条未覆盖边。它们的度数之和为六，每个有边的点度数至少为二，因此至多涉及三个点。三条不同的边于是构成可补的三角形。由逐类饱和判据，全局减少的块数是各类减少数之和，每个正项至少为二。完整证明由 Lean 内核检查。
:::

例如，七标签的法诺平面有七块。取 $d=1$ 时，拉丁方部分有 $147$ 块，九个余数类还可共给 $63$ 块。两个最大饱和大小是 $210$ 和 $208$。局部极大装填谱见 [Colbourn，第 2.3.3 节](https://ajc.maths.uq.edu.au/pdf/4/ocr-ajc-v4-p143.pdf)。

### 删去一点后的匹配装填

若偶数 $r$ 满足存在一个 $r+1$ 点的完备斯坦纳三元系，就能在 $r$ 个标签上得到最大的部分装填。删去点 $p$ 和所有含 $p$ 的块。对每个剩余点 $a$，原来覆盖 $\{p,a\}$ 的块还含有一个剩余点 $m(a)$。所有未覆盖点对恰为 $\{a,m(a)\}$。因此每个点正好有一个未用的搭档。

::: {.theorem #thm-joint-circuit-steiner-point-deleted-switch title="删点装填的换块判据" lean="D5/S3/Combinatorics/Matroids/PointDeletedSteinerSwitch.point_deleted_switch"}
从任意有限完备的斯坦纳三元系删去一点。取不同于 $a$ 和 $c=m(a)$ 的剩余点 $v$，令 $b,d$ 分别完成原装填中的 $av,cv$ 点对。五个标签 $a,b,v,d,c$ 两两不同。删去 $abv,vdc$ 并加入 $avc$ 后，仍是部分斯坦纳三元系，块数恰少一。未覆盖点对由原匹配中的 $ac$ 换成路径 $a,b,v,d,c$。新装填按包含关系极大，当且仅当 $d\ne m(b)$。
:::

::: proof
原匹配的边 $ac$ 尚未使用。新块也重新使用了两条随旧块删去的边 $av,cv$，所以保留点对唯一性。两块的其余四条边恰好构成所述路径。路径本身没有三角形，匹配中每点至多接一条边。任何三角形都要用路径的两条相邻边。路径两端 $a,c$ 已失去原来的匹配边，所以唯一可能是路径中间的 $b,v,d$，它恰在 $d=m(b)$ 时闭合。完整证明由 Lean 内核检查。
:::

::: {.theorem #thm-joint-circuit-steiner-matching-first-deficit title="一次换块实现最大值减一" lean="D5/S3/Combinatorics/Matroids/PointDeletedSteinerSwitch.matching_switch_first_deficit"}
沿用本节的跨行三元组及归一化条件。如果 $r$ 个标签上有一个未覆盖点对恰为完美匹配的装填，并且其中有一处满足上述极大性判据的换块，则最大的饱和扩充有
$$
N_{\max}=3^d r^2+3^{d+1}\frac{r(r-2)}{6}
$$
个新增同行三元组，$N_{\max}-1$ 也可以取得。所有保持所需归一化维数的扩充都不超过 $N_{\max}$。
:::

::: proof
每块在其三个点上各用去两个搭档。完美匹配留下每点一个搭档，因此 $r$ 为偶数，且其他装填每点至少也留下一个搭档。故原装填的 $r(r-2)/6$ 块达到上界。它在每个类内都是极大的，因为匹配没有三角形。每类使用原装填达到全局上界，把其中一类换成上述少一块的极大装填便取得 $N_{\max}-1$。完整证明由 Lean 内核检查。
:::

要判断固定的剩余点 $v$ 允许哪些换块，可在原斯坦纳系之外添一点 $\ast$。对每个原点 $x$，把 $\ast$ 与 $x$ 配对，其余点按含 $x$ 的块中另外两点配对。将删去点 $p$ 和剩余点 $v$ 对应的两套匹配叠在一起。每个点恰有来自两套匹配的两条边，连通分量是交替偶圈。

::: {.theorem #thm-joint-circuit-steiner-alternating-starts title="交替分量给出全部成功起点" lean="D5/S3/Combinatorics/Matroids/SteinerAlternatingSwitches.point_deleted_successful_starts"}
从一个有 $r+1$ 点的有限完备斯坦纳三元系删去一点 $p$。固定任意剩余点 $v$。在两套匹配的并图中，大小至少为六的分量的顶点，恰为使 [@thm-joint-circuit-steiner-point-deleted-switch] 中的换块达到极大的剩余起点。若 $4\mid r$，每个 $v$ 至少有六个这样的起点。
:::

::: proof
包含 $\ast$ 的四圈依次经过 $p$、$m(v)$ 和 $v$。含 $\ast$ 的四圈以外的顶点都可用作起点 $a$。从 $a$ 分别按两种次序各走一次两套匹配的边，到达 $d$ 和 $m(b)$。两条路终点相同，当且仅当 $a$ 所在的分量是一个四圈。若 $4\mid r$，总点数 $r+2$ 除以四余二，所以至少有一个分量的大小达到六。完整证明由 Lean 内核检查。
:::

如果可以选择删去哪个点，就要看该点的配对何时与其余每套配对可交换。把 $\ast$ 作为单位元，令原点 $x$ 满足 $x\cdot x=\ast$，不同原点的乘积 $x\cdot y$ 取它们所在块的第三点。这给出斯坦纳环 $L$。沿 $x$ 的匹配走一步就是乘以 $x$。上面的四圈判据于是说，删去 $p$ 后，所有允许的换块都失败，当且仅当
$$
p\cdot(v\cdot a)=v\cdot(p\cdot a)
$$
对所有 $v,a\in L$ 成立。对原本不能用作起点的四圈顶点，等式由四圈本身给出。由于乘法可交换，这一等式恰要求 $p$ 与任意两点满足中心元素的结合律。

因此，**删去 $p$ 后存在极大换块，当且仅当 $p$ 不在 $L$ 的中心**。单位元在中心，故在原来的 $r+1$ 个点中，允许成功换块的删点选择恰有 $r+2-|Z(L)|$ 个。在三元系的语言中，被排除的原点恰是 Veblen 点。它们要求每个保留块 $\{a,v,b\}$ 都能补成含 $\{m(a),v,m(b)\}$ 的 Pasch 构形，这正是换块失败时补全三角形的条件。 [中心判据](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchCentre.admits_switch_iff_not_central) · [删点计数](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchCentre.ncard_admits_switch) · [Veblen 点与环中心](https://doi.org/10.1002/jcd.21964)

固定删点 $p$ 和枢轴 $v$ 时，中心也约束成功起点的数目。乘以任意中心元都与两套匹配的步进可交换，因而保持每个交替分量的大小。成功顶点于是按中心平移分成若干轨道。把中心各元素分别乘到同一个顶点上，所得顶点两两不同，所以每条轨道有 $|Z(L)|$ 个点。对应到保留标签，**成功起点数是 $|Z(L)|$ 的倍数**，其中允许数目为零。 [固定枢轴的整除性](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchOrbit.successful_starts_dvd_center)

把 $L$ 中相差一个中心平移的点视为同一个商点。**成功起点数只取决于删点和枢轴的商类。** 取中心元 $z,w$，把 $p,v$ 分别换成 $z\cdot p,w\cdot v$，并要求换后的两点仍是互异的原点。中心的结合律把两种次序的终点分别化为 $z\cdot(w\cdot(p\cdot(v\cdot a)))$ 和 $z\cdot(w\cdot(v\cdot(p\cdot a)))$。这两次中心平移都是双射，故两个终点是否相同保持不变。逐点应用四圈判据，就得到相同的成功起点数。

若任一点在中心，两套匹配处处交换。若 $p$ 与 $v$ 有相同的商类，可把 $(p,v)$ 看成 $(v,v)$ 在两个坐标分别作中心平移所得。相同的终点化简仍成立，所以两个步进次序处处给出相同的终点。这两种情形的成功起点数都是零。

对其余商类，可以从商图计算成功起点数。若删点 $p$ 与枢轴 $v$ 在商环中的类互异，且都异于单位元的类，两套匹配便在商图上各给出一步，每点的两个邻点互异。取商图中一个长度为 $\ell$ 的交替分量。交替走两步作为一轮，走 $\ell/2$ 轮后回到原来的商点。在 $L$ 中，这次返回把起点乘上一个中心元 $z$。

若 $z$ 是单位元，商分量上方有 $|Z(L)|$ 个长度为 $\ell$ 的分量。若 $z$ 非单位元，第二次沿商分量走完才回到原起点，上方有 $|Z(L)|/2$ 个长度为 $2\ell$ 的分量。两种情形都用同一个计数：商分量的每个点有 $|Z(L)|$ 个原像，所有这些原像分属于同样大小的提升分量。 商图中长度至少为六的分量贡献其全部原像。商图中的四圈也贡献其全部原像，条件是 $z$ 异于单位元。 [商分量的提升计数](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchQuotient.point_deleted_component_lifts)

给定一个有限、中心只含单位元的斯坦纳环 $Q$，固定两个互异的非单位元作为枢轴，再取一个有限交换群 $A$，使每个 $a\in A$ 都满足 $a+a=0$。可以构造一个商环为 $Q$、中心为 $A$ 的斯坦纳环，在同一个扩张中任意指定各交替分量的返回量。经过单位元的分量总返回零。构造在每一步加上当前三元组的标签。单位元分量以外，不同的匹配边使用不同的三元组，所以每个分量可用一条边的标签单独设定返回量。沿任一匹配走一步会反转返回，群中的元素都等于自己的相反元，因此同一分量的各个起点具有相同的返回量。 [独立指定返回量](lean:D5/S3/Combinatorics/Matroids/SteinerSchreierExtension.realizeSchreierReturns) · [Falcone、Figula 和 Galici 的扩张乘法，定理 3.1](https://arxiv.org/pdf/2406.12796)

设 $M$ 为商图中长度至少为六的分量的顶点总数，$s$ 为不经过单位元的四圈数。固定这对枢轴，长分量总贡献 $M|A|$ 个成功起点，单位元所在的四圈贡献零。其余四圈中，恰有返回量非零的四圈各贡献 $4|A|$ 个起点。若 $|A|\ge2$，可任选四圈设为非零，因此所有可能的计数恰为 $|A|(M+4j)$，其中 $j=0,1,\ldots,s$。平凡纤维只能取 $j=0$。要在三元系中读这个数，去掉扩张的单位元，以 $\{x,y,xy\}$ 为块，并给剩余点编号。斯坦纳环的乘法使每对不同点恰落在一个块里，沿枢轴乘法走一步就是沿相应匹配走一步。[有限编号下的逐点对应和计数](lean:D5/S3/Combinatorics/Matroids/SteinerSchreierSwitchCount.realizeLabelledSwitchCount) · [固定枢轴对的精确计数范围](lean:D5/S3/Combinatorics/Matroids/SteinerFixedPivotCountRange.labelledFixedPivotCountRange)

也可直接从三元组判断何时存在这样的四圈。若四个不同于枢轴的点 $a,b,c,d$ 与枢轴 $p,q$ 构成六个互异的点，且有四个块 $\{q,a,b\},\{p,b,c\},\{q,c,d\},\{p,d,a\}$，就得到一个 Pasch 构型。两个枢轴分居相对位置，在这四个块中从不共处一块。沿这四个块轮流按 $q,p$ 走，恰好走完一个不经过单位元的交替四圈。反过来，从任何这样的四圈读出两种匹配的四条边，便得到这四个块。因此，对固定的枢轴对和非平凡二元纤维，成功起点数随标签而变，当且仅当原三元系含有这样一个以这两点为相对枢轴的 Pasch 构型。 [Pasch 构型，定义 2.5 与图 1](https://arxiv.org/html/2406.12796v2#S2.F1) · [Lean 核验的 Pasch 判据](lean:D5/S3/Combinatorics/Matroids/Steiner/SteinerPaschSwitchCount.variableLabelledSwitchCount_iff)

把固定枢轴对的最大成功起点数减去最小值，记为 $W(p,q)$。在上述假设下，若 $A$ 非平凡，每个以 $p,q$ 为相对点的 Pasch 恰为 $W(p,q)$ 贡献 $4|A|$。每个 Pasch 有三对从不共处一块的点。例如，四个块若为 $\{a,b,c\},\{a,d,e\},\{b,e,f\},\{c,d,f\}$，这三对就是 $\{a,f\},\{b,d\},\{c,e\}$。每对有两种顺序。因此，若 $P$ 是原三元系中按四块集合计数的 Pasch 总数，则

$$
\sum_{\substack{p,q\in Q\setminus\{1_Q\}\\p\ne q}} W(p,q)=24|A|P,
$$

其中 $1_Q$ 是商环的单位元。和式中的每个跨度都在该枢轴对的所有标签表上独立取极值。若 $A$ 平凡，每个跨度都是零。 [Erskine 与 Griggs，第 2 页](https://arxiv.org/pdf/2405.07750v1#page=2)

对有限个指定的分量，在每条交替回路上选一个起点。第 $i$ 项的向量 $v_i$ 以三元组为坐标，每个坐标记录该三元组被经过的次数模二。经过单位元或两点相同的步骤在归一化扩张中加零，因此略去。记 $u_i$ 为指定的返回量。存在共同标签当且仅当每个二元关系 $\sum_i c_i v_i=0$ 都满足 $\sum_i c_i u_i=0$。

绕行一周的返回量是标签之和，所以共同标签必满足这些关系。反过来，把 $v_i$ 送到 $u_i$。关系条件保证这给出这些向量所张成空间上的良定义线性映射。把该空间的一组基扩充为整个三元组向量空间的基，在新增基向量上取零。用扩张后的映射在各个三元组的坐标基向量上取值，即得共同标签。各代表起点于是具有指定的返回量，沿匹配行走便把同一返回量传到分量中的所有起点。 [同时指定返回量的 Lean 证明](lean:D5/S3/Combinatorics/Matroids/SteinerReturnDependencies.realizesExactlyCompatibleReturns)

同一个扩张若要同时控制几对枢轴，共用的三元组会限制可取的返回量。设商环含一个八元布尔子环。取其中一个四元子群的三个非单位元 $p,q,r$，其余四点在每对枢轴下各组成一个交替四圈。记三对枢轴的返回量为 $u_{pq},u_{pr},u_{qr}$。每种匹配颜色的边标签在这三个返回量中各出现两次，故 $u_{pq}+u_{pr}+u_{qr}=0$。这也是此构型的充分条件。将枢轴 $q$ 的一条边标为 $u_{pq}$，枢轴 $r$ 的一条边标为 $u_{pr}$，其余标签取零，第三个返回量便是 $u_{pq}+u_{pr}=u_{qr}$。任取一个非平凡且中心平凡的斯坦纳环，其三重直积仍中心平凡。每个坐标只取单位元和一个非单位元，便得到所需的布尔子环。比如，取十元的仿射平面斯坦纳环，所得商环有一千个元素。在二元中心纤维上，单独让其中一圈返回 $1$、其余两圈返回 $0$ 的指定就无法实现。 [三对枢轴的返回范围](lean:D5/S3/Combinatorics/Matroids/SteinerMultipivotReturns.simultaneousReturns) · [中心平凡的构型](lean:D5/S3/Combinatorics/Matroids/SteinerMultipivotReturns.existsCentrelessBooleanCube)

若只指定哪些分量的返回量为零，纤维的最小维数由一个子空间规避问题给出。设 $V$ 为所有指定分量的行向量所张成的空间，$Z$ 为要求返回零的行所张成的子空间。给三元组赋标签相当于在线性空间上取一个映射，每个返回量就是对应行的像。这个映射在 $Z$ 上为零，因此在 $V$ 上的限制经由 $V/Z$ 分解。要求返回非零的行在 $V/Z$ 中的像必须避开该映射的核 $H$。反过来，给定这样的 $H$，只要纤维的维数至少是 $H$ 在 $V/Z$ 中的余维，就可把 $(V/Z)/H$ 线性嵌入纤维，再把所得映射从 $V$ 扩张到所有三元组的坐标空间。因此最小维数等于这些规避子空间的最小余维。若某个要求非零的行已经落在 $Z$ 中，则任何纤维都无法实现指定的零与非零分布。这是有限域上的 Crapo–Rota 临界问题在返回量上的应用。 [Crapo–Rota 临界问题，§1.2](https://arxiv.org/pdf/2201.07193v1) · [返回支撑的证明](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchSupport.realizesReturnSupport)

在八元布尔子环的三个四圈上，若要求三圈都返回非零，二维二元纤维已经足够，可取 $(1,0),(0,1),(1,1)$。一维纤维只有一个非零元，三个返回量若都取它，和仍非零，违反上述关系。

Pasch 的总数给出共同达到各对最大值的充分条件。设原 Steiner 环有限且中心平凡，二元纤维的维数为 $d\ge3$，并把每个 Pasch 的四块集合只计一次。若 $P\le 2^{d+1}-1$，就有一张归一化标号表，在每一对不同的非单位枢轴的零提升处都达到该对的最大成功起点数。

取由所有四块 Pasch 的二元关联向量组成的集合 $S$。在任何极大的避让子空间 $K$ 上取商时，商空间的每个非零向量都来自 $S$，因为遗漏一个非零向量就能沿它再增加一维。若 $|S|<2^{d+1}-1$，商空间的维数因此至多为 $d$。若恰好等于这个数，$S$ 与零的并集不能构成子空间。否则它含有一个四维二元子空间，其中十五个非零向量的重量总和为 $60$，但每个坐标对总和的贡献是 $0$ 或 $8$。因此 $S$ 中有两个向量的和非零且落在 $S$ 外。沿这个和生成的直线取商，使这两个向量的像重合，同时保留所有像非零，由此回到严格不等式。把所得商空间嵌入纤维，就能让每个避开单位元的方格都产生非零回返。每个枢轴对于是取得各自的最大值。 [有限几何中的避让问题](https://arxiv.org/pdf/2201.07193v1#page=5) · [证明及适用范围](https://github.com/the-omega-institute/trureturing/issues/33915)

严格不等式的商空间论证在二维纤维中保证至多六个 Pasch 时可以共同最优。七个 Pasch 已能使共同最优失效。一个含 19 个点、57 个块的 Steiner 三元系包含一个 Fano 平面，整个系统的七个 Pasch 都位于该平面内。加上单位元得到的环中心平凡。给这七个 Pasch 取三个生成的回返量，其余四个分别是三个两两和与三者之和。二维纤维中，三个生成量必有一个非空子集的和为零，所以任意标号表都在某个避开单位元的方格上失去成功起点。为这一对枢轴另选一张表，便能取得严格更大的计数。 [19 点构造与核验](https://github.com/the-omega-institute/trureturing/issues/33933)

固定大小的非平凡二元纤维在足够大的幂中也会漏掉某对枢轴的最大值。固定一个非平凡的有限无中心斯坦纳环 $Q$，并取 $t\ne 1_Q$。在 $Q^n$ 中只将第 $i,j$ 个坐标设为 $t$，得到点 $x_{ij}$。这些点的乘法对应支撑集的对称差，所以任意三个坐标 $i,j,k$ 的三个边点 $x_{ij},x_{ik},x_{jk}$ 组成原三元系的一个块。按该块在 $A$ 中的标签给坐标三元组着色。$n$ 足够大时，有限拉姆齐定理保证有四个坐标，它们的四个三元组都同色。 [Ramsey，1930](https://doi.org/10.1112/plms/s2-30.1.264)

这六个边点上的四块形成 Pasch，相对的两个枢轴可取 $x_{ij},x_{kl}$。对应交替四圈的四个标签相同，总和为零，因此给定标签表在该圈上没有成功起点。而这对枢轴的单独最大值包含所有不经过单位元的四圈的贡献，所以另一个标签表可得到更多成功起点。拉姆齐定理给出的幂次数上界取决于 $|A|$，未达最大值的枢轴对可随标签表变化。 [证明与适用范围](https://github.com/the-omega-institute/trureturing/issues/33898#issuecomment-7137999178) · [拉姆齐反例的 Lean 证明](lean:D5/S3/Combinatorics/Matroids/Steiner/SteinerRamseyObstruction.noCommonMaximumInSomePower)

同一个核也决定每对枢轴的成功起点数。在所有三元组的坐标空间里选一个核 $K$，其余维至多为 $\dim_{\mathbb F_2} A$。对第 $j$ 对枢轴，令 $g_j(x)=p_j(q_jx)$。商顶点 $x$ 的所有提升都成功，恰当且仅当 $g_j^2(x)\ne x$，或通过 $x$ 的返回行不属于 $K$。因为 $p_j\ne q_j$，$g_j$ 没有不动点。当 $g_j^2(x)=x$ 时，商图的第一次返回恰好在两轮后发生。提升在两轮后回到原点，恰当且仅当其返回行的像为零。因而每对枢轴的成功数等于选中的商顶点数乘以 $|A|$。任意满足余维条件的 $K$ 都给出一套共同标签，实现这一整组计数。枢轴都不等于单位元时，去掉同一个扩张的单位元并给其余点统一编号，就能在一套完备三元系中同时读出这些计数。扩张的中心恰是单位元上方的纤维。所得标签的线性映射以指定的 $K$ 为核，因此同一个三元系中的每一条返回行在 $K$ 中时返回零，在 $K$ 外时返回非零。 对给定商环，可以逐个计算满足余维条件的核所产生的计数组合，再将重复组合合并。四圈返回行之间的依赖约束哪些组合能同时实现。 [同时计数的证明](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchSupport.commonSwitchCounts) · [统一编号的证明](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchSupport.labelledCommonSwitchCounts)

三元有限域上的仿射空间给出一族计数与三元组标签无关的例子。向 $\mathbb F_3^n$ 添加一个新的单位元 $e$。两个不同的仿射点相乘，得到它们所在直线上的第三点 $-x-y$，相同的点相乘则得到 $e$。对不同的仿射枢轴 $p,q$，映射 $x\mapsto p(qx)$ 在直线外是阶为三的平移 $q-p$。在该直线和 $e$ 上，它交换 $p$ 与 $q$，也交换 $e$ 与 $-p-q$。沿这两种两轮返回，略去涉及单位元或相同点的步骤后，同一个三元组各出现两次，所以二元返回行都为零。

当 $n\ge2$，对任一仿射点 $p$，都可选另一枢轴 $q$ 以及两点连线外的一点 $x$。此时 $p(xq)=x+q-p$ 与 $(px)q=x+p-q$ 不同。因此中心只有 $e$。对有限二元向量空间 $A$ 的任意正规化扩张，恰有直线外 $3^n-3$ 个点上方的整个纤维提供成功起点。在对应的带标号三元系中，对任意有序的不同仿射枢轴对，删去提升 $(p,0)$ 并保留 $(q,0)$ 为枢轴，成功起点数都是 $(3^n-3)|A|$。仿射平面配平凡纤维时，恰有六个成功起点。 [仿射计数的 Lean 证明](lean:D5/S3/Combinatorics/Matroids/SteinerAffineSwitchCount.labelledAffineSwitchCount)

若 $4\mid r$，且存在一个 $r+1$ 点的完备斯坦纳三元系，就能在一个余数类中成功换块。对满足这两个条件的正整数 $r$，取正整数 $d$ 并沿用本节的跨行条件，则饱和扩充的两个最大大小为 [@thm-joint-circuit-steiner-matching-first-deficit] 中的 $N_{\max}$ 和 $N_{\max}-1$。[删点情形的 Lean 证明](lean:D5/S3/Combinatorics/Matroids/SteinerAlternatingSwitches.point_deleted_first_deficit_of_four_dvd)

例如在 $\mathbb F_3^2$ 的仿射平面中删去原点，$m(a)=-a$，且 $b=-v-a$、$d=-v+a$。此时 $b+d=v\ne0$，因此换块达到极大。取 $r=8,d=1$，得到 $264$ 和 $263$ 两种饱和大小。对于法诺平面的二元向量表示，剩余两点满足 $b+d=p$，相同换块总会留下可补的三角形。 [局部极大装填谱](https://doi.org/10.1007/BF01388482)
