# O.2.4.1 The minimum number of internal additions {#356841-the-minimum-number-of-internal-additions}

Fix $d,r\ge 1$ and put $q=3^d$. The points are $\mathbb F_3^d\times\mathbb Z/(3r)\mathbb Z$, with one row for each $x\in\mathbb F_3^d$. Keep all the mixed lifted triples, whose first coordinates are distinct and whose sum in the product group is zero. New triples may lie within a row. Every triple must have three distinct points, and any two distinct points may occur together at most once. [@thm-joint-circuit-internal-dimension]

::: {.theorem #thm-joint-circuit-minimum-internal-lower-bound title="A lower bound for gaining one potential dimension" lean="D5/S3/Combinatorics/Matroids/RankThreeMinimumInternalAdditions.internal_additions_lower_bound"}
Under these conditions, if the normalized potential space grows to dimension $d+1$, at least $qr^2$ internal triples must be added.
:::

::: proof
The dimension criterion requires every uncovered pair within a row to have the same residue modulo three. Thus two points in the same row with different residues must occur together in an added triple. Each row has six ordered pairs of distinct residue classes, with $r$ points per class. Across all rows this gives $6qr^2$ ordered point pairs.

For every such pair, choose a containing triple and record the ordered slots of the two points. The triple and slots recover the original pair, so the assignment is injective. Each added triple supplies only six ordered pairs of distinct slots, giving the lower bound $qr^2$. The full proof is checked by the Lean kernel. [@thm-joint-circuit-internal-dimension]
:::

::: {.theorem #thm-joint-circuit-minimum-internal-attained title="A transversal design on the residue classes attains the bound" lean="D5/S3/Combinatorics/Matroids/RankThreeMinimumInternalAdditions.exists_internal_additions_attaining"}
Exactly $qr^2$ internal triples can be added to the mixed family above so that each triple in the combined family has three distinct points, every pair of distinct points occurs at most once, and the normalized potential space has dimension exactly $d+1$.
:::

::: proof
In each row, divide the cyclic coordinates into their three residue classes modulo three. Each class has $r$ points, which can be labelled by $\mathbb Z/r\mathbb Z$. For every pair of labels $a,b$, take the points labelled $a$ in class $0$, $b$ in class $1$, and $-a-b$ in class $2$. Any two points from different classes determine the third label. Hence every different-residue pair within a row occurs exactly once, while same-residue pairs lie in none of these triples. Each new triple has residue sum $0+1+2=0$, and each uncovered pair in a row has residue difference zero. Both residue conditions hold, so the potential dimension is $d+1$.

Each row contributes $r^2$ new triples, and none shares a pair with a mixed triple. The labels need only give a bijection from each residue class to the set $\mathbb Z/r\mathbb Z$, so the construction also applies when $9\mid 3r$. For example, when $d=1$ and $r=2$, each row has classes $\{0,3\}$, $\{1,4\}$, and $\{2,5\}$. Label each class by $0,1$ in the order shown. This gives the four triples $\{0,1,2\}$, $\{0,4,5\}$, $\{3,1,5\}$, and $\{3,4,2\}$ in each row, for twelve additions across the three rows. The full proof is checked by the Lean kernel. [@thm-joint-circuit-internal-dimension]
:::

## O.2.4.1.1 All extensions at the minimum {#3568411-all-extensions-at-the-minimum}

The construction above uses a cyclic rule for the last label. The exact count also tells us how much freedom is left. In each row and each residue class, fix a labelling by $\{0,\ldots,r-1\}$, independently of the labellings in the other classes and rows.

::: {.theorem #thm-joint-circuit-minimum-internal-latin title="A minimum family is generated by rowwise Latin squares" lean="D5/S3/Combinatorics/Matroids/RankThreeOptimalInternalLatin.exists_latin_of_optimal_family"}
Keep the mixed family fixed. If the added family has $3^d r^2$ triples and the normalized potential dimension is $d+1$, there is an order-$r$ Latin square $L_x$ for each row $x$. The unordered triples in row $x$ are exactly those formed from label $a$ in residue class $0$, label $b$ in class $1$, and label $L_x(a,b)$ in class $2$, for all $a,b$.
:::

::: proof
At the minimum, the injection from the lower bound is a bijection. Every ordered pair of distinct positions of an added triple is used by a same-row point pair with different residues. The three points in each triple therefore have residues $0,1,2$ in some order. Each pair in different residue classes has a unique third point. Define $L_x(a,b)$ using the pair in classes $0,1$. The unique completions for pairs in classes $0,2$ and $1,2$ make every row and every column of $L_x$ a permutation of the labels. The full proof is checked by the Lean kernel.
:::

::: {.theorem #thm-joint-circuit-minimum-internal-latin-unique title="The unordered family determines the squares" lean="D5/S3/Combinatorics/Matroids/RankThreeOptimalInternalLatin.latin_assignment_injective"}
For the fixed labellings, two assignments of tables give the same unordered triple family only if their entries agree in every row and cell.
:::

::: proof
The point residues distinguish the three roles in a triple after its order is forgotten. For a fixed row and cell $(a,b)$, the points in classes $0,1$ recover $a,b$, and the point in class $2$ recovers the entry. The full proof is checked by the Lean kernel.
:::

::: {.theorem #thm-joint-circuit-minimum-internal-latin-converse title="Any assignment of Latin squares gives a minimum family" lean="D5/S3/Combinatorics/Matroids/RankThreeOptimalInternalLatin.optimal_family_of_latin"}
Choose an order-$r$ Latin square independently in every row. Adding its cell triples to the fixed mixed family gives $3^d r^2$ distinct internal triples. The combined family remains pair-unique and its normalized potential space has dimension $d+1$.
:::

::: proof
The permutation laws give unique completion for each pair of points with different residues in a row. The internal triples never repeat a point and cover no same-residue pair. A mixed triple covers only pairs from different rows, so the new triples preserve pair uniqueness. Every internal residue sum is zero, and every uncovered same-row pair has residue difference zero. The dimension criterion then gives $d+1$. There are $r^2$ cells per row. The full proof is checked by the Lean kernel. [@thm-joint-circuit-internal-dimension]
:::

## O.2.4.1.2 All extensions with the extra dimension {#3568412-all-extensions-with-the-extra-dimension}

A minimum extension already covers every pair of different residues in a row. To add more triples while retaining the extra dimension, the dimension criterion allows additions inside individual residue classes. Keep the mixed family and the independent labellings fixed. A partial Steiner triple system is a family of three-element sets in which any two distinct labels occur together at most once.

::: {.theorem #thm-joint-circuit-steiner-decomposition title="The Latin squares and partial Steiner systems of an extension" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSteinerDecomposition.forward_decomposition"}
Suppose the added triples have three distinct points within one row and the combined family is pair-unique. If the normalized potential space has dimension $d+1$, the unordered added family consists of the cell triples of one Latin square per row and the triples of a partial Steiner system in each actual residue class of each row.
:::

::: proof
The residue sum of every internal triple is zero, so its residues are all equal or all distinct. Every same-row pair with different residues needs a triple. The pairs in classes $0,1$ count each different-residue triple once, giving exactly $3^d r^2$. Deleting the same-residue triples retains all different-residue pairs and the extra dimension. Thus the minimum-family classification applies to the retained triples. The remaining triples inherit pair uniqueness within each residue class. The full proof is checked by the Lean kernel.
:::

::: {.theorem #thm-joint-circuit-steiner-realization title="The square and packing choices are independent" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSteinerDecomposition.realize_decomposition"}
Any rowwise assignment of order-$r$ Latin squares and any assignment of partial Steiner systems on the $r$ labels of each residue class gives a pair-unique extension of the mixed family with normalized potential dimension $d+1$.
:::

::: proof
Mixed triples use pairs from different rows. Latin triples use pairs of different residues in one row. The partial systems use pairs within a single residue class. These pair types are disjoint. The added same-residue triples have residue sum zero and can only remove uncovered pairs, so the condition for the extra dimension survives. The full proof is checked by the Lean kernel.
:::

::: {.theorem #thm-joint-circuit-steiner-unique title="The unordered family determines all the choices" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSteinerDecomposition.decomposition_unique"}
For the fixed labellings, the unordered extension uniquely determines the square in each row and the partial Steiner system in each row and residue class.
:::

::: proof
The residue pattern identifies which triples come from the squares. Each remaining triple identifies its row and residue class, and the labels in that class recover the three-element set. The full proof is checked by the Lean kernel.
:::

For example, take $d=1$ and $r=3$. Each residue class contains exactly three points. Its unique triple can be added or left out, independently in each of the nine classes across the three rows. Thus the Latin squares supply $27$ triples, and any number from zero through nine can be added to them while keeping the normalized potential space two-dimensional.

## O.2.4.1.3 Attainable numbers of internal triples {#3568413-attainable-numbers-of-internal-triples}

In the preceding example, any number of same-residue triples can be removed while retaining the dimension. The same deletion property holds for arbitrary residue classes. Write $D(r,3,2)$ for the largest number of blocks in a partial Steiner triple system on $r$ labels.

::: {.theorem #thm-joint-circuit-internal-size-spectrum title="The full interval of attainable sizes" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.exact_size_spectrum"}
Keep the mixed triples, pair uniqueness and normalization specified above. The possible numbers of added same-row triples that retain potential dimension $d+1$ are exactly the integers in
$$
3^d r^2 \le N \le 3^d r^2+3^{d+1}D(r,3,2).
$$
:::

::: proof
Each row contributes $r^2$ Latin-square triples. Those triples occupy distinct rows or distinct cells and have three different residues. Each remaining triple belongs to a partial Steiner system in a single residue class. There are $3^{d+1}$ such classes, each contributing at most $D(r,3,2)$ triples. This gives the two endpoints.

To realize any integer between them, place a largest packing in each residue class. Choose any $N-3^d r^2$ triples from their union. Deleting triples preserves pair uniqueness within each class. These choices and the rowwise Latin squares give an extension by [@thm-joint-circuit-steiner-realization]. The full proof is checked by the Lean kernel.
:::

## O.2.4.1.4 Sizes of saturated extensions {#3568414-sizes-of-saturated-extensions}

Keep the mixed triples fixed and require pair uniqueness and normalized potential dimension $d+1$. An extension is **saturated** if one more same-row triple cannot be added under these conditions. Any proper compatible enlargement permits adding one of its new triples first, so saturation is equivalent to inclusion maximality. [@thm-joint-circuit-steiner-insert]

::: {.theorem #thm-joint-circuit-steiner-insert title="Adding one triple from a larger extension" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.internal_extension_insert"}
If compatible families of same-row triples satisfy $G\subseteq H$, adjoining any triple of $H$ to $G$ gives a compatible family.
:::

::: proof
Each Latin-square triple of $G$ remains a Latin-square triple in $H$. Its points of residues $0$ and $1$ determine the cell, and its point of residue $2$ determines the entry. Thus the squares agree. If the chosen triple is new, it belongs to a single residue class. Adjoining it leaves that class's packing inside the corresponding packing of $H$, preserving pair uniqueness and the extra dimension.
:::

::: {.theorem #thm-joint-circuit-steiner-saturated title="Saturation is maximality within each residue class" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.saturated_internal_extension_iff"}
Under the actual residue labellings, an extension is saturated exactly when every partial Steiner triple system in its decomposition is inclusion-maximal.
:::

::: proof
A larger packing in one class gives a proper global enlargement by changing that class alone. Conversely, a proper global enlargement fixes the Latin squares and therefore enlarges the packing in at least one residue class.
:::

::: {.theorem #thm-joint-circuit-steiner-six-saturated-sizes title="Saturated sizes with six labels have step two" lean="D5/S3/Combinatorics/Matroids/RankThreeInternalSizeSpectrum.saturated_six_size_spectrum"}
For $r=6$, the attainable sizes of saturated extensions are exactly
$$
36\cdot 3^d+2\cdot 3^{d+1}+2k,\qquad 0\le k\le 3^{d+1},\quad k\in\mathbb Z.
$$
:::

::: proof
The two local maximal sizes also follow from the classical packing spectrum surveyed by Colbourn. [Sections 2.3.1–2.3.3](https://ajc.maths.uq.edu.au/pdf/4/ocr-ajc-v4-p143.pdf)

On six labels, each label lies in at most two triples. Each incident triple uses two of the label's five available partners. Counting incidences gives at most four blocks. An empty or one-block packing can be extended. In a three-block packing, no two blocks can be disjoint, since a third would then repeat a pair of one of them. The three pairwise intersections are distinct singletons. Each block also has one point belonging only to it. All three pairs among these private points are unused, so the three points form an addable fourth block.

Both maximal sizes occur. Writing $abc=\{a,b,c\}$, the two-block example $012,345$ leaves a complete bipartite graph of unused pairs and hence no available triangle. The example $012,034,135,245$ attains the four-block upper bound. Each of the $3^{d+1}$ actual residue classes can independently take either size. Choosing four blocks in exactly $k$ classes and adding the $36$ Latin-square blocks per row gives the formula. For $d=1$, the saturated sizes are precisely $126,128,\ldots,144$.
:::

### The gap below a complete packing

When $r\ge7$ and the labels support a complete Steiner triple system, the two largest saturated sizes again differ by two. A complete packing uses every unordered pair, so each class contains $r(r-1)/6$ blocks. To use two fewer blocks, choose three points that form no block and replace the blocks covering their three pairs.

::: {.theorem #thm-joint-circuit-steiner-saturated-top-gap title="The two largest saturated sizes from a complete Steiner system" lean="D5/S3/Combinatorics/Matroids/RankThreeSaturatedTopGap.saturated_top_gap"}
Keep the cross-row triples, pair uniqueness, and normalization of this section. Let $d>0$ and $r\ge7$, and assume that the $r$ labels admit a Steiner triple system covering every unordered pair. Write
$$
N_{\max}=3^d r^2+3^{d+1}\frac{r(r-1)}{6}.
$$

Every saturated extension has at most $N_{\max}$ added within-row triples. Both $N_{\max}$ and $N_{\max}-2$ occur, and $N_{\max}-1$ is impossible.
:::

::: proof
A complete packing in every residue class attains the upper bound. To lose two blocks, change one class. Choose $a,b,c$ that do not form a block and write $abx,bcy,caz$ for the blocks covering $ab,bc,ca$, respectively. Since $abc$ is not a block, $x,y,z$ all lie outside $\{a,b,c\}$. Pair uniqueness makes them distinct. Remove the three blocks and insert $abc$. The uncovered pairs form exactly the cycle $a,x,b,y,c,z,a$. This cycle has no triangle, so no block can be added.

Every block through a point uses two of its partners. The complete packing covers all $r-1$ partners at each point, so $r$ is odd and every vertex has even degree in the uncovered graph of any partial packing. One missing block would leave three edges. The degree sum is six and each nonisolated vertex has degree at least two, so there are at most three nonisolated vertices. The three different edges therefore form a triangle that can be added. By the classwise saturation criterion, the global loss in block count is the sum of the local losses, and every positive term is at least two. The full proof is checked by the Lean kernel.
:::

For example, the Fano plane on seven labels has seven blocks. With $d=1$, the Latin squares give $147$ blocks and the nine residue classes contribute up to $63$. The two largest saturated sizes are $210$ and $208$. For the local maximal-packing spectrum, see [Colbourn, Section 2.3.3](https://ajc.maths.uq.edu.au/pdf/4/ocr-ajc-v4-p143.pdf).

### Matching leaves after deleting a point

If a complete Steiner triple system exists on $r+1$ points for even $r$, it gives a largest partial packing on $r$ labels. Delete a point $p$ and every block containing it. For each remaining point $a$, the original block covering $\{p,a\}$ contains another remaining point $m(a)$. The uncovered pairs are exactly the pairs $\{a,m(a)\}$. Each label has one unused partner.

::: {.theorem #thm-joint-circuit-steiner-point-deleted-switch title="The switch criterion for a point-deleted packing" lean="D5/S3/Combinatorics/Matroids/PointDeletedSteinerSwitch.point_deleted_switch"}
Delete a point from any finite complete Steiner triple system. Choose a remaining $v$ distinct from $a$ and $c=m(a)$, and let $b,d$ complete the pairs $av,cv$ in the original packing. The five labels $a,b,v,d,c$ are distinct. Removing $abv,vdc$ and inserting $avc$ gives a partial Steiner triple system with exactly one fewer block. Its uncovered pairs replace the original matching edge $ac$ by the path $a,b,v,d,c$. The switched packing is inclusion maximal exactly when $d\ne m(b)$.
:::

::: proof
The matching edge $ac$ was unused. The new block also reuses the two edges $av,cv$ released by the old blocks, so no pair is repeated. The other four edges of the removed blocks form the stated path. The path has no triangle, and a vertex has at most one matching edge. Any triangle must use two consecutive path edges. The endpoints $a,c$ have lost their matching edge, leaving the triangle on $b,v,d$ as the only possibility. It closes exactly when $d=m(b)$. The full proof is checked by the Lean kernel.
:::

::: {.theorem #thm-joint-circuit-steiner-matching-first-deficit title="One switch realizes the largest size minus one" lean="D5/S3/Combinatorics/Matroids/PointDeletedSteinerSwitch.matching_switch_first_deficit"}
Keep the cross-row triples and normalization of this section. Suppose the $r$ labels admit a packing whose uncovered pairs form a perfect matching, with a switch satisfying the maximality criterion above. The largest saturated extension has
$$
N_{\max}=3^d r^2+3^{d+1}\frac{r(r-2)}{6}
$$
added within-row triples, and $N_{\max}-1$ also occurs. The bound $N_{\max}$ applies to every extension preserving the required normalized dimension.
:::

::: proof
Each block uses two partners at each of its three points. The matching leaves one partner at every point, so $r$ is even and every other packing must leave at least one partner at every point. Thus the matching packing attains the upper bound $r(r-2)/6$. The matching contains no triangle, so this packing is maximal in each class. Using it in every class attains the global bound. A switch in one class gives the maximal packing one block smaller and realizes $N_{\max}-1$. The full proof is checked by the Lean kernel.
:::

To determine which starts work for a fixed remaining point $v$, adjoin a point $\ast$ to the original Steiner system. For each original point $x$, pair $\ast$ with $x$ and pair the remaining points that lie together in a block through $x$. Draw both matchings, one for the deleted point $p$ and one for $v$. Each vertex meets one edge from each matching, so the connected components are alternating even cycles.

::: {.theorem #thm-joint-circuit-steiner-alternating-starts title="Alternating components identify all successful starts" lean="D5/S3/Combinatorics/Matroids/SteinerAlternatingSwitches.point_deleted_successful_starts"}
Delete a point $p$ from a finite complete Steiner triple system on $r+1$ points. Fix any retained point $v$. The vertices in components of size at least six in the union of the two matchings are exactly the retained starts for which the switch in [@thm-joint-circuit-steiner-point-deleted-switch] gives a maximal packing. If $4\mid r$, every $v$ has at least six such starts.
:::

::: proof
The square through $\ast$ visits $p$, $m(v)$, and $v$ in that order. Each vertex outside it is eligible as a start $a$. Taking one step in each matching in the two possible orders leads to $d$ and $m(b)$. These endpoints agree exactly when $a$ lies on a square. If four divides $r$, the total vertex count $r+2$ leaves remainder two on division by four, so some component has at least six vertices. The full proof is checked by the Lean kernel.
:::

If the deleted point is a choice, ask when its matching commutes with all the others. Give $\ast$ the role of identity, set $x\cdot x=\ast$ for each original point, and take the product of distinct original points to be the third point of their block. This is the Steiner loop $L$. One step in the matching of $x$ is multiplication by $x$. By the square criterion, every eligible switch fails after deleting $p$ exactly when
$$
p\cdot(v\cdot a)=v\cdot(p\cdot a)
$$
for all $v,a\in L$. The square through the identity supplies the equality at its ineligible vertices. Commutativity turns this equality into the association laws for a central element $p$.

Thus **deleting $p$ admits a maximal switch exactly when $p$ lies outside the centre of $L$**. The identity lies in the centre, so exactly $r+2-|Z(L)|$ of the original $r+1$ points admit a switch upon deletion. In the language of triple systems, the excluded original points are the Veblen points. For each retained block $\{a,v,b\}$, they require the completing block $\{m(a),v,m(b)\}$ in a Pasch configuration. That completion is the condition for the triangle left by a switch to close. [Centre criterion](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchCentre.admits_switch_iff_not_central) · [Deletion count](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchCentre.ncard_admits_switch) · [Veblen points and the loop centre](https://doi.org/10.1002/jcd.21964)

The centre also constrains the number of successful starts for fixed $p$ and $v$. Multiplication by a central element commutes with taking a step in either matching, so it preserves the size of each alternating component. The successful vertices therefore split into orbits under central translations. For a given vertex, multiplying it by distinct central elements produces distinct vertices, so each orbit contains $|Z(L)|$ of them. After transferring the count to the retained labels, **the number of successful starts is a multiple of $|Z(L)|$**, including zero. [Divisibility at a fixed pivot](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchOrbit.successful_starts_dvd_center)

Identify points of $L$ that differ by a central translation. **The successful-start count depends only on the quotient classes of the deleted point and pivot.** Take central elements $z,w$ and replace $p,v$ by $z\cdot p,w\cdot v$, keeping the replacements distinct original points. The two orders of taking a step now end at $z\cdot(w\cdot(p\cdot(v\cdot a)))$ and $z\cdot(w\cdot(v\cdot(p\cdot a)))$. The two central translations are bijections, so the endpoints agree at exactly the same vertices. The square criterion gives the same successful-start count.

If either point is central, the two steps commute everywhere. If $p$ and $v$ have the same quotient class, the pair $(p,v)$ arises from $(v,v)$ by central translations of its entries. The same endpoint calculation then gives commuting steps at every vertex. Both cases have zero successful starts.

For the remaining pairs of quotient classes, the quotient graph determines the count together with the lifts of its components. If the deleted point $p$ and the pivot $v$ have distinct nonidentity classes, both matchings descend and each quotient vertex has two distinct partners. Fix an alternating component of length $\ell$ in the quotient. Each round takes one step in each matching. After $\ell/2$ rounds the quotient vertex returns to itself, and the lifted walk has multiplied its start by some central element $z$.

If $z$ is the identity, there are $|Z(L)|$ lifted components of length $\ell$. Otherwise the lifted walk returns to its start after two trips around the quotient component, and there are $|Z(L)|/2$ lifted components of length $2\ell$. Each quotient vertex has $|Z(L)|$ preimages, and the lifted components partition these preimages into equal-sized parts. A quotient component of length at least six contributes all its preimages. A quotient square contributes all its preimages when $z$ is nonidentity. [Counting the lifts](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchQuotient.point_deleted_component_lifts)

Fix a finite Steiner loop $Q$ with trivial centre, two distinct nonidentity pivots, and a finite abelian group $A$ in which $a+a=0$ for every $a\in A$. One can construct a Steiner loop with quotient $Q$ and centre $A$ that realizes any prescribed returns of the alternating components in a single extension. The component through the identity always returns by zero. Each step adds the label of the triple it traverses. Outside the identity component, different matching edges use different triples, so one label per component sets its return independently. Taking one matching step reverses the return. Every group element equals its negative, so the return is the same at every start in the component. [Prescribing returns independently](lean:D5/S3/Combinatorics/Matroids/SteinerSchreierExtension.realizeSchreierReturns) · [Extension multiplication of Falcone, Figula, and Galici, Theorem 3.1](https://arxiv.org/pdf/2406.12796)

Let $M$ count the quotient vertices in components of length at least six, and let $s$ count the squares that avoid the identity. For this fixed pivot pair, the long components always contribute $M|A|$ successful starts, and the identity square contributes zero. Each remaining square contributes $4|A|$ starts exactly when its return is nonzero. If $|A|\ge2$, any subset of these squares can have nonzero return, so the exact count range is $|A|(M+4j)$ for $j=0,1,\ldots,s$. With a trivial fibre, only $j=0$ is attainable. To read the count in a triple system, remove the identity of the extension, take $\{x,y,xy\}$ as the block through distinct points $x,y$, and label the remaining points. The Steiner loop law gives a unique block through each pair, and multiplication by a pivot is a step in the corresponding matching. [The pointwise correspondence and count on finite labels](lean:D5/S3/Combinatorics/Matroids/SteinerSchreierSwitchCount.realizeLabelledSwitchCount) · [The exact fixed-pair count range](lean:D5/S3/Combinatorics/Matroids/SteinerFixedPivotCountRange.labelledFixedPivotCountRange)

The blocks themselves determine when such a square exists. Take six distinct points $p,q,a,b,c,d$. If $\{q,a,b\},\{p,b,c\},\{q,c,d\},\{p,d,a\}$ are blocks, they form a Pasch configuration. The pivots $p,q$ are opposite in the configuration, so none of its four blocks contains both. Alternating the $q$ and $p$ steps around these four blocks gives a square that avoids the identity. Conversely, the four edges of any such square give the four blocks of a Pasch. For a fixed pivot pair and a nontrivial binary fibre, the successful-start count therefore varies with the labels exactly when the original triple system contains a Pasch with those pivots opposite. [Pasch configuration, Definition 2.5 and Figure 1](https://arxiv.org/html/2406.12796v2#S2.F1) · [Lean proof of the Pasch criterion](lean:D5/S3/Combinatorics/Matroids/Steiner/SteinerPaschSwitchCount.variableLabelledSwitchCount_iff)

Write $W(p,q)$ for the maximum successful-start count minus the minimum at the fixed pair. Under the assumptions above, with $A$ nontrivial, each Pasch with opposite points $p,q$ contributes $4|A|$ to $W(p,q)$. Each Pasch has three pairs of points that share none of its blocks. For example, with blocks $\{a,b,c\},\{a,d,e\},\{b,e,f\},\{c,d,f\}$, these pairs are $\{a,f\},\{b,d\},\{c,e\}$. Each pair has two orderings. If $P$ counts the Pasches of the original triple system as sets of four blocks, then

$$
\sum_{\substack{p,q\in Q\setminus\{1_Q\}\\p\ne q}} W(p,q)=24|A|P,
$$

where $1_Q$ is the identity of the quotient loop. Each width in the sum takes its extrema independently over the label tables for that pair. If $A$ is trivial, every width is zero. [Erskine and Griggs, page 2](https://arxiv.org/pdf/2405.07750v1#page=2)

For a finite family of requested components, choose one starting point on each alternating circuit. For request $i$, let $v_i$ be the binary vector whose coordinate at a triple counts its traversals modulo two. Omit the steps involving the identity or a repeated point, which add zero in the normalized extension. Write $u_i$ for the requested return. A common labelling exists exactly when every binary relation $\sum_i c_i v_i=0$ also satisfies $\sum_i c_i u_i=0$.

The return on a full circuit is the sum of its labels, so any common labelling respects these relations. For the converse, send $v_i$ to $u_i$. The relation condition makes this assignment a well-defined linear map on the span of the rows. Extend a basis of that span to a basis of the full vector space on triples and assign zero on the added vectors. Evaluating the extended map on the original triple coordinates supplies the labels. Each representative then has the requested return, and taking matching steps carries that return to all starts in its component. [Lean proof of the simultaneous return criterion](lean:D5/S3/Combinatorics/Matroids/SteinerReturnDependencies.realizesExactlyCompatibleReturns)

When one extension must serve several pivot pairs, their shared triples can constrain the return values. Suppose the quotient contains a Boolean subloop of order eight. Let $p,q,r$ be the three nonidentity elements of a subgroup of order four. For each pivot pair the other four points form an alternating square. Write $u_{pq},u_{pr},u_{qr}$ for the three returns. Each colour's edge labels occur in two of these sums, so $u_{pq}+u_{pr}+u_{qr}=0$. This condition is also sufficient in this configuration. Label one edge for pivot $q$ by $u_{pq}$ and one edge for pivot $r$ by $u_{pr}$, and set the other labels to zero. The third return is then $u_{pq}+u_{pr}=u_{qr}$. For any nontrivial centreless Steiner loop, its triple product is centreless and contains this Boolean subloop: use the identity and one nonidentity element in each coordinate. For example, the affine-plane Steiner loop of order ten gives a centreless quotient of order one thousand. With a fibre of order two, prescribing a return of $1$ on just one of the squares and $0$ on the other two is impossible. [The three-pair return range](lean:D5/S3/Combinatorics/Matroids/SteinerMultipivotReturns.simultaneousReturns) · [Centreless configuration](lean:D5/S3/Combinatorics/Matroids/SteinerMultipivotReturns.existsCentrelessBooleanCube)

If we prescribe only which returns vanish, a subspace avoidance condition gives the minimum fibre dimension. Let $V$ be the span of all the prescribed circuit rows, and let $Z$ be the span of the rows prescribed to vanish. Labelling the triples defines a linear map that sends each row to its return. Since the map vanishes on $Z$, its restriction to $V$ factors through $V/Z$. The images of the rows prescribed to return nonzero must avoid the kernel $H$ of this map on $V/Z$. Conversely, given such an $H$, embed $(V/Z)/H$ linearly in the fibre and extend the resulting map from $V$ to the full space on triples. The embedding exists exactly when the fibre dimension is at least the codimension of $H$. Thus the minimum fibre dimension equals the minimum codimension of an avoiding subspace. If a row prescribed to return nonzero already belongs to $Z$, no fibre realizes the prescription. This is an application of the Crapo–Rota Critical Problem over a finite field. [Crapo–Rota Critical Problem, §1.2](https://arxiv.org/pdf/2201.07193v1) · [Proof of the return-support criterion](lean:D5/S3/Combinatorics/Matroids/SteinerSwitchSupport.realizesReturnSupport)

For the three squares in the Boolean subloop, a binary fibre of dimension two allows all three returns to be nonzero, for example $(1,0),(0,1),(1,1)$. In dimension one, all three would have to be the sole nonzero vector, whose threefold sum violates the relation.

The total number of Pasches gives a sufficient condition for attaining the pairwise maxima simultaneously. Take a finite centreless Steiner loop and a binary fibre of dimension $d\ge3$. Count each Pasch once by its set of four blocks. If $P\le 2^{d+1}-1$, one normalized label table attains the maximum successful-start count for the two zero lifts of every pair of distinct nonidentity pivots.

Let $S$ consist of the binary incidence vectors of the four blocks of each Pasch. Modulo any maximal subspace $K$ that avoids $S$, every nonzero quotient vector must come from $S$, since a missing vector would allow $K$ to grow by one dimension. Thus $|S|<2^{d+1}-1$ forces the quotient dimension to be at most $d$. At equality, adjoining zero to $S$ cannot give a subspace. Such a subspace would contain a four-dimensional binary subspace whose fifteen nonzero vectors have total weight $60$, whereas each coordinate contributes either $0$ or $8$. Two vectors in $S$ therefore have a nonzero sum outside $S$. Quotienting by the line through their sum makes their images coincide and keeps every image nonzero, giving the strict inequality. Embedding the resulting quotient into the fibre gives nonzero return on every square away from the identity. Each pivot pair then attains its individual maximum. [Subspace avoidance in finite geometry](https://arxiv.org/pdf/2201.07193v1#page=5) · [Proof and scope](https://github.com/the-omega-institute/trureturing/issues/33915)

In fibre dimension two the strict quotient bound guarantees simultaneous attainment for at most six Pasches. Seven Pasches can already prevent it. A Steiner triple system with 19 points and 57 blocks contains a Fano plane, and all seven Pasches of the system lie in that plane. The loop obtained by adjoining an identity has trivial centre. Choose three generating Pasch returns. The other four are the three pairwise sums and the sum of all three. In a two-dimensional fibre some nonempty subset of the three generators sums to zero. Every label table therefore loses successful starts on at least one square away from the identity. A different table gives a strictly larger count for that pivot pair. [The 19-point construction and its verification](https://github.com/the-omega-institute/trureturing/issues/33933)

A fixed finite nontrivial binary fibre also fails to attain all the pairwise maxima in sufficiently large powers. Fix a nontrivial finite centreless Steiner loop $Q$ and $t\ne 1_Q$. In $Q^n$ put $t$ in exactly coordinates $i,j$ to obtain the point $x_{ij}$. The three edge points $x_{ij},x_{ik},x_{jk}$ of any coordinate triple form an original block, since multiplication takes the symmetric difference of their supports. Colour each coordinate triple by that block's label in $A$. For $n$ large enough, finite Ramsey gives four coordinates whose four triples all have the same label. [Ramsey, 1930](https://doi.org/10.1112/plms/s2-30.1.264)

The four blocks on those six edge points form a Pasch with opposite pivots $x_{ij},x_{kl}$. Its alternating square has zero return because its four equal labels sum to zero. That square therefore contributes zero for the given table. For this pair the individual maximum includes all its squares that avoid the identity, so a different table gives more successful starts. The Ramsey bound on the power depends on $|A|$, and the deficient pivot pair can depend on the given table. One kernel also determines the number of successful starts for each pivot pair. Here choose a kernel $K$ in the full space on triples with codimension at most $\dim_{\mathbb F_2} A$. For the $j$th pair, write $g_j(x)=p_j(q_jx)$. All lifts of a quotient vertex $x$ succeed exactly when $g_j^2(x)\ne x$ or the return row at $x$ lies outside $K$. The distinct pivots ensure that $g_j$ has no fixed point. If $g_j^2(x)=x$, the first quotient return is after two rounds. The lift comes back after those two rounds exactly when the linear map sends the return row to zero. Each successful-start count is therefore $|A|$ times the number of selected quotient vertices. Every single choice of $K$ satisfying the dimension bound yields one common labelling realizing the entire count profile. With nonidentity pivots, deleting the identity of the extension and numbering the remaining points once transfers all the counts to the same complete triple system. The centre of the extension is exactly the fibre above the identity. The resulting labelling has kernel $K$. In the same triple system, a circuit has zero return exactly when its row lies in $K$. For a given quotient, evaluate each kernel that meets the codimension bound and retain each resulting profile once. Dependencies among the square return rows constrain which counts can occur together. The affine space over $\mathbb F_3$ gives a family in which the count is independent of the triple labels. Adjoin a new identity $e$ to $\mathbb F_3^n$. Two distinct affine points multiply to the third point $-x-y$ on their line, and a point multiplied by itself gives $e$. For distinct affine pivots $p,q$, the map $x\mapsto p(qx)$ acts off their line by translation by $q-p$, which has order three. On the line together with $e$, it swaps $p$ with $q$ and $e$ with $-p-q$. Along either of these two-step returns, the same triple occurs twice after the identity and equal-point steps are discarded, so the binary return row is zero.

For $n\ge2$, every affine point $p$ admits a second pivot $q$ and a point $x$ outside their line. At those three points, $p(xq)=x+q-p$ and $(px)q=x+p-q$ are distinct. Thus only $e$ is central. In every normalized extension by a finite binary vector space $A$, exactly the fibres over the $3^n-3$ off-line points contribute successful starts. The corresponding labelled triple system has $(3^n-3)|A|$ successful starts when the lift $(p,0)$ is deleted and $(q,0)$ is retained as pivot, for every ordered pair of distinct affine pivots. The formula gives six starts in the affine plane with the trivial fibre. [Lean proof of the affine count](lean:D5/S3/Combinatorics/Matroids/SteinerAffineSwitchCount.labelledAffineSwitchCount)
