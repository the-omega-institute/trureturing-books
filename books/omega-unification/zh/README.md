# 前言 四问、零圆满与数学边界的制图学 {#sec-ou-prelude}

> “$4/4$ 问有模型内结果。依原书标准，从同一主联络无事后拟合地完整推出的有 $0/4$。”
> —— [研究总录](https://github.com/the-omega-institute/trureturing-experiments/blob/ba0ac9539cdb641744054bf3a0398494f4cba1c8/experiments/ch39-omega-research/README.md)

物理学史上有两种截然不同的“大统一”写法。一种是胜利者的神话学：先画出一张气势恢宏的统一蓝图，把不合拍的质量阈值藏进“高阶修正”，把手工调节的耦合系数包装成“自然标度”，再宣布宇宙已在一页方程里彻底闭合。另一种是制图者的解剖学：把同一套离散几何结构推到算术精度、区间证明与形式化内核的聚光灯下，看看它究竟能自己走出多远，又在**哪一条精确的数值悬崖上**撞墙停步。

本书《OMEGA 统一》选择第二条路。全书围绕《量子计算的几何直觉》第三十三章第九节（研究源码沿用原编号 `ch39`）立下的**四道大统一开放问题**，以十九点贝伦德球壳 $x_1^2 + x_2^2 + x_3^2 = 867$、四元数双时钟与黎曼 $\zeta$ 函数非平凡零点谱为共同试验场，完整呈现从基础整数算术、规范交汇与希格斯门户、四维格点手征三代与味谱障碍、质子重子三重选择定则、离散雷吉引力与暗能量配平，到五百二十九面双钟绕数阶梯、六百二十四内部通道记忆秩与四问全景总账的整张数学边界地图。

## 0.1 四问的来历与“零圆满”的科学重量 {#sec-ou-0-1}

一切始于一个极具诱惑力也极具杀伤力的追问：如果宇宙底层不存在高维额外空间，也不借助包含 $(X, Y)$ 轻子夸克玻色子的巨型单群矩阵，而是把三维空间、超荷、弱同位旋与强色荷安放在同一枚离散极小圆弧复形之上，**能否从同一条主联络出发，不引入任何事后曲线拟合参数，一举定量导出标准模型与引力的全部核心数字？**

这一总纲拆解为四道硬指标，贯穿本书第二卷至第五卷：

1. **第一问（规范交汇、希格斯质量与电弱尺度）**：最小标准模型无阈值单圈跑动在 $10^{13}\text{–}10^{17}\,\mathrm{GeV}$ 之间留下 $\Delta\alpha^{-1} > 3.66$（精确值约 $3.664$）的三线交汇缺口；能否从球壳自身的离散配分函数推出重粒子阈值、闭合三力两圈交汇，并同步锁定 $m_H \approx 125.2\,\mathrm{GeV}$ 与电弱标度比 $v / M_P \sim 10^{-17}$？
2. **第二问（四维格点手征三代）**：能否在不违背尼尔森—二宫费米子倍增定理的前提下，由球壳相位与离散拓扑分界在四维相互作用格点上导出恰好 $N_{\mathrm{gen}} = 3$ 代手征外尔费米子？
3. **第三问（汤川味谱层级、夸克混合与质子稳定性）**：能否从同一跨概念耦合同时生出横跨五个数量级的费米子质量谱、真实的 CKM 夸克混合角与 CP 破坏不变量 $J$，并由重子三重对称等精确选择定则护住质子寿命？
4. **第四问（四维自旋二引力与宇宙学常数）**：能否从离散雷吉角亏与四层热核配平导出无质量螺旋度 $\pm 2$ 引力传播子、牛顿常数 $G_N$，以及不预先塞入哈勃半径的 $\Lambda_{\mathrm{cos}}\ell_P^2 \sim 10^{-122}$ 真空能标度？

面对这样一份考卷，最廉价的诱惑是宣布“三问已破、一问在望”；最诚实也最有价值的交付，则是像本书题记所写的那样直接亮出总账：**四问之中，每一问都已产出可独立复算的模型内正例与精确障碍（$4/4$）；但按原书“同一主联络、零事后拟合”的第一性原理铁律，真正完全闭合的题数是 $0/4$。**

## 0.4 记号约定、阅读路线与复算入口 {#sec-ou-0-4}

为方便跨卷对照，全书统一采用以下核心记号：

- **球壳与原弧记号**：$V_{19}$ 表示 $x_1^2 + x_2^2 + x_3^2 = 867$ 的 $19$ 个非负整点；$G_{19} = (V_{19}, E_{135})$ 为保留平方弦长 $d^2 \le 804$ 所得的 $135$ 边图（含 $529$ 个三角面）；$\theta_j = \arccos(1 - j/1734)$ 记平方弦长为 $j$ 的球心弧角。
- **双时钟与谱记号**：$U, V \in \mathrm{Sp}(1)$ 为单位四元数双时钟，半迹记 $x = \operatorname{Re} U$、$y = \operatorname{Re} V$、$z = \operatorname{Re}(UV^{-1})$，交换子亏量记 $E = 1 + 2xyz - x^2 - y^2 - z^2$；$\gamma > 0$ 按解析重数 $m_\gamma$ 计为正黎曼零点纵坐标，$Z_T(t)$ 记截至高度 $T$ 的归一化调和相位得分，$P_k(T)$ 记第 $k$ 阶频率差配对矩。
- **证明结语规范**：全书凡紧随 `lean=` 定理盒之后的 `proof` 块，均解释证明骨架并以“完整证明由 Lean 内核检查。”收束；纯手工推导、第四层区间与复算证书（正文简标 `CERT`，归属第四层 `NUM`）、模型内构造与开放边界则明确在段首或括号中标明 `ARGUED`、`CERT` / `NUM`、`MODEL` 或 `OPEN`。
