# 第一章 十九点贝伦德球壳与二十二独立频率 {#sec-ou-ch01}

如果有人告诉你，他打算用一颗只含十九个整数坐标点的小球，去同时拷问强弱电规范交汇、手征三代、夸克味混合与四维雷吉引力，你第一反应多半是怀疑他在玩某种精巧的数字游戏。费曼面对这类提议时的经典反问只有一句：**把坐标写出来，把每条边的长度算出来，看看它究竟能做什么、不能做什么。**

我们这就把这颗小球放在桌上，一颗顶点不漏、一条弦长不藏地解剖干净。为什么恰恰选中平方半径 $R = 867 = 3 \times 17^2$ 的第一卦限整点球壳？这并非拍脑袋挑出的幸运数字，而是三条纯几何算术门槛共同筛出的**最小解**：

1. **贝伦德（Behrend）球壳的严格凸性**：落在欧氏球面 $x_1^2 + x_2^2 + x_3^2 = R$ 上的任意三个互异整点都不可能构成非平凡三项等差数列 $A + C = 2B$，因为球面严格凸，弦中点恒落在球内。这一反等差性质使整数球壳成为组合数论与有限谐振采样的经典载体。
2. **三阶中心相位门槛 $R = 3m^2$**：沿非负整点球壳 $S_R$ 上任意三点 $A, B, C$ 的最短大圆弧走完闭合三角形、执行自旋 $\frac{1}{2}$ 平行输运，所得归一化全纯相位 $h = z / |z|$ 满足 $z = R(R + A\cdot B + B\cdot C + C\cdot A) + \det(A, B, C)\sqrt{-R}$，故 $h^2 = z / \bar{z} \in \mathbb{Q}(\sqrt{-R})$。要令有限闭路精确产生三代轮换所需的中心相位 $\omega = e^{2\pi i/3}$，数域必须包含 $\omega^2 \in \mathbb{Q}(\sqrt{-3})$，从而迫使 $R = 3m^2$（`ARGUED`）。早期使用的九点球壳 $R = 17$（$(0,1,4)$ 与 $(2,2,3)$ 的排列）因此被彻底排除在精确三阶相位之外。
3. **三模手征陈数门槛 $m = 17$**：在 $R = 3m^2$ 序列中，更小的非平凡壳（直至 $m = 15$、$R = 675$）上所有外轨道到内轨道的三条平方弦长都满足“远边严格大于近边与中边之和”，令按平方弦长比例设定的跃迁振幅无法在相位环面上相消，最高本征线陈数恒为零；$m = 16$（$R = 768$）在非负整点中仅含单个极点 $(16, 16, 16)$。直到 **$m = 17$（$R = 867$）**，外轨道 $(1, 5, 29)$ 到内轨道 $(13, 13, 23)$ 的三条平方弦长 $(244, 724, 804)$ 才首次满足三角不等式（$244 + 724 = 968 > 804$），使按平方弦长比例设定的跃迁振幅得以相消产生三条同手征零模，同时保留精确的 $e^{2\pi i/3}$ 闭路相位（`CERT / MODEL`）。

选定这颗十九点球壳作为共同试验台本身属于**模型选择（`MODEL`）**；但一旦它落定，其上的一切组合计数、伽罗瓦独立性、射影流群律与有理格拉姆障碍，全部变成无可通融的硬数学。

## 1.1 十九点贝伦德球壳的整数解剖 {#sec-ou-1-1}

我们先以正式定义固定全书反复调用的十九点贝伦德球壳骨架。

$$
x_1^2 + x_2^2 + x_3^2 = 867 \qquad (x_1, x_2, x_3 \in \mathbb{Z}_{\ge 0})
$$

的全部非负整数解之集 $V_{19}$ 为**十九点贝伦德球壳**。在坐标三阶循环置换 $\sigma(x_1, x_2, x_3) = (x_2, x_3, x_1)$ 下，$V_{19}$ 分解为一个唯一不动极点与六条长度为 $3$ 的循环轨道（共 $1 + 6 \times 3 = 19$ 个顶点）：

  3. $\{(11, 11, 25),\; (11, 25, 11),\; (25, 11, 11)\}$（次内层 $3$ 点）；
  4. $\{(13, 13, 23),\; (13, 23, 13),\; (23, 13, 13)\}$（内层 $3$ 点）。

$$

$$
\theta_j := \arccos\!\left(1 - \frac{j}{1734}\right) \in \left(0, \frac{\pi}{2}\right) \qquad (j \in \mathcal{J}_{23}).

## 1.2 二十三个弦角为何恰好留下二十二个有理独立频率 {#sec-ou-1-2}

到了[第二章](ch02-quaternion-clocks-and-haar-zeros.md)，我们要用这颗球壳上的原弧角度乘以黎曼零点纵坐标 $\gamma$，去驱动整个标准模型规范群 $\mathrm{U}(1) \times \mathrm{SU}(2) \times \mathrm{SU}(3)$ 的双元哈尔积分。要让多只相位指针在环面上真正联合等分布而不是锁死在低维共振子环面上，我们必须先回答一个纯粹的代数数论问题：**这 $23$ 个原弧角 $\theta_j$ 在有理数域 $\mathbb{Q}$ 上究竟有多少个线性无关的频率？**

答案出人意料地干净——**恰好 $22$ 个**（`ARGUED`，详见[规范群积分专题](https://github.com/the-omega-institute/trureturing-experiments/blob/ba0ac9539cdb641744054bf3a0398494f4cba1c8/experiments/ch39-omega-research/replay/ch39-%E9%9B%B6%E7%82%B9%E4%B8%8E%E6%A0%87%E5%87%86%E6%A8%A1%E5%9E%8B%E8%A7%84%E8%8C%83%E7%BE%A4%E7%A7%AF%E5%88%86.md)）。我们不跳过一步，直接用手算把证明走通：

第一步，把角度翻译成单位圆上的代数数。对每个 $j \in \mathcal{J}_{23}$，令

$$
\alpha_j := e^{i\theta_j} = \frac{1734 - j + i\sqrt{j(3468 - j)}}{1734}.
$$

首先确认这 $23$ 个数里**没有一个是单位根**：因为 $0 < j \le 804 < 867$，所以 $2\operatorname{Re}\alpha_j = 2 - \frac{j}{867}$ 严格介于 $1$ 与 $2$ 之间且为有理数，绝不是整数；而由尼文定理（或分圆多项式整性），单位根的两倍实部若为有理数则必属于 $\{-2, -1, 0, 1, 2\}$。因此 $\alpha_j$ 在乘法群中全部为无穷阶元。

第二步，按虚二次域分班。把每个 $j(3468 - j)$ 剥去全部平方因子，求出无平方因子判别核 $D_j$：

- 当 $j \in \{12, 68, 136\}$ 时，直接算得 $12\times 3456 = 2\times 144^2$、$68\times 3400 = 2\times 340^2$、$136\times 3332 = 2\times 476^2$，三者同落于**同一个虚二次域 $\mathbb{Q}(\sqrt{-2})$**！
- 其余 $20$ 个 $j$ 对应的无平方因子核 $D_j$ 按核的大小排列为

$$
86,\; 542,\; 1478,\; 1538,\; 1634,\; 1698,\; 1718,\; 2534,\; 7998,\; 8858,\; 10374,\; 11102,\; 11354,\; 11942,\; 14874,\; 31502,\; 49166,\; 57962,\; 58682,\; 112022,
$$

二十个数两两互不相等，且都不等于 $2$。

第三步，伽罗瓦特征空间一刀切开跨域线性关系。取全部 $21$ 个虚二次域的复合域 $K$，考察去掉扭元（单位根）后的乘法 $\mathbb{Q}$-向量空间 $V := (K^\times / \mu(K)) \otimes_{\mathbb{Z}} \mathbb{Q}$。对任意 $\sigma \in \operatorname{Gal}(K/\mathbb{Q})$，每个 $\alpha_j$ 属于单一虚二次子域 $F_j = \mathbb{Q}(\sqrt{-D_j})$，而 $\sigma$ 在 $F_j$ 上的限制非恒等即复共轭——又因 $\alpha_j$ 位于单位圆上，$\bar{\alpha}_j = \alpha_j^{-1}$！于是 $\sigma(\alpha_j) = \alpha_j^{\chi_j(\sigma)}$，其中 $\chi_j : \operatorname{Gal}(K/\mathbb{Q}) \to \{\pm 1\}$ 是 $F_j$ 对应的二次符号特征标。在加性记号的 $\mathbb{Q}$-空间 $V$ 中，不同特征标的特征向量必然线性无关——哪怕各平方类 $D_j$ 之间存在乘法依赖，不同虚二次子域诱导的伽罗瓦限制特征标依然两两不同！因此，只要乘积 $\prod_j \alpha_j^{n_j}$ 是单位根，对应的关系就必须在各个二次域所对应的特征空间中分别成立。每个只出现一次的二次域都给出 $n_j=0$。

第四步，解剖唯一的重复宿舍 $\mathbb{Q}(\sqrt{-2})$。把 $j = 12, 68, 136$ 化简到最简分式：

$$
\alpha_{12} = \frac{287 + 24\sqrt{-2}}{289}, \qquad \alpha_{68} = \frac{49 + 10\sqrt{-2}}{51}, \qquad \alpha_{136} = \frac{47 + 14\sqrt{-2}}{51}.
$$

在草稿纸上直接把前两个相乘：

$$
(287 + 24\sqrt{-2})(49 + 10\sqrt{-2}) = (14063 - 480) + (2870 + 1176)\sqrt{-2} = 13583 + 4046\sqrt{-2} = 289\,(47 + 14\sqrt{-2}),
$$

分子分母齐约 $289 = 17^2$，精确得到 **$\alpha_{136} = \alpha_{12}\alpha_{68}$**！三者辐角均在第一象限 $(0, \pi/2)$，故精确成立唯一的有理线性关系：

$$
\theta_{136} = \theta_{12} + \theta_{68}.
$$

至于 $\alpha_{12}$ 与 $\alpha_{68}$ 本身是否独立？只需看唯一分解整环 $\mathbb{Z}[\sqrt{-2}]$ 中素数 $3$ 上方的素理想 $\mathfrak{p}_3 = (1 + \sqrt{-2})$：分母 $289 = 17^2$ 不被 $3$ 整除且 $287 + 24\sqrt{-2} \equiv 2 \not\equiv 0 \pmod{\mathfrak{p}_3}$，故 $v_{\mathfrak{p}_3}(\alpha_{12}) = 0$；而 $51 = 17(1 + \sqrt{-2})(1 - \sqrt{-2})$ 且 $49 + 10\sqrt{-2} = (1 + \sqrt{-2})^2(-1 - 12\sqrt{-2})$，余因子 $-1-12\sqrt{-2}$ 模 $\mathfrak{p}_3$ 为 $2$，故 $v_{\mathfrak{p}_3}(\alpha_{68}) = 2 - 1 = 1$。赋值在单位根上为零，所以若 $\alpha_{12}^a\alpha_{68}^b$ 是单位根，先得 $b=0$，再由 $\alpha_{12}$ 的无穷阶性得 $a=0$。

取次内层点 $P = (11, 11, 25)$、内层点 $Q = (13, 13, 23)$ 与极点 $O = (17, 17, 17)$：

1. **最短原弧 $PQ$（$d^2 = 12$）**：$P - Q = (-2, -2, 2)$，故 $\|P - Q\|^2 = 4 + 4 + 4 = 12$；内积 $P \cdot Q = 143 + 143 + 575 = 861$，于是 $\cos\theta_{12} = \frac{861}{867} = \frac{287}{289}$，且 $\sin\theta_{12} = \frac{\sqrt{289^2 - 287^2}}{289} = \frac{\sqrt{1152}}{289} = \frac{24\sqrt{2}}{289}$，正好还原 $\alpha_{12}$。

:::

对整数系数 $n_j$，若 $\sum_j n_j\theta_j$ 是 $2\pi$ 的有理倍数，则 $\prod_j\alpha_j^{n_j}$ 是单位根。逐个特征空间消去其他系数后，只剩 $n_{12}+n_{136}=n_{68}+n_{136}=0$。因此这些系数向量全由 $(1,1,-1)$ 在 $j=12,68,136$ 三处的取值生成，角度和本身总为零。

删去 $\theta_{136}$ 后，余下 **$22$ 个频率连同 $2\pi$ 一起在 $\mathbb{Q}$ 上线性无关**。第 2 章把 $\theta_{724}, \theta_{804}$ 换成双时钟差频 $\theta_{724}-\theta_{244}$ 与 $\theta_{804}-\theta_{244}$，同时保留 $\theta_{244}$。把 $\theta_{244}$ 分别加回两个差频就能复原旧频率，因此这项整数换基保留同样的独立性。

## 1.3 射影三元流群、整数球壳压缩与各向同性反演 {#sec-ou-1-3}

在把黎曼零点喂给这 $22$ 个频率之前，我们需要两根经 Lean 4 内核锁死的数学承重柱，分别钉住球壳的**离散非交换代数面**与**连续各向同性投影面**。

第一根支柱把四元数比较从“预设单位元 $\mathbf{1}$ 与实数根号”的脚手架上解绑出来。在整四元数环 $\mathbb{Z}^4$ 上，定义无须除法的三元代表元 $\operatorname{triad}(x, y, z) := (x\bar{y})z$ 以及纯整数射影有理重叠加权 $\kappa(a, b) := \langle a, b\rangle^2 / (\|a\|^2 \|b\|^2)$。下面这条冻结定理保证了无原点三元迁移的结合律与读数平移不变性：

::: {.theorem #thm-ou-ch01-ternion-heap title="整四元数射影三元流群结合律与有理保真度平移不变性" lean="D5/S3/Quantum/AURICOmega/OmegaTernionHeap.triad_assoc D5/S3/Quantum/AURICOmega/OmegaTernionHeap.kappa_heap_invariant"}
设 $\mathrm{Quaternion}$ 为整系数四元数类型，配哈密顿乘积、共轭 $y \mapsto \bar{y}$、平方范数 $\|a\|^2 \in \mathbb{N}$、非零谓词 `Nonzero` 与三元代表元 $\operatorname{triad}(x, y, z) := (x\bar{y})z$。记两枚整四元数满足射影射线等价 `RayEquiv`（写作 $a \sim_{\mathrm{ray}} b$），若二者均非零且存在非零整数 $k, l \in \mathbb{Z}\setminus\{0\}$ 使 $ka = lb$；在有号整数分数类型 `Omega.IntRatio` 中记射影重叠为 $\kappa(a, b) := \langle a, b\rangle^2 / (\|a\|^2 \|b\|^2)$。则以下两条结论成立：

1. **三元流群外结合律**（[`triad_assoc`](lean:D5/S3/Quantum/AURICOmega/OmegaTernionHeap.triad_assoc)）：对一切非零整四元数 $x, y, z, u, v$，

   $$
   \operatorname{triad}\bigl(\operatorname{triad}(x, y, z),\, u,\, v\bigr) \;\sim_{\mathrm{ray}}\; \operatorname{triad}\bigl(x,\, y,\, \operatorname{triad}(z, u, v)\bigr).
   $$

2. **有理重叠的右平移不变性**（[`kappa_heap_invariant`](lean:D5/S3/Quantum/AURICOmega/OmegaTernionHeap.kappa_heap_invariant)）：对任意整四元数 $a, b$ 及任意非零整四元数 $u, v$，在 `IntRatio.Equivalent` 下成立

   $$
   \kappa\bigl(\operatorname{triad}(a, u, v),\, \operatorname{triad}(b, u, v)\bigr) \;\equiv\; \kappa(a, b).
   $$

:::

::: proof
对于第一款，由整四元数乘法结合律直接得出逐分量等式 $\bigl(((x\bar{y})z)\bar{u}\bigr)v = (x\bar{y})\bigl((z\bar{u})v\bigr)$；再由四平方范数乘性知非零整四元数的三元积恒保持非零，按 `RayEquiv` 的自反性即证外结合律。对于第二款，记 $p := \bar{u}v$；因 $u, v$ 非零，$p$ 非零且其平方范数 $n := \|p\|^2 > 0$。右乘 $p$ 使欧氏内积放大 $n$ 倍（$\langle ap, bp\rangle = n\langle a, b\rangle$），同时使分母 $\|ap\|^2 \|bp\|^2 = n^2 \|a\|^2 \|b\|^2$ 放大 $n^2$ 倍；分子平方与分母同含正因子 $n^2$，在有号分数等价关系 `IntRatio.Equivalent` 中精确消去（若 $a$ 或 $b$ 为零则两端同为未定义亦等价）。完整证明由 Lean 内核检查。
:::

这套整四元数代数并非停留在抽象符号里——早在十九点壳的前身（平方半径 $17$ 的九点壳）上，独立复算文件 [`ShellProjection.lean`](https://github.com/the-omega-institute/trureturing-experiments/blob/ba0ac9539cdb641744054bf3a0398494f4cba1c8/experiments/ch39-omega-research/replay/ShellProjection.lean)（`CERT`，仅导入 Lean 标准 `Init` 并全靠定义归约 `rfl` 验证，独立于本书冻结库）就给出了一个令人拍案的纯整数压缩见证。取九点壳上的纯虚四元数列表（$(0, 1, 4)$ 与 $(2, 2, 3)$ 的全部九个排列），固定极轴 $a = (0, 0, 1, 4)$，对每个壳点 $p$ 定义整数平面投影算子

$$

逐项穷举全部 $9 \times 9 = 81$ 对顶点与全部四枚四元数基矢，$P_p$ 满足精确整系数压缩恒等式（`shell_compressions`）：

P_p\bigl(P_q(P_p(v))\bigr) = 34\,(17 + p \cdot q)\,P_p(v).

更妙的是，一旦沿内层有向三角形 $p = (0, 3, 2, 2)$、$q = (0, 2, 3, 2)$、$r = (0, 2, 2, 3)$ 绕行一圈（`inner_oriented_triangle`），取 $z = P_p(v)$，三步复合不仅输出实标量项，还精确激发出一条非零的极轴定向扭转：

而将单步反射算子 $u_p(x) := (p x)a$ 沿正向三循环之和减去逆向三循环之和（`oriented_axis_from_shell`），所有对称残渣悉数抵消，干净吐出纯定向极轴见证 $714\,x a$！不需要一个浮点小数，也不需要任何连续流形坐标，有限整数球壳自己就会用整数 $7$ 与 $714$ 喊出空间定向。

压缩律与有向三角形律这两条恒等式，既不依赖平方半径 $17$，也不依赖逐点穷举。对整数 $s$ 与纯虚整四元数 $p$、$a$，记壳映射 $P_{s,p,a}(v) := s\,v + (p v)\,a$，以 $x \cdot y$ 表示四维欧氏内积，并记平方范数 $N(x) := x \cdot x$。下面这条冻结定理说明：只要 $s^2 = N(p)\,N(a)$，这两条律就对一切整四元数 $v$ 精确成立，对中间顶点 $q$、$r$ 的范数没有任何要求：

::: {.theorem #thm-ou-ch01-shell-compression-triangle title="整四元数壳映射的压缩恒等式与有向三角形恒等式" lean="D5/S3/Quantum/AURICOmega/OmegaShellProjection.shell_compress_of_eq D5/S3/Quantum/AURICOmega/OmegaShellProjection.shell_triangle_of_eq"}
设 $s$ 为整数，$p, q, r, a$ 为实部为零的整四元数，且 $s^2 = N(p)\,N(a)$。则对任意整四元数 $v$，以下两条结论成立：

1. **压缩恒等式**：

$$
P_{s,p,a}\bigl(P_{s,q,a}(P_{s,p,a}(v))\bigr) = 2\bigl(s^2 + N(a)\,(p \cdot q)\bigr)\,P_{s,p,a}(v).
$$

2. **有向三角形恒等式**：记 $z := P_{s,p,a}(v)$，则

$$
P_{s,p,a}\bigl(P_{s,q,a}(P_{s,r,a}(z))\bigr) = 2s\bigl(s^2 + N(a)\,(p \cdot q + q \cdot r + r \cdot p)\bigr)\,z + 2\,N(a)\,\bigl(p \cdot (q r)\bigr)\,z\,a.
$$
:::

::: proof
把形如 $u \mapsto c\,u + (d\,u)\,a$ 的映射记成系数对 $(c, d)$，壳映射 $P_{s,p,a}$ 就是系数对 $(s, p)$。纯虚的 $a$ 满足 $a a = -N(a)$，所以两个这样的映射复合后仍是同一形状，系数按 $(c, d) \circ (e, f) = (c e - N(a)\,d f,\ c f + d e)$ 合成。三重与四重复合由此化为四元数系数之间的整系数多项式恒等式，逐坐标展开核对。不加范数条件时，两式各多出一项正比于 $s^2 - N(p)\,N(a)$ 的缺陷项；代入 $s^2 = N(p)\,N(a)$ 后缺陷项为零。完整证明由 Lean 内核检查。
:::

取 $s = 17$、$N(p) = N(a) = 17$，第一款的系数 $2(289 + 17\,p \cdot q) = 34\,(17 + p \cdot q)$ 正是九点壳的压缩律。内层三角形的三个内积都等于 $16$，而纯虚四元数之积 $q r$ 的虚部是叉积 $q \times r$，故 $p \cdot (q r) = \det(p, q, r) = 7$；第二款的两个系数于是化为 $2 \cdot 17\,(289 + 17 \cdot 48) = 34 \cdot 1105$ 与 $2 \cdot 17 \cdot 7 = 34 \cdot 7$，与穷举证书逐项吻合。

第三条恒等式同样不依赖平方半径与逐点穷举，而且连范数条件也不需要：

::: {.theorem #thm-ou-ch01-oriented-axis title="整四元数映射的定向轴恒等式" lean="D5/S3/Quantum/AURICOmega/OmegaShellOrientedAxis.oriented_axis_from_shell"}
设 $p, q, r, a$ 为实部为零的整四元数，并记 $u_c(x) := (c\,x)\,a$。则对任意整四元数 $x$，

$$
u_p u_q u_r\,x + u_q u_r u_p\,x + u_r u_p u_q\,x - u_p u_r u_q\,x - u_r u_q u_p\,x - u_q u_p u_r\,x = 6\,N(a)\,\bigl(p \cdot (q r)\bigr)\,x\,a.
$$
:::

::: proof
纯虚的 $a$ 满足 $a a = -N(a)$，所以三重复合 $u_{c_1} u_{c_2} u_{c_3}\,x = \bigl((c_1 c_2 c_3)\,x\bigr)\,a^3$ 等于 $-N(a)\,\bigl((c_1 c_2 c_3)\,x\bigr)\,a$。左端于是等于 $-N(a)\,(A\,x)\,a$，其中 $A = p q r + q r p + r p q - p r q - r q p - q p r$ 是三个因子六种次序乘积的交错和；这一步只用到 $a$ 纯虚。对纯虚的 $p, q, r$，这个交错和是纯量 $-6\,p \cdot (q r)$，代入即得右端。完整证明由 Lean 内核检查。
:::

取 $N(a) = 17$ 与内层三角形的 $p \cdot (q r) = 7$，系数为 $6 \cdot 17 \cdot 7 = 714$，正是证书中的定向轴见证 $714\,x a$。这条恒等式不含 $s$，$x$ 也不必纯虚。

第二根支柱则把离散球壳与三维各向同性连续分布衔接起来。在研究球壳径向系综对单轴外场的静态响应时，若三维旋转不变随机向量 $X \in \mathbb{R}^3$ 的半径密度为 $h(r)$，则给定半径 $R = r$ 时其单轴分量均匀分布在 $[-r, r]$ 上，因此全实轴上可观测的一维投影边缘密度为 $f(t) = \int_{|t|}^\infty \frac{h(r)}{2r}\,dr$（在非负半轴 $t \ge 0$ 上即写作 $\int_t^\infty \frac{h(r)}{2r}\,dr$）。下面这条 Lean 4 冻结定理确立了从一维投影反演三维球壳密度的唯一性与质量守恒律：

::: {.theorem #thm-ou-ch01-shell-inversion title="三维各向同性球壳密度的唯一性与投影总质量关系" lean="D5/S3/Quantum/StaticExchange/IsotropicShellInversion.shell_density_unique D5/S3/Quantum/StaticExchange/IsotropicShellInversion.shell_projection_mass"}
对函数 $h, d : \mathbb{R} \to \mathbb{R}$，定义球壳投影与反演壳密度算子：

$$
\operatorname{projection}(h)(t) := \int_t^\infty \frac{h(r)}{2r}\,dr, \qquad \operatorname{shell}(d)(r) := -2r\,d(r).
$$

则以下两条结论成立：

1. **连续球壳密度的逐点唯一性**（[`shell_density_unique`](lean:D5/S3/Quantum/StaticExchange/IsotropicShellInversion.shell_density_unique)）：设 $h, f : \mathbb{R} \to \mathbb{R}$ 满足 $h$ 在 $(0, \infty)$ 上连续，对每个 $t > 0$ 有 $r \mapsto \frac{h(r)}{2r}$ 在 $(t, \infty)$ 上可积，且对一切 $t > 0$ 有 $\operatorname{projection}(h)(t) = f(t)$。则对所有 $r > 0$ 恒有

   $$
   h(r) = \operatorname{shell}(f')(r) = -2r\,f'(r).
   $$

2. **非负性、边缘恢复与二倍质量恒等式**（[`shell_projection_mass`](lean:D5/S3/Quantum/StaticExchange/IsotropicShellInversion.shell_projection_mass)）：设 $f, d : \mathbb{R} \to \mathbb{R}$，其中 $f$ 在 $0$ 点右连续、在 $(0, \infty)$ 上可积，且对一切 $r > 0$ 满足 $f$ 在 $r$ 处导数为 $d(r) \le 0$。则对所有 $r \ge 0$ 有 $\operatorname{shell}(d)(r) \ge 0$，对所有 $t \ge 0$ 有 $\operatorname{projection}(\operatorname{shell}(d))(t) = f(t)$，且总质量精确满足

   $$
   \int_0^\infty \operatorname{shell}(d)(r)\,dr = 2\int_0^\infty f(r)\,dr.
   $$

:::

::: proof
第一款直接对反常尾积分 $f(t) = \int_t^\infty \frac{h(r)}{2r}\,dr$ 在任意 $r > 0$ 处应用微积分基本定理：由 $h$ 在 $(0, \infty)$ 连续知 $r \mapsto \frac{h(r)}{2r}$ 亦连续，故 $f$ 在 $r$ 处可微且 $f'(r) = -\frac{h(r)}{2r}$，两边同乘 $-2r$ 即得 $h(r) = -2r f'(r)$。第二款由 $r \ge 0$ 及 $d(r) \le 0$（对 $r > 0$，而 $r = 0$ 时 $-2\cdot 0\cdot d(0) = 0$）立得 $\operatorname{shell}(d)(r) \ge 0$；因为 $f$ 单调递减且在 $(0, \infty)$ 上可积，必有 $\lim_{R\to\infty} f(R) = 0$，从而对每个 $t > 0$ 有 $\int_t^\infty (-d(r))\,dr = f(t)$，右连续性把该等式延拓至 $t = 0$；最后由非负函数上的托内利（Tonelli）换序积分（或对 $-2r d(r)$ 分部积分），

$$
\int_0^\infty (-2r\,d(r))\,dr = 2\int_0^\infty \left(\int_t^\infty (-d(r))\,dr\right)dt = 2\int_0^\infty f(t)\,dt.
$$

完整证明由 Lean 内核检查。
:::

## 1.4 有理格拉姆障碍：为何十九点拉普拉斯恰需二十一个有理坐标 {#sec-ou-1-4}

但一旦要求坐标全部落在有理数域 $\mathbb{Q}$ 内——也就是剥掉一切无理平方根——局势立刻剧变（`CERT / ARGUED`，复算脚本 [`ch39-native-shell-rational-gram.py`](https://github.com/the-omega-institute/trureturing-experiments/blob/ba0ac9539cdb641744054bf3a0398494f4cba1c8/experiments/ch39-omega-research/replay/ch39-native-shell-rational-gram.py)）：

2. **用希尔伯特符号否决 $20$ 维以下一切有理嵌入**：把 $q$ 按相邻顺序主子式之比在 $\mathbb{Q}$ 上正交对角化。若 $q$ 能等距嵌入 $20$ 维标准欧氏有理空间 $\mathbb{Q}^{20}$（配标准平方和二次型 $I_{20}$），则存在一个二维正交补有理二次型 $q_\perp$，其行列式平方类必为 $d = \tau$，且对一切素数 $p$ 满足局部哈塞符号条件 $c_p(q_\perp) = c_p(q)(d, -1)_p$。逐个素因子精确核算表明，这一目标符号在四个素数 **$p \in \{2, 11, 17, 71\}$** 处取值为 $-1$。然而在 $p = 2$ 处，精确整数模 $8$ 检验给出 $-d \equiv 1 \pmod 8$，这意味着 $-d$ 在 $2$-进数域 $\mathbb{Q}_2$ 中是一个平方数！对于任何行列式类为 $d$ 的二元二次型，其 $2$-进哈塞符号 $(x, -d)_2$ 必然恒等于 $+1$，与目标值 $-1$ 迎面相撞！于是 $d = 18, 19, 20$ 全部被彻底封杀。

现在，静态骨架已就位，真正棘手的问题随之而来：**两只普通复数相位时钟总是彼此交换的；当我们将球壳相位提升为非交换单位四元数双时钟 $(U, V)$，一个量子谱究竟能否“听出”两只钟是否交换？这二十二个有理独立频率又能否在黎曼零点纵坐标的驱动下，免去全部随机数发生器，直接算准整个标准模型规范群 $\mathrm{U}(1)\times\mathrm{SU}(2)\times\mathrm{SU}(3)$ 上的哈尔积分？** 这正是[第二章 四元数双时钟、非交换逆谱与零点哈尔积分](ch02-quaternion-clocks-and-haar-zeros.md)的中心战场。
