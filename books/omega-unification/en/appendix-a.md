## A.2 ShellProjection.lean: Exact Integer Compression on the Squared-Radius-17 Nine-Point Shell {#sec-ou-appa-shell-projection}

Alongside the Python and Arb suite, the repository includes a standalone Lean 4 verification file [`replay/ShellProjection.lean`](https://github.com/the-omega-institute/trureturing-experiments/blob/ba0ac9539cdb641744054bf3a0398494f4cba1c8/experiments/ch39-omega-research/replay/ShellProjection.lean) (59 lines, importing only Lean `Init`, with `maxRecDepth 80000` and `maxHeartbeats 4000000`). Using neither `Mathlib` nor any real-number or classical axioms, every construction operates in pure integer arithmetic on the quaternion structure `H := (w, x, y, z : Int)`.

Fixing the pure-imaginary reference axis $b = \mathrm{axis} = (0, 0, 1, 4)$ (with $b^2 = -17$), each rank-2 orthogonal projector $P_p = \frac{1}{2}(I + \frac{1}{17} L_p R_b)$ at a radius-$\sqrt{17}$ shell site $p$ clears all denominators upon multiplication by $34$, yielding the integer operator

$$
P_p^{\mathbb{Z}}(v) = 17 v + (p v) b, \qquad v \in \mathbb{Z}^4.
$$

The file enumerates all nine pure-imaginary integer sites of `shell`—the six coordinate permutations of $(0, 1, 4)$ plus the three permutations of $(2, 2, 3)$—and checks three exact integer identities exhaustively over the four standard basis vectors `basis` via `checkAll`:

$$
P_p^{\mathbb{Z}}\!\left(P_q^{\mathbb{Z}}\!\left(P_p^{\mathbb{Z}}(v)\right)\right) = 34(17 + p \cdot q)\,P_p^{\mathbb{Z}}(v),
$$

$$
P_p^{\mathbb{Z}}\!\left(P_q^{\mathbb{Z}}\!\left(P_r^{\mathbb{Z}}(z)\right)\right) = 34(1105 z + 7 z b), \qquad \sum_{\mathrm{cyc}} u_p u_q u_r(x) - \sum_{\mathrm{cyc}} u_p u_r u_q(x) = 714\,x b,
$$

where $p = (0,3,2,2)$, $q = (0,2,3,2)$, $r = (0,2,2,3)$, $z = P_p^{\mathbb{Z}}(v)$, and $u_a(x) = a x b$. All three theorems close in one step by kernel reduction `rfl`, audited by `#print axioms` for zero classical axiom dependence:

Keep the archival boundary clear: the file `ShellProjection.lean` lives in the upstream replay repository as a standalone Tier-4 (`NUM`) certificate (see [Appendix B §B.2](appendix-b.md#sec-ou-appb-epistemic-ledger)), and the file itself is not counted in the live `trureturing@dev` totals of §B.4. Its first two identities are the instance $s = 17$, $N(p) = N(b) = 17$ of [@thm-ou-ch01-shell-compression-triangle]; that theorem holds for every integer $s$ and all pure imaginary integer quaternions with $s^2 = N(p)\,N(b)$, is frozen in the D5 library of `the-omega-institute/trureturing`, and is counted in §B.4. The third item, `oriented_axis_from_shell`, is the instance $N(b) = 17$, $p \cdot (q r) = 7$ of [@thm-ou-ch01-oriented-axis]; that theorem holds for all pure imaginary integer quaternions with no norm condition, and it is likewise frozen and counted in §B.4.

## A.4 Local Reproduction Environment, Audit Discipline, and Verification Commands {#sec-ou-appa-reproducibility}

Scripts fall into two dependency tiers: purely integer, rational, and combinatorial certificates require only the **Python 3 standard library**, whereas rigorous real/complex ball enclosures (Arb) and exact rational-matrix linear algebra (FLINT `fmpq_mat`) require **`python-flint 0.9.0`**. Selected polyhedral finite-element checks and trial-function fits additionally invoke **`NumPy 2.x`** (with final inequalities independently certified by `python-flint`), octahedral chiral operator matrices use **`SymPy 1.14`**, and `ShellProjection.lean` replays under **Lean `v4.35.0`**.

To guarantee drift-free cross-platform reproduction, every replay run follows five audit rules:

1. **Snapshot or archive parity**: obtain identical scripts and JSON reference tables either from pinned commit `ba0ac9539cdb641744054bf3a0398494f4cba1c8` or from the bundled `ch39-omega-math-replay.zip` archive;
2. **Search separated from certification**: whenever `NumPy` discovers candidate optima or trial vectors, all final inequalities and sign tests are independently enclosed via directed-rounding `python-flint` ball arithmetic rather than trusting raw floats;
3. **Fail-fast assertions**: every certificate embeds explicit `assert` checks that abort immediately with a non-zero exit status if any interval enclosure, inertia count, or exact fraction identity fails;
4. **Explicit axiom printing**: replaying `ShellProjection.lean` prints three `#print axioms` diagnostics confirming zero classical axioms beyond Lean `Init`;
5. **Immutable archival baseline**: commit `ba0ac9539cdb641744054bf3a0398494f4cba1c8` in `the-omega-institute/trureturing-experiments` serves as the immutable baseline for all first-edition `NUM` certificates, tracked separately from `trureturing@dev` frozen declarations.
