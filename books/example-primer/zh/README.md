# 前言

这是一本关于斐波那契数与卢卡斯数的入门小书，写给高中生和大学一年级的读者。全书两章：第一章从递推关系出发，讨论增长、卡西尼恒等式、整除与周期；第二章引入形如 $a + b\varphi$ 的“黄金整数”，用它解释卢卡斯数，并说明相邻斐波那契数之比怎样逼近黄金比。读者只需要会代数运算、数学归纳法和带余除法。

本书的每一条定理都对应 [trureturing](https://github.com/the-omega-institute/trureturing) 中一条已被 Lean 内核验证并冻结的声明。书负责解释，Lean 负责成立。阅读时请留意以下约定：

$F_0 = 0,\ F_1 = 1$
: 本书的斐波那契数从 $F_0 = 0$、$F_1 = 1$ 开始，与 Lean 数学库 Mathlib 的 `Nat.fib` 相同。有的书从 $F_1 = F_2 = 1$ 开始，数是同样的数；也有的书从 $F_0 = F_1 = 1$ 开始，那样下标与本书差 $1$。

LEAN ✓
: 定理旁的绿色徽章由构建根据所钉的 trureturing 提交自动生成，链接到该提交上 Lean 源文件的对应行。书中定理的陈述与所引 Lean 声明的陈述一致。

证明
: 证明块只解释思路，完整的证明由 Lean 内核检查。

开放问题
: 带红色 OPEN 徽章的条目是尚未解决的问题，书中不把它们当作已证结论。

表格里的数值都是计算结果，用来帮助理解，不代替证明。书末的“形式化验证账本”由构建自动生成，列出每条定理对应的 Lean 声明。

本书可以作为同一书库中专著《黄金整数与可观测性》的入门读物：那本书的第一章同样用到斐波那契数、黄金比与黄金整数 $a + b\varphi$，随后走得远得多。读完本书，再去读它会更顺手。
