# Preface

This is a short introduction to the Fibonacci and Lucas numbers, written for high-school and first-year university readers. It has two chapters. Chapter 1 starts from the recurrence and covers growth, Cassini's identity, divisibility and periods. Chapter 2 introduces the "golden integers" $a + b\varphi$, uses them to explain the Lucas numbers, and shows how the ratios of consecutive Fibonacci numbers approach the golden ratio. All you need is algebra, proof by induction, and division with remainder.

Every theorem in this book corresponds to a declaration in [trureturing](https://github.com/the-omega-institute/trureturing) that the Lean kernel has verified and that is frozen. The book explains; Lean proves. Please keep the following conventions in mind:

$F_0 = 0,\ F_1 = 1$
: The Fibonacci numbers in this book start with $F_0 = 0$ and $F_1 = 1$, as Mathlib's `Nat.fib` does. Some books start with $F_1 = F_2 = 1$, which gives the same numbers; others start with $F_0 = F_1 = 1$, which shifts every index by $1$.

LEAN ✓
: The green badge next to a theorem is generated by the build from the pinned trureturing commit and links to the corresponding line of the Lean source at that commit. Each theorem is stated in the book as the cited Lean declaration states it.

Proof
: Proof blocks only explain the idea; the full proofs are checked by the Lean kernel.

Open problem
: Items with a red OPEN badge are unsolved questions; the book never treats them as proved.

The numbers in the tables are computations that help with understanding; they do not replace proofs. The verification ledger at the end of the book is generated by the build and lists the Lean declaration behind every theorem.

This book can serve as an introduction to the monograph *Golden Integers and Observability* in the same library: its first chapter also works with the Fibonacci numbers, the golden ratio and the golden integers $a + b\varphi$, and it then goes much further. It will read more easily after this one.
