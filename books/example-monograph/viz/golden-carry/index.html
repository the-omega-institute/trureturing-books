理论接口 · 这个页面在演示什么Theory interface · what this page shows

每个自然数 v 都唯一地写成互不相邻的 Fibonacci 数之和（Zeckendorf 表示 Z(v)），权重 W₀ = F₂ = 1、W₁ = F₃ = 2、W₂ = 3、W₃ = 5……。把权重 Wᵢ 换成 φ^(i+2) 得到 β(v)。β 不保持加法，差额就是亏量 c(v₁, v₂) = β(v₁) + β(v₂) − β(v₁ + v₂)。本页是数值演示，不是证明。

  1. 精确计算。β(v) 写成 a + bφ，整数 a、b 由 φ^k = F(k−1) + F(k)·φ 得到（只用 φ² = φ + 1），所以 b 恰好是 v 本身。亏量的 φ 系数因此是 v₁ + v₂ − (v₁ + v₂) = 0：c 是一个整数，页面不做浮点近似。
  2. 进位账本。Z(v₁) 与 Z(v₂) 逐位相加后可能出现 2 或相邻的 1。每一步触发一条规则：优先在最低的“2”处做重复进位（R₀、R₁ 或 Rⱼ），没有“2”时在最低的相邻一对处做相邻进位 A，直到得到 Z(v₁ + v₂)。这与 trureturing 中 carryPass 的顺序相同。
  3. 哪些规则改变 β。Rⱼ（j ≥ 2）与 A 不改变 β；R₀ 使 β 减少 1，R₁ 使 β 增加 1。所以 c 等于 R₀ 的次数减去 R₁ 的次数：符号带上青色记 +1，品红记 −1。这是 deficit_integer（LEAN ✓）。
  4. 只有三个值。在收缩面上把 φ 换成 ψ = 1 − φ，每个 β′(v) 落在长度为 1 的窗口 [−1/φ², 1/φ] 内，所以 c 严格介于 −2 与 2 之间，又是整数，只能是 −1、0、1。这是 deficit_three_valued（LEAN ✓）。读数面板显示当前三个 β′ 的值。
  5. 亏量图。热图逐格画出 0 ≤ v₁, v₂ ≤ N 上的 c；琥珀色十字标出当前一对。图关于对角线对称，并呈现 Fibonacci 尺度上的自相似结构。网格只是有限的检查，结论的一般性来自 Lean 定理。

Every natural number v is, in exactly one way, a sum of nonadjacent Fibonacci numbers (its Zeckendorf representation Z(v)), with weights W₀ = F₂ = 1, W₁ = F₃ = 2, W₂ = 3, W₃ = 5, …. Replacing each weight Wᵢ by φ^(i+2) gives β(v). β does not preserve addition, and the difference is the deficit c(v₁, v₂) = β(v₁) + β(v₂) − β(v₁ + v₂). The page is a numerical illustration, not a proof.

  1. Exact arithmetic. β(v) is written as a + bφ with integers a, b, using φ^k = F(k−1) + F(k)·φ (nothing but φ² = φ + 1), so b is v itself. The φ-coefficient of the deficit is therefore v₁ + v₂ − (v₁ + v₂) = 0: c is an integer, and the page never rounds.
  2. The carry ledger. Adding Z(v₁) and Z(v₂) digit by digit can leave a 2 or two adjacent 1s. Each pass fires one rule: a repeated carry at the lowest 2 (R₀, R₁ or Rⱼ) if there is one, otherwise the adjacent carry A at the lowest adjacent pair, until Z(v₁ + v₂) is reached. This is the order of carryPass in trureturing.
  3. Which rules move β. Rⱼ (j ≥ 2) and A leave β unchanged; R₀ lowers β by 1 and R₁ raises it by 1. So c is the number of R₀ carries minus the number of R₁ carries: on the sign tape cyan counts +1 and magenta −1. This is deficit_integer (LEAN ✓).
  4. Only three values. On the contraction face φ is replaced by ψ = 1 − φ, and every β′(v) lies in the window [−1/φ², 1/φ] of length 1, so c lies strictly between −2 and 2; being an integer, it is −1, 0 or 1. This is deficit_three_valued (LEAN ✓). The readouts show the three current values of β′.
  5. The deficit map. The heat map draws c cell by cell for 0 ≤ v₁, v₂ ≤ N; the amber cross marks the current pair. The map is symmetric about the diagonal and self-similar at Fibonacci scales. The grid is a finite check only; the general statement comes from the Lean theorems.
