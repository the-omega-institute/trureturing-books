LEAN ✓无穷远点闭合到对径点：对整数 p ≠ 0，在 [p : 0] 处 κ 等价于 0、spread 等价于 1，凯莱像 X 等价于 −1、Y 等价于 0；其中对整数对 [p : q]，κ = q²/(p² + q²)、spread = p²/(p² + q²)、X = (q² − p²)/(p² + q²)、Y = (pq + qp)/(p² + q²)：The point at infinity closes at the antipode: for an integer p ≠ 0, at [p : 0] κ is equivalent to 0 and spread to 1, and the Cayley image has X equivalent to −1 and Y to 0; here, for an integer pair [p : q], κ = q²/(p² + q²), spread = p²/(p² + q²), X = (q² − p²)/(p² + q²) and Y = (pq + qp)/(p² + q²): cayley_antipodal_closure
LEAN ✓三元积的射线外结合律：对非零整四元数 x、y、z、u、v，triad(triad(x, y, z), u, v) 与 triad(x, y, triad(z, u, v)) 射线等价；其中 triad(a, b, c) = (a·conj(b))·c，两个整四元数射线等价指二者都非零且有非零整数 k、l 使 k·a = l·b：The outer associativity of the triad on rays: for nonzero integer quaternions x, y, z, u, v, triad(triad(x, y, z), u, v) and triad(x, y, triad(z, u, v)) are ray-equivalent; here triad(a, b, c) = (a·conj(b))·c, and two integer quaternions are ray-equivalent when both are nonzero and k·a = l·b for some nonzero integers k, l: triad_assoc
LEAN ✓有号核与射影核的二次桥：对 PythSpinor p、q（整四元数分子 num p、正自然数半径 rp，且 ‖num p‖² = rp²），κproj(p, q) = ⟨num p, num q⟩²/(‖num p‖²‖num q‖²) 等价于 (2κspin(p, q) − 1)²，其中 κspin(p, q) = (rprq + ⟨num p, num q⟩)/(2rprq)：The quadratic bridge between the signed and the projective kernel: for PythSpinors p, q (integer quaternion numerator num p, positive natural radius rp, and ‖num p‖² = rp²), κproj(p, q) = ⟨num p, num q⟩²/(‖num p‖²‖num q‖²) is equivalent to (2κspin(p, q) − 1)², where κspin(p, q) = (rprq + ⟨num p, num q⟩)/(2rprq): quadratic_kernel
LEAN ✓凯莱矩阵正交：对有理三维向量 s = (x, y, z)/d（d ≥ 1），Cayley s = C/N，C = (d² − x² − y² − z²)I + 2d[s₀]× + 2s₀s₀T（s₀ = (x, y, z)），N = d² + x² + y² + z²，满足 (Cayley s)T·Cayley s 等价于单位矩阵：The Cayley matrix is orthogonal: for a rational 3-vector s = (x, y, z)/d (d ≥ 1), Cayley s = C/N with C = (d² − x² − y² − z²)I + 2d[s₀]× + 2s₀s₀T (s₀ = (x, y, z)) and N = d² + x² + y² + z² satisfies that (Cayley s)T·Cayley s is equivalent to the identity matrix: cayley_orthogonal
LEAN ✓伴随作用是乘法同态：对非零整四元数 p、q 与有理三维向量 v，Ad(p·q) v 与 Ad(p)(Ad(q) v) 等价，其中 Ad(p) v = Im(p·v·conj(p))/‖p‖²（v 看作纯虚四元数）：The adjoint action is a homomorphism: for nonzero integer quaternions p, q and a rational 3-vector v, Ad(p·q) v is equivalent to Ad(p)(Ad(q) v), where Ad(p) v = Im(p·v·conj(p))/‖p‖² (v read as a pure quaternion): ad_hom
LEAN ✓旋量流群递推每一拍模方为一：对 PythSpinor a、b 与自然数 n，heapAt(a, b, n) 的有理模方 ‖num‖²/r² 等价于 1；其中 heapAt(a, b, 0) = a、heapAt(a, b, 1) = b、heapAt(a, b, n + 2) = triad(heapAt(a, b, n + 1), heapAt(a, b, n), heapAt(a, b, n + 1))，triad(p, q, r) = (p·conj(q))·r（分子相乘，半径相乘）：Every beat of the spinor heap recurrence has squared norm one: for PythSpinors a, b and a natural number n, the rational squared norm ‖num‖²/r² of heapAt(a, b, n) is equivalent to 1; here heapAt(a, b, 0) = a, heapAt(a, b, 1) = b, heapAt(a, b, n + 2) = triad(heapAt(a, b, n + 1), heapAt(a, b, n), heapAt(a, b, n + 1)), and triad(p, q, r) = (p·conj(q))·r (numerators multiply, radii multiply): heap_norm_preserved
