LEAN ✓整数缩放保持相融度：对整数 p、q、k，若 k ≠ 0，则 κ(kp, kq) 与 κ(p, q) 等价，其中 κ(p, q) = q²/(p² + q²)，分母为 0 时取“未定义”；两个有定义的比交叉相乘相等时等价，“未定义”只与自身等价：Integer scaling keeps the overlap: for integers p, q, k with k ≠ 0, κ(kp, kq) is equivalent to κ(p, q), where κ(p, q) = q²/(p² + q²) and a zero denominator gives “undefined”; two defined ratios are equivalent when their cross products are equal, and “undefined” is equivalent only to itself: OmegaCircleClosure.kappa_scale
LEAN ✓正自然数缩放保持相融度：对自然数 p、q、k，κ(p(k + 1), q(k + 1)) 与 κ(p, q) 等价，其中 κ(p, q) = q²/(p² + q²)；p = q = 0 时两边都是“未定义”，也算等价：Positive natural scaling keeps the overlap: for natural numbers p, q, k, κ(p(k + 1), q(k + 1)) is equivalent to κ(p, q), where κ(p, q) = q²/(p² + q²); for p = q = 0 both sides are “undefined”, which also counts as equivalent: ProjectiveOverlapScaling.kappa_scale
LEAN ✓相融度与展度之和为一：对不全为 0 的整数 p、q，κ(p, q) + spread(p, q) 等价于 1，其中 spread(p, q) = p²/(p² + q²)：Overlap and spread sum to one: for integers p and q, not both 0, κ(p, q) + spread(p, q) is equivalent to 1, where spread(p, q) = p²/(p² + q²): kappa_add_spread_eq_one
LEAN ✓凯莱像落在单位圆上：对不全为 0 的整数 p、q，X = (q² − p²)/(p² + q²)、Y = (pq + qp)/(p² + q²) 满足 X·X + Y·Y 等价于 1：The Cayley image lies on the unit circle: for integers p and q, not both 0, X = (q² − p²)/(p² + q²) and Y = (pq + qp)/(p² + q²) satisfy that X·X + Y·Y is equivalent to 1: cayley_circle_unit
LEAN ✓无穷远点闭合到对径点：对整数 p ≠ 0，在 [p : 0] 处 κ 等价于 0、spread 等价于 1，凯莱像 X 等价于 −1、Y 等价于 0：The point at infinity closes at the antipode: for an integer p ≠ 0, at [p : 0] κ is equivalent to 0 and spread to 1, and the Cayley image has X equivalent to −1 and Y to 0: cayley_antipodal_closure
LEAN ✓齐次乘法把模方相乘：对整数 p₁、q₁、p₂、q₂，(p₁² + q₁²)(p₂² + q₂²) 等于乘积 (p₁q₂ + q₁p₂, q₁q₂ − p₁p₂) 的模方（作为自然数相等）：Homogeneous multiplication multiplies the squared norms: for integers p₁, q₁, p₂, q₂, (p₁² + q₁²)(p₂² + q₂²) equals the squared norm of the product (p₁q₂ + q₁p₂, q₁q₂ − p₁p₂) (as natural numbers): projective_circle_mul_normSq
