# 前言 为什么重建零公理数学 {#sec-om-prelude}

> *“无穷大只是开口直线在尽头留下的裂口，圆周率与自然底数只是平直切尺贴合弯曲圆弧时磨出的无穷级数碎屑；回到闭合的球面与有限的有理比，数学本身不需要任何幽灵。”*

两千多年来，数学家一直默认自己必须支付三笔昂贵的入场费，才能讨论几何、微积分与物理定律：第一笔是**康托尔的实无穷**（$\infty$、$\aleph_0$、$\aleph_1$），假定我们可以把无穷多对象一次性塞进静态的已完成集合；第二笔是**不可数的实数与复数连续统**（$\mathbb{R}$、$\mathbb{C}$），假定直线由无穷多个不可计算的十进制小数填满；第三笔则是**超越近似常数**（$\pi$、$e$、$\varphi$）与依赖它们的无穷级数、极限滤子和非构造性选择公理。

本书提出并系统展开一条相反的道路：**撤去实无穷、撤去不可计算连续统、撤去平直切线近似常数，直接站在零公理的归纳构造演算（CIC）裸内核与齐次有理数系之上，重建覆盖球面几何、非线性代数、微积分、调和分析、阿代尔算术与非阿贝尔计算论的完备有理数学体系。** 这并非削足适履的简陋妥协，而是给数学卸下十九世纪线性化脚手架后的本来面目——每一条代数法则都可执行，每一枚分数读数都精确无损，每一次旋转都在有限步整数四则运算中严丝合缝地留在球面上。

## 0.1 三笔隐藏的账单：实无穷、不可计算连续统与平直近似常数 {#sec-om-prelude-three-bills}

在动手重建之前，不妨像物理学家检查实验误差那样，逐一核对传统标准数学底座上那三笔很少被明码标价的账单。

第一笔账单是**开口直线制造的实无穷**。欧氏直尺向两端无限延伸、永不回环，于是斜率在垂直方向被迫触发 $1/0$ 的除零崩塌，只得在直线尽头外贴一枚异质符号 $\infty$。一旦把这种“永不闭合”的习惯推广为静态已完成的无穷集合 $\aleph_0, \aleph_1$，再叠加非构造性的选择公理（`Classical.choice`），几何世界立刻出现违背体积直觉的裂痕——例如巴拿赫—塔斯基分球悖论，允许将一颗实心三维单位球拆成五块不可测碎片，仅凭刚体运动重拼为两颗等大实心球。若一开始就改用齐次整数对 $[P : Q]$ 在射影闭环上度量方向，原先的“无穷远”不过是一枚平平无奇的整数锚点 $[1 : 0]$，分母 $P^2 + Q^2 = 1$ 严格为正，裂口从未存在过。

第二笔账单是**不可计算连续统的测度幽灵**。有限字母表上的有限程序或图灵机至多只有可数多个，而在勒贝格测度意义下，实数轴 $\mathbb{R}$ 上占比 $100\%$ 的点根本不存在任何有限算法定义。传统教科书假装我们可以随意“取出”任意实数并做除法或开方；落到现代交互式定理证明器（如 Lean 4 的 `Mathlib.Real`）中，这笔欠账当场暴露无遗——实数作为有理柯西序列的商集，一举引入三大经典公理 `{propext, Classical.choice, Quot.sound}`，使实数除法、平方根、矩阵指数与实导数大面积传染 `noncomputable` 标记，既无法编译为可执行代码求值，也令内核反射归约停摆。

第三笔账单是**平直尺丈量弯曲球面留下的近似常数**。圆周率 $\pi$ 源于执意用平面正 $N$ 边形的零曲率直边去拼凑圆弧，每一条直弦都留下正的弦弧矢高，唯有令 $N \to \infty$ 才吐出超越数 $\pi$；自然底数 $e$ 源于每一步都沿平直切线跨出欧拉步 $(1 + \theta\mathbf{i}/N)^N$，有限步内模方必然刺破单位球壳，唯有无限切碎步长才在实轴上凝出 $e$；黄金比 $\varphi$ 则源于三维空间等距单形在四顶点正四面体（有理保真度 $\kappa = 1/3$）封顶之后，强行追逐五重平直面配位或大圆五周期闭合所撕出的二次无理残差。如果直接以有理保真度 $\kappa$、有理凯莱变换与整系数切比雪夫递推书写球面几何，旋转与谐波一步驻球、零截断漂移，根本不需要 $\pi$、$e$ 或 $\varphi$ 充当底层公理原语。

::: {.remark #rem-prelude-classical-boundaries title="经典分析、可计算性与超越数文献边界（ARGUED）"}

Math.* **6**, 244–277, 1924），最少块数为五由 R. M. Robinson（*Ann. of Math.* **48**, 281–295, 1947）证得；$e$ 与 $\pi$ 的超越性分别由 C. Hermite（1873）与 F. Lindemann（1882）证得；关于无极限代数微积分与有理三角学的先驱思路，可分别参看 A. Kock（*Synthetic Differential Geometry*, 1981）与 N. J. Wildberger（*Divine Proportions*, 2005）。

## 0.2 认识论诚实契约与五级证据分层 {#sec-om-prelude-epistemic-contract}

重建基础数学最忌讳的，是把哲学愿景、手工推导、数值验算与机器内核证明混为一谈。全书对每一条数学断言实行严格的分层标注，绝不越级包装：

| 证据层级 | 呈现方式与核验来源 | 公理与逻辑边界 |
| :--- | :--- | :--- |
| **严格端零公理冻结定理** | 定理环境链接 D5 冻结声明，严格端证据见附录 A | `strict_omega.axioms` 为 `[]`，同一条声明行的 `axioms` 记录官方端公理依赖 |
| **经典阴影冻结锚点** | 正式定理环境配冻结声明链接（经典 `Mathlib` 侧，正文显式注明） | 附录 A.5 的 35 条经典锚点在所钉版本均缺少官方公理测量，许可上界为 `{propext, Classical.choice, Quot.sound}`。已有测量的声明按该行记录读取确切依赖。 |
| **严谨论证与文献结果（`ARGUED`）** | 正文阐释、定义、注记中的完整代数推导或经典文献引述 | 由作者与评审负责；尚未冻结入零公理声明库的构造性命题均暂列于此，绝不冒用内核徽章 |
| **概念模型与架构纲领（`MODEL`）** | 认识论框架、物理观察者诠释与跨领域结构对应 | 明确标识为建构纲领或诠释模型，不与纯数学定理混淆 |
| **精确算术与数值核验（`NUM`）** | 手算整分数轨迹、有限可判定计算与对照数值表 | 读者可逐行徒手复算或直接交由整数算术核对 |

开放问题保留其未证身份。六卷原生骨架的 D5 定理在严格端有空公理记录，下文在这些定理旁所说的“零公理”指严格端。常规官方构建采用锁文件解析的官方公理记录。严格库的空内核重放覆盖所选库根的导入闭包。两种核验的入口见 [附录 A](appendix-a.md)，出版徽章与统计的口径见 [附录 B](appendix-b.md)。`OmegaShadowBridge` 把核心构造接到经典实数刻度尺上，几何诠释（`MODEL`）、文献与手工论证（`ARGUED`）和精确算例（`NUM`）则各按所据标明。

读者既可按卷顺序通读，也可按关注领域快速定位各卷主线：

- **第一卷：公理地基与齐次有理数系**（[第一章](ch01-axiom-omega-and-cic.md)–[第三章](ch03-canonical-ternion-manifold.md)）。先剥离 `Mathlib` 经典公理，在裸 CIC 上以类型类示意母公理 `AXIOM-Ω` 的部分定律，并给出观察者精度契约 $\varepsilon_{\mathrm{self}} = 1/M$；再以齐次整数对 $\mathbb{QP}^1$ 驯服 $\infty$ 并用零公理内核证明六条圆周闭合定理；最后构造免 `Quot.sound`、免根号的规范整三元数，给出特征秩为 $10$ 的非交换有理射影算例。在预连通、局部紧并满足相应连续性条件的非交换实值比较模型中，有号单位四元数达到局部坐标维数 $3$ 与特征秩 $5$ 的下界。假设详见[第三章 §3.4](ch03-canonical-ternion-manifold.md#sec-ch03-real-shadow-completion)。
- **第二卷：无原点非线性代数与球面有理几何**（[第四章](ch04-heaps-and-lie-triple-curvature.md)–[第六章](ch06-bargmann-gram-spherical-trigonometry.md)）。把无原点流群、利雅三元恒常单位曲率 $K \equiv +1$ 与本原毕达哥拉斯有号旋量六拍双覆叠展开到底，建立双卡无奇点三维有理凯莱旋转、整系数切比雪夫谐波以及球面巴格曼—格拉姆闭合律与有理正弦／勾股定理。
- **第三卷：无极限射流微积分与全息圆弧流形**（[第七章](ch07-second-order-jet-calculus.md)–[第九章](ch09-telescoping-stokes-and-arc-manifold.md)）。以二阶幂零射流环 $\mathbb{Q}[\eta]/(\eta^3)$、对称中点凯莱驻球守恒和任意阶 D-有限微分射流复合链式法则及凯莱—三角大一统取代 $\lim_{h \to 0}$，并借流群中继消去与单纯形锥同伦在粗剖分下完成精确积分。
- **第四卷：三维球面有理调和分析**（[第十章](ch10-peter-weyl-rational-spin-shells.md)–[第十二章](ch12-algebraic-extensions-and-schur-positivity.md)）。给出偶次切比雪夫特征标的整数乘积律，并用无 $\pi$ 的阶乘哈尔配对证明所有整数自旋特征标的正交归一性，并以零公理二次扩张域与有理舒尔补正定性承载不可约代数边界。
- **第五卷：阿代尔算术与纯有理赫克—黎曼谱论**（[第十三章](ch13-computable-arithmetic-horizon.md)–[第十五章](ch15-rational-hecke-ramanujan-spectrum.md)）。以欧几里得素数逃逸、有限连分数和整数四分深度预算取代静态素数无穷集，进而联通有理阿代尔乘积守恒、模方 $5$ 赫维茨素旋子自由群 $F_3 \hookrightarrow \mathrm{SO}(3,\mathbb{Q})$ 伴随单射与无复数赫克—拉马努金谱隙。
- **第六卷：Ω-FRACTRAN 计算论、观察者宇宙与零公理内核**（[第十六章](ch16-omega-fractran-and-nonabelian-stack.md)–[第十八章](ch18-zero-axiom-kernel-and-shadow-bridge.md)）。构造原生非阿贝尔旋子指令集与二维整数矩阵环，阐发观察者自包含时间与记忆切分模型，最终用空内核公理审计与单向阴影投影函子 $\Pi_{\mathbb{R}}$ 连接整个经典分析生态；全书以[终章](coda.md)全景对照与双语演示文稿、[附录 A](appendix-a.md) 模块冻结索引及[附录 B](appendix-b.md) 词典、证据总账与动态统计收尾。
