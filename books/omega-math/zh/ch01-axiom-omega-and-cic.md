# 第一章 纯归纳构造演算与母公理 AXIOM-Ω

> *“不要修改验证器的内核，更不要用 `axiom` 关键字硬塞任何未经检验的教条；把母公理写成可计算的类型类，再用一枚不含商公理、不含选择公理的纯整数结构去亲手实现它，相容性与可执行性便一举两得。”*

重建一套零公理有理数学，第一个必须回答的不是“数怎么写”，而是**“我们脚下的逻辑地板究竟是什么”**。如果一出发就站在传统集合论 ZFC 与实数连续统之上，哪怕口头上宣称排斥实无穷与超越数，底层证明引擎仍会在暗处悄悄注入选择公理与商集公理。本章把整座大厦的地基摊开在阳光下：第一，剖开 Lean 4 的纯归纳构造演算（CIC）裸内核，看清它为何天生没有实无穷与选择公理；第二，以有限有理精度契约 $\varepsilon_{\mathrm{self}} = 1/M$ 取代静态无穷集合；第三，立起无原点母公理 `AXIOM-Ω` 的三条法则；第四，用教学接口说明如何把运算与分项证书一起交给内核。
本书的“零公理内核验证”指严格 Omega 后端的空公理记录。源码链接所指的官方版本有独立的冻结公理记录。例如，第三章的射线左消去在严格后端公理为空，在官方后端依赖 `propext`。

## 1.1 纯归纳构造演算裸内核与三类隐藏公理 {#sec-ch01-bare-cic}

把现代交互式定理证明器 Lean 4 拆成两层，会发现它的**底层验证内核**与**上层经典分析库**遵循着截然不同的世界观。

尚未导入经典实分析库之前，Lean 4 的裸内核是**带宇宙层级的纯归纳构造演算（Calculus of Inductive Constructions, CIC）**。整个内核只有三种原生构件：依值函数类型（$\Pi$-类型，即把命题全称量词与函数空间合二为一的构造）、宇宙层级（防止罗素悖论的分层类型塔），以及有限归纳定义（`inductive`）。求值与证明检查完全由四条确定性归约规则驱动：函数代换（$\beta$）、定义展开（$\delta$）、归纳递归子消去（$\iota$）与局部绑定展开（$\zeta$）。

在这个裸内核中，并不存在康托尔意义下“事先装满 $\aleph_0$ 个元素的已完成无穷集合”。自然数类型 `Nat` 只由两条有限构造规则生成：零 `zero` 与后继 `succ`。任何写得出来的自然数都是一棵有限深度的语法树，任何定义在 `Nat` 上的递归函数都在有限步归纳拆解内停机。内核里既没有实数 $\mathbb{R}$，没有复数 $\mathbb{C}$，没有符号 $\infty$，也没有 $\pi$ 或 $e$；甚至连经典排中律与选择公理都不是内核的内置规则。

那么，传统形式化数学里的三大公理究竟从哪里混进来的？它们恰恰来自三大看似无害的经典便利工具：

1. **非构造性选择公理 `Classical.choice`**：允许从“某非空类型存在元素”的命题证明中凭空抽出一个数据元素，却不提供任何计算算法。需要把这个见证作为数据的计算，在提取见证这一步没有可执行实现。若只在可擦除的证明中使用选择公理，数据部分仍可执行。
2. **商类型公理 `Quot.sound`**：把等价类强行压成新类型，使等价但表示不同的两个对象在命题上相等，却在计算归约层缺少唯一的规范代表元。`Mathlib` 将实数定义为有理柯西序列模去零极限序列的商，一步把 `Quot.sound` 与 `Classical.choice` 全部带进底层。
3. **命题外延性 `propext`**：断言逻辑等价的两个命题完全相等。尽管它不像 `Classical.choice` 那样直接破坏求值，却仍属于裸 CIC 归约机制之外的附加公理。

值得特别警惕的是，即便不导入 `Mathlib`，标准库中某些自带类型也可能暗藏陷阱：例如带互素证明字段的内置有理数算术往往在内部引用了 `propext`、`Quot.sound` 乃至 `Classical.choice`。因此，在 `OmegaInit` 与 `OmegaMath` 的零公理算术部分，我们直接启用 `prelude` 裸环境，从零构造归纳自然数、有号整数与显式携带“零分母未定义分支”的精确分数类型（如 `Omega.Ratio` 与 `Omega.IntRatio`），或采用唯一约分的纯数据规范记录，并一律依托**构造性可判定相等性（`DecidableEq`）**——即对任意两个对象 $a, b$，都存在一个在有限步内停机、给出“$a = b$ 的显式证明”或“$a \neq b$ 的显式反驳”的决策程序。

::: {.definition #def-ch01-zero-axiom-core title="零公理裸 CIC 构造层与可判定相等性"}
称一个形式化模块处于**零公理裸 CIC 构造层**，若其中每条定义与定理的传递公理闭包均为空集（即不依赖 `propext`、`Classical.choice`、`Quot.sound` 或任何用户自定义 `axiom`），且所有类型判断与等式验证仅通过依值类型检查与 $\beta\delta\iota\zeta$-归约完成。称类型 $T$ 具有**构造性可判定相等性**（`DecidableEq`），若存在可计算函数，对任意 $a, b : T$ 返回两分支之一：或是 $a = b$ 的证明项，或是 $(a = b) \to \mathrm{False}$ 的反驳项。
:::

当每条射线都有唯一规范代表元时，比较两个规范整数元组即可判定它们是否代表同一射线。[第二章](ch02-homogeneous-projective-line.md)先在齐次整数对上说明这种做法，[第三章](ch03-canonical-ternion-manifold.md)再把它用到整四元组。底层库也可以保留未约分的代表元，直接用射线等价关系比较。

::: {.remark #rem-ch01-cic-hedberg-literature title="CIC 元理论、赫德伯格定理与三公理审计（ARGUED）"}

## 1.2 观察者有理精度契约与按需视界 {#sec-ch01-precision-contract}

撤去康托尔的静态实无穷之后，一个立刻跳出来的追问是：**“如果不允许把无穷多个数一次性装进集合，我们又如何处理不断细化的测量精度，或者任意大的素数与任意长的演化步？”**

答案极为朴素，而且与物理实验和数字计算机完全同构：**以显式的有理精度契约 $\varepsilon_{\mathrm{self}} = 1/M \in \mathbb{Q}_+$ 取代静态实无穷，以“按需扩展的有限视界”取代“已完成无穷容器”。**

没有任何真实观察者、实验室仪器或有限内存计算设备能够在一次读数中分辨无限位小数。每当观察者启动一次比较或计算，系统都伴随着一个严格正整数分辨率刻度 $M \in \mathbb{N}_+$，对应有理精度门槛 $\varepsilon_{\mathrm{self}} = 1/M > 0$。在这个当前视界下，一切坐标、分数读数与候选态都落在高度不超过 $M$ 的有限既约有理格网之内——对象个数有限，穷举搜索、极值判定与等价核验全部可在有限步内停机。

这并不意味着宇宙被锁死在某个永不增大的僵硬网格里。当两次合法运算的复合产生了更大的分子或分母（例如两枚有理圆点相乘，分母从 $M_1, M_2$ 升至 $M_1 M_2$），或者当观察者要求更高的分辨力时，视界高度按惰性求值按需抬升 $M \mapsto M'$。任何一次具体计算中，高度 $M'$ 始终是一个确定的有限正整数；我们永远拥有“造出更大有限视界”的构造规则（潜在无限，即归纳法则），却从不假定“所有视界已经同时完毕地装在一个静态口袋里”（康托尔实无穷）。

::: {.definition #def-ch01-observer-precision title="观察者有理精度契约与有限高度视界（MODEL）"}
设 $M \in \mathbb{N}_+$ 为正整数。称有理数

$$
\varepsilon_{\mathrm{self}} \;=\; \frac{1}{M} \;\in\; \mathbb{Q}_+
$$

为观察者在当前比较任务中的**有理精度契约**。对一维齐次整数射影对 $[P : Q]$（$\gcd(\lvert P\rvert, \lvert Q\rvert) = 1$），定义高度为 $H([P : Q]) := \max(\lvert P\rvert, \lvert Q\rvert)$，称有限集合

$$
\mathbb{QP}^1_{\le M} \;:=\; \bigl\{\,[P : Q] \in \mathbb{QP}^1 \;:\; \max(\lvert P\rvert, \lvert Q\rvert) \le M\,\bigr\}
$$

为分辨率 $M$ 下的**有限射影视界**。当运算结果的高度超过 $M$ 时，契约通过有限正整数提升 $M \mapsto M'$ 按需扩展，全过程不引入不可数集合或已完成实无穷。
:::

::: {.example #ex-ch01-finite-horizon-budget title="有限精度预算的算术演练（NUM）"}
取分辨率 $M = 12$，对应观察者精度契约 $\varepsilon_{\mathrm{self}} = \frac{1}{12}$。若要求测量分辨误差不超过 $\frac{1}{12}$，在既约分数格网中任意两个互异正有理数 $a/b \neq c/d$（分母 $b, d \le 12$）满足 $\lvert a/b - c/d\rvert = \lvert ad - bc\rvert / (bd) \ge \frac{1}{12 \times 11} = \frac{1}{132}$——整个格网的最小间距是严格正的有理数，没有任何“无穷靠近却不相等”的模糊地带。现在设任务需要复合两枚分别位于 $M = 3$ 视界内的有理圆点 $[1 : 2]$（平方范数 $1^2 + 2^2 = 5$）与 $[1 : 3]$（平方范数 $1^2 + 3^2 = 10$）：未约分乘积的高度暂时升至 $5$，经公因子 $5$ 约分后反倒落回高度为 $1$ 的锚点 $[1 : 1]$；若复合 $[1 : 2]$ 与 $[2 : 5]$（平方范数 $5$ 与 $29$），乘积为 $[9 : 8]$，高度自然按需抬升至 $M' = 9$。每一拍都只有有限整数在运转。
:::

从数理逻辑的角度看，有限高度视界还有一道深层庇护：在无界整数环 $(\mathbb{Z}, +, \times)$ 上，任意存在量词丢番图方程因希尔伯特第十问题的否定解而不可判定；但在任何给定有限高度视界 $M$ 内，有界量化命题全都可以由有限步算术精确判定（`ARGUED`，参见 Yu. Matiyasevich, 1970）。有理精度契约既是物理可观测性的诚实表达，也是算法可判定性的天然护栏。

## 1.3 母公理 AXIOM-Ω 的三条核心法则 {#sec-ch01-mother-laws}

站稳了零公理裸 CIC 地板并确立了有限有理视界之后，我们终于可以问出全书的核心几何问题：**如果我们把传统教科书里的两根人工脚手架——“特权外部原点 $\mathbf{1}$”与“平直笛卡尔线性加法 $+$”——一并拆掉，宇宙中最朴素的几何关系还剩下什么？**

剩下的只有两件东西：一个非空的状态载体 $\mathcal{M}$，以及两种纯粹的关系动作。第一种动作是**无源三元比较迁移** $[-, -, -] : \mathcal{M} \times \mathcal{M} \times \mathcal{M} \to \mathcal{M}$：把 $y$ 当作临时参照桥，读出“$x$ 相对于 $y$ 的关系变化”，再无损地搬运到 $z$ 身上，得到新态 $[x, y, z]$。第二种动作是**有理对称保真度读数** $\kappa : \mathcal{M} \times \mathcal{M} \to \mathbb{Q} \cap [0, 1]$：直接量出任意两态 $x, y$ 之间的对齐程度，不借用任何外部坐标系或实数弧度尺。

这两枚原语服从三条不可分割的母法则，统称为**母公理 `AXIOM-Ω`**：

::: {.definition #def-ch01-axiom-omega title="母公理 AXIOM-Ω 的三条法则（MODEL）"}
设 $\mathcal{M}$ 为非空类型，配备三元比较迁移 $[-, -, -] : \mathcal{M} \times \mathcal{M} \times \mathcal{M} \to \mathcal{M}$ 与对称保真度读数 $\kappa : \mathcal{M} \times \mathcal{M} \to \mathbb{Q}$。称三元组 $(\mathcal{M}, [-, -, -], \kappa)$ 满足母公理 **`AXIOM-Ω`**，若它服从以下三条母法则：

1. **法则 I（无源求同消去与三元结合律）**：对一切 $x, y, z, u, v \in \mathcal{M}$，

   $$
   \begin{aligned}
   [x, x, z] &= z, \qquad [x, z, z] = x, \\
   \bigl[[x, y, z],\, u,\, v\bigr] &= \bigl[x,\, y,\, [z, u, v]\bigr].
   \end{aligned}
   $$

2. **法则 II（双侧迁移不变、外延分离、触零与有理格拉姆半正定）**：对一切 $x, y, u, v \in \mathcal{M}$，满足对称性 $\kappa(x, y) = \kappa(y, x)$、外延分离 $\kappa(x, y) = 1 \iff x = y$、非负性 $\kappa(x, y) \ge 0$、存在完全失配正交对（或读数可任意逼近零的触零性），以及左右双侧迁移不变性：

   $$
   \kappa\bigl([x, u, v],\, [y, u, v]\bigr) \;=\; \kappa\bigl([u, v, x],\, [u, v, y]\bigr) \;=\; \kappa(x, y);
   $$

   同时，对任意有限样本 $x_1, \dots, x_n \in \mathcal{M}$ 与任意有理权重 $c_1, \dots, c_n \in \mathbb{Q}$，有限格拉姆矩阵 $\mathbf{G}_n = \bigl[\kappa(x_i, x_j)\bigr]_{i,j=1}^n$ 满足有理半正定性（记作 $\mathbf{G}_n \succeq 0$）：

   $$
   \sum_{i=1}^{n}\sum_{j=1}^{n} c_i c_j\,\kappa(x_i, x_j) \;\ge\; 0.
   $$

3. **法则 III（极小非对易自锁律）**：三元迁移对外侧两个槽位的次序敏感，即存在 $x, y, z \in \mathcal{M}$ 使得

   $$
   [x, y, z] \;\neq\; [z, y, x],
   $$

   并且结构取满足法则 I、法则 II 与非对易性的极小非退化自由度与特征秩自锁解。
:::

请停下来端详这组法则的惊人节俭之处。整套公理里**没有一个 $\pi$、没有一个 $e$、没有一个 $\varphi$、没有实数 $\mathbb{R}$、没有加法 $+$、没有预设的空间维数“$3$”，甚至没有预设一个特权单位元 $\mathbf{1}$**。从法则 II 的小格拉姆矩阵与法则 I 的代数改写，可以直接读出保真度的约束与局部群结构（`ARGUED`）。

- **保真度上界 $\kappa \le 1$ 自动免费得出**：在法则 II 的有理格拉姆半正定不等式中取 $n = 2$、两点 $(x, y)$ 与有理权重 $(c_1, c_2) = (1, -1)$，利用 $\kappa(x, x) = \kappa(y, y) = 1$ 与对称性立刻得到

  $$
  1^2\cdot 1 + (-1)^2\cdot 1 + 2(1)(-1)\kappa(x, y) \;=\; 2 - 2\kappa(x, y) \;\ge\; 0 \quad \Longrightarrow \quad \kappa(x, y) \;\le\; 1.
  $$

  结合非负性，得到 $\kappa(x, y) \in \mathbb{Q} \cap [0, 1]$。

  再加入一个任意探测点 $z$，记 $d = \kappa(x,z)-\kappa(y,z)$。样本 $(x,y,z)$ 取有理权重 $(1,-1,-d)$，由归一化和对称性，格拉姆二次型为 $2-2\kappa(x,y)-d^2 \ge 0$。于是 $\kappa(x,y)=1$ 时，$x$ 与 $y$ 对每个 $z$ 的读数都相同。反过来，若整行相同，取 $z=y$ 即得 $\kappa(x,y)=\kappa(y,y)=1$。这一步只用了归一化、对称性和有理格拉姆半正定。要由单位读数推出底层点相等，所需的附加条件恰是读数行映射 $x\mapsto\kappa(x,\cdot)$ 的单射性。这就是法则 II 中外延分离的作用。

  两次读数究竟能相差多远？先把 $x,y$ 的相互读数固定为 $3/5$，让第三点 $z$ 对它们分别读出 $4/5$ 和 $0$。对三个点依次赋予有理权重 $u,v,w$，格拉姆二次型恰为 $(v+3u/5)^2+(w+4u/5)^2$。因此这组三点读数确实可实现。式中的 $3^2+4^2=5^2$ 提示我们把相互读数与探测读数之差放进同一个平方和。

::: {.theorem #thm-ch01-three-reading-contrast title="三点格拉姆读数差的精确范围" lean="D5/S3/Quantum/AURICOmega/ThreeReadingContrast.exists_nonnegative_readings_iff"}
给定 $r,d\in\mathbb Q$。存在非负有理数 $a,b$，使 $a-b=d$ 且对一切 $u,v,w\in\mathbb Q$ 都有

$$
Q(u,v,w)=u^2+v^2+w^2+2(ruv+auw+bvw)\ge 0,
$$

当且仅当 $r^2+d^2\le 1$。
:::

::: {.proof}
由 $Q(1,-1,0)\ge0$ 得 $r\le1$。若 $d=a-b\ge0$，则
$1-r^2-d^2=Q(1,-r,-d)+2(1-r)bd\ge0$。若 $d<0$，交换前两点即可。反过来，若 $r^2+d^2\le1$ 且 $d\ge0$，可取 $a=d,b=0$，此时

$$
Q(u,v,w)=(v+ru)^2+(w+du)^2+(1-r^2-d^2)u^2.
$$

当 $d<0$ 时交换前两点，取 $a=0,b=-d$。完整证明由 Lean 内核检查。
:::

三点判据与下面的五点判据都使用 Mathlib 的有理数与序结构，两条 Lean 证明均依赖 `propext`、`Classical.choice` 和 `Quot.sound`。在法则 II 中，$r$ 还须非负。

回到 $3/5$ 的算例。把两枚迁移点 $w=[x,y,z]$ 与 $v=[y,x,z]$ 也纳入样本，双侧迁移不变性使 $z$ 对两者的读数都等于 $t=\kappa(x,y)$。原来 $4/5$ 的读数差还能保住吗？当 $t=3/5$ 时，五点矩阵允许的最大差值降为 $13/20$，由 $a=3/4$、$b=1/10$ 取得。

::: {.theorem #thm-ch01-five-point-transported-contrast title="两枚迁移点给出的读数差范围" lean="D5/S3/Quantum/AURICOmega/FivePointTransportedContrast.exists_transported_readings_iff"}
给定 $t,d\in\mathbb Q$，$0\le t\le1$。在标签顺序 $(x,y,z,w,v)$ 下，存在非负有理数 $a,b,c,e,r$，使 $a-b=d$ 且矩阵

$$
G=\begin{pmatrix}
1&t&a&b&e\\
t&1&b&c&a\\
a&b&1&t&t\\
b&c&t&1&r\\
e&a&t&r&1
\end{pmatrix}
$$

对每个 $h\in\mathbb Q^5$ 满足 $h^{\mathsf T}Gh\ge0$，当且仅当

$$
d^2\le
\begin{cases}
(1-t^2)^2, & 0\le t\le 1/2,\\
(5/4-t)^2, & t>1/2,\quad (t-1/2)^2\le 1-t^2,\\
(2t-1)^2(1-t^2), & t>1/2,\quad (t-1/2)^2>1-t^2.
\end{cases}
$$
:::

::: {.proof}
同时交换 $x,y$ 和 $w,v$ 可将 $d$ 变号，故只需考虑 $a\ge b$。先删去 $v$。把前四点的权重按同时交换 $x,z$ 和 $y,w$ 分为对称与反对称两部分，得到两个二元二次型。它们的行列式约束给出分段上界。反过来，各段都可选取有理的四点读数，使 $c=0$、$b<1$。让第五点在 $y,z$ 上的投影分别给出所需读数 $a,t$。取投影系数 $(a-bt)/(1-b^2)$ 和 $(t-ba)/(1-b^2)$，四点二次型保证把第五个对角元补到 $1$ 所需的余量非负。完整证明由 Lean 内核检查。
:::

这些矩阵给出了五个标签上相容的读数。哪些五点数据能延拓为整个三元运算空间上的双侧不变核，仍是另一个存在性问题。

- **任意一点都可临时充当原点，三行还原为群**：在 $\mathcal{M}$ 中任挑一点 $o$ 作为临时参照基点，定义二元乘积 $x \star_o z := [x, o, z]$ 与局部逆元 $x^{-1_o} := [o, x, o]$。由法则 I 的结合律直接得 $(x \star_o y) \star_o z = [[x, o, y], o, z] = [x, o, [y, o, z]] = x \star_o (y \star_o z)$；左右单位元分别由 $[o, o, z] = z$ 与 $[x, o, o] = x$ 证毕；左右逆元只需展开两步：

  $$
  \begin{aligned}
  x \star_o x^{-1_o} &= \bigl[x, o, [o, x, o]\bigr] = \bigl[[x, o, o], x, o\bigr] = [x, x, o] = o, \\
  x^{-1_o} \star_o x &= \bigl[[o, x, o], o, x\bigr] = \bigl[o, x, [o, o, x]\bigr] = [o, x, x] = o.
  \end{aligned}
  $$

  并且原始三元迁移恰好还原为 $x \star_o y^{-1_o} \star_o z = [x, y, z]$；更换临时基点 $o \mapsto o'$ 的映射 $x \mapsto [x, o, o']$ 则是保持三元迁移与保真度读数的双射（逆映射为 $x \mapsto [x, o', o]$）。宇宙中没有任何一点高人一等，任何观察者都可以站在自己脚下开启局部代数运算，算完之后参照桥自动消去不留残渣。

**把整行相同的点合成一类。** 若保留归一化及法则 II 的其余读数条件，暂去掉外延分离，能否直接在读数类上做三元迁移？记 $x\sim y$ 表示整行相同，在临时基点 $o$ 所确定的群 $G$ 中令 $N=\{n\in G:n\sim o\}$。左平移保读数，且可逆，因此 $x\sim y$ 当且仅当 $x^{-1}y\in N$。若 $n,m\in N$，左平移给出 $nm\sim n\sim o$，也给出 $n^{-1}\sim o$，所以 $N$ 是子群。右平移也保读数时，先左乘 $g$，再右乘 $g^{-1}$，即得 $gng^{-1}\sim o$，所以 $N$ 是正规子群。

因此读数类是商群 $G/N$ 的元素，三元迁移可用三类的群运算 $[xN,yN,zN]=(xy^{-1}z)N$ 计算。仅有左平移不变性时，正规性仍是迁移能在读数类上定义的充要条件。若迁移与代表元无关，取中槽为 $o$ 就得到与代表元无关的乘法，因而可在 $n\sim o$ 的两边分别乘 $g$ 与 $g^{-1}$。商上的读数也与代表元无关，第一槽由整行相同保证，第二槽由对称性保证。在代表元上计算可知，原来成立的平移不变性在商上仍成立。每个有限商样本选一组代表元便得到原来的格拉姆二次型，所有读数值也原样保留，因此仍然触零。商上单位保真度恰好表示两个类相同。

看外槽次序是否仍可区分，只需在商群里比较 $xy$ 与 $yx$，因为取中槽为单位元便得到群乘法，而交换群的任意三元迁移都可交换外槽。故非交换性保留的充要条件是存在换位子 $xyx^{-1}y^{-1}$ 落在 $N$ 之外，等价于 $[G,G]\nsubseteq N$。

同一个有限群上就能看见两种情形。令 $G=S_3\times\{+1,-1\}$，用 $[x,y,z]=xy^{-1}z$ 作迁移。可以约定两点的置换分量相同时读数为 $1$，否则为 $0$，也可以只比较置换的奇偶性。两种读数都按群同态的纤维分组，左右平移都保持分组关系。若以 $r_i$ 表示样本 $x_i$ 的置换或奇偶性，格拉姆二次型为 $\sum_r(\sum_{i:\,r_i=r}c_i)^2$，所以半正定。两种读数都把 $(e,+1)$ 和 $(e,-1)$ 合为同一类，并给单位元与换位之间的读数 $0$。

按置换分量取商得到 $S_3$，换位 $(12)$ 与 $(23)$ 的乘积仍取决于次序。只按奇偶性取商则得到二元交换群，两个次序给出同一个偶置换类。这就恢复了外延分离，而读数能否区分外槽次序取决于哪些换位子在商中仍然可见。

在置换读数的 $S_3$ 商上，每类选 $(\sigma,+1)$ 就能把三元迁移带回原来的十二个点。相同读数也可以来自另一组十二个点
$$
  G'=\{(\sigma,j)\in S_3\times\mathbb{Z}/4\mathbb{Z}:j\bmod 2=\epsilon(\sigma)\},
$$
其中 $\epsilon$ 为奇偶性，偶置换取 $0$，奇置换取 $1$。这里的乘法是 $(\sigma,j)(\tau,k)=(\sigma\tau,j+k)$。仍只比较置换分量，于是读数类、商迁移和上面的格拉姆平方和都相同。

设 $s$ 为换位。$G'$ 中代表 $s$ 的两点是 $(s,1)$ 与 $(s,3)$，两者平方均为 $(e,2)$。若能为每类选一个保持三元迁移的代表，先把所有代表左乘单位类代表的逆，就可令单位类的代表为 $(e,0)$。这个平移保留各点所在的类和三元迁移。此时商中 $[s,e,s]=e$ 要求 $s$ 的代表平方为 $(e,0)$，与计算矛盾。因此相同的读数和商迁移可以对应不同的选代表能力。两个算例都放宽了外延分离，极小性仍须相对于指定的模型类判断。

## 1.4 为什么用可计算类型类 class OmegaSpace 而不是 axiom {#sec-ch01-typeclass-not-axiom}

在交互式定理证明器里写下 `AXIOM-Ω` 时，新手最容易掉进一个看似快捷的陷阱：直接敲下 `axiom M : Type`、`axiom triad : M → M → M → M`、`axiom kappa_refl : ∀ x, kappa x x = 1`。**本书从第一条规则起就彻底禁止这种做法。**

原因有两条，每一条都足以摧毁整座形式化工程。

第一，**裸 `axiom` 毫无无矛盾性保障，漏掉一个微小边界就会炸出 `False`**。Lean 内核无条件信任每一条用户声明的 `axiom`。假设有人在一个包含零四元组 $z_0 = (0, 0, 0, 0)$ 的原始载体上草率写下 `axiom kappa_refl : ∀ x, kappa x x = 1`，而底层的分数函数对零分母返回未定义值或 $0$，那么只要代入 $x = z_0$，三行之内就能推出 `0 = 1`，进而推出逻辑爆炸 `False`——从此一切真假命题都能“被证明”。任何严肃的独立内核审计器遇到非标准 `axiom` 都会当场拒收。

第二，**没有实现的数据公理会卡住依赖它的计算**。若声明 `axiom n : Nat`，以 `n` 为被匹配项的 `match` 看不到构造子，内核的 $\iota$-归约便卡在此处，代码生成器也无从取得 `n` 的值。`Prop` 中的证明可以在编译时擦除。例如，下面的子类型值将 `42` 与公理给出的证明 `h` 配对，投影 `.val` 在内核归约和编译求值时都得到 `42`。

```lean
axiom n : Nat
#reduce (match n with | 0 => 0 | Nat.succ k => k)

axiom h : 42 = 42
#eval (⟨42, h⟩ : {k : Nat // k = 42}).val
```

可以把运算与逐条证书收在同一个结构里，使定理显式依赖传入的证书。下面的 `class OmegaSpace` 是一段教学接口示意，列出法则 I 和法则 II 中的部分读数条件。

```lean
class OmegaSpace (M : Type) where
  triad       : M → M → M → M
  kappa       : M → M → QRat
  idemp_left  : ∀ x z, triad x x z = z
  idemp_right : ∀ x z, triad x z z = x
  assoc_triad : ∀ x y z u v, triad (triad x y z) u v = triad x y (triad z u v)
  kappa_refl  : ∀ x, kappa x x = QRat.one
  kappa_symm  : ∀ x y, kappa x y = kappa y x
  kappa_inv_r : ∀ x y u v, kappa (triad x u v) (triad y u v) = kappa x y
  kappa_inv_l : ∀ x y u v, kappa (triad u v x) (triad u v y) = kappa x y
```

这样的接口只承诺所列字段。取八元四元数群 $Q_8 = \{\pm 1,\pm\mathbf{i},\pm\mathbf{j},\pm\mathbf{k}\}$，以 $[x,y,z]=xy^{-1}z$ 为迁移，令 $\kappa(x,y)=1$ 恒成立。群的恒等式给出消去与结合，常值读数满足其余读数字段，甚至让每个有限格拉姆二次型成为 $(\sum_i c_i)^2 \ge 0$，而 $\mathbf{i}\mathbf{j}\neq\mathbf{j}\mathbf{i}$。可是 $\kappa(1,-1)=1$，读数也无法触零。要得到完整模型，须逐项补证分离、非负、格拉姆半正定、触零和非交换性，并说明极小性相对于哪一类结构。

实际的零公理库用非零代表元与射线等价来验证整四元数定律。第三章再手工推导规范代表元上的严格消去与读数性质，并在实值比较结构上交代秩五结论的额外前提。见[第三章](ch03-canonical-ternion-manifold.md)。

::: {.film src="the-bare-kernel"}
**裸 CIC 内核只有三种构件与四条归约，经典公理借捷径混入；精度改成有限契约 $1/M$，母公理只留三元迁移与保真度 $\kappa$，并写成可计算的类型类而不是裸 `axiom`（3 分 02 秒）。** 青色面板列出依值函数、宇宙层级与有限归纳定义以及 $\beta$、$\delta$、$\iota$、$\zeta$ 四条归约，$3$ 画成 `succ succ succ zero` 的有限树；品红卡片依次是 `Classical.choice`、`Quot.sound` 与 `propext`，这些类型论元理论按文献结果标为紫色论证（[@rem-ch01-cic-hedberg-literature]）。交叉相乘判定 $12/18 = 2/3$ 与 $3/4 \neq 2/3$、$[0, 1]$ 中分母不超过 $12$ 的 $47$ 个既约分数及其最小间距 $1/132$（$1/12$ 与 $1/11$ 之间，琥珀色）、$[1 : 2] \odot [1 : 3] = (5, 5) \sim [1 : 1]$ 与 $[1 : 2] \odot [2 : 5] = [9 : 8]$ 都是屏幕计算（青色 NUM，[@ex-ch01-finite-horizon-budget]），视界从 $M = 3$ 抬升到 $M' = 9$。精度契约与三条母法则是模型（紫色，[@def-ch01-observer-precision]、[@def-ch01-axiom-omega]），迁移图是示意；由格拉姆二次型得 $\kappa \le 1$、以任一点 $o$ 为单位元的局部群按本章推导标为论证。零四元组上的 $0 = 1$、自然数公理 `n` 卡住对它的模式匹配、擦除 `Prop` 证明后仍可投影出 `42`，以及教学接口 `class OmegaSpace`，均标为论证。取常值 $\kappa \equiv 1$ 的 $Q_8$ 满足接口所列字段（屏幕上逐例核对），却有 $\kappa(1, -1) = 1$，且读数下确界为 $1$，因此既不分离也不触零。
:::
